## OCR 規則（必須全部遵守）

1. **保留原文順序**，不重排、不增刪任何文字
2. **中文字之間若有多餘空白請去掉**（但中英文之間、中數字之間保留一個空格）
3. **數學公式**：行內公式用 `$...$` 包，例如 `$\frac{1}{2}$`；獨立公式用 `$$...$$`
4. **表格**：輸出 markdown table（`| 欄1 | 欄2 |` 格式），不要用純文字排版
5. **選擇題**：保留 (A)(B)(C)(D) 或 ①②③④ 的格式
6. **不確定的字**：用 `[?]` 標記，絕對不要亂猜
7. **試卷與答案**之間（若同一份文件含兩部分）用 `\n\n---\n\n` 分隔
8. **圖片/示意圖**：輸出 `![圖N](略)` 並在下方加「圖示說明：…」一句描述圖意；不要跳過圖片
9. **輸出格式**：只輸出 Markdown 內容本身，不要 code fence（不要 \`\`\`markdown）、不要開場白、不要結語
10. **題號**：保留所有原始題號（一、二、1. 2. 等）
