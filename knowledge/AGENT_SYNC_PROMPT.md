# 協作 Agent 雙軌品質指標大腦更新語法 (Prompt)

請複製以下整段指令，貼給正在負責產題的 Cursor 或其他協作 Agent，讓它們更新認知：

```markdown
@knowledge/README_出題設計準則.md 

【系統認知緊急更新：雙軌品質指標機制】
本專案的品質評分系統已經正式升級為「雙軌制」，為了兼顧內部優化動能與外部平台防呆，請你在後續產出題庫與驗收時，嚴格遵守以下認知與原則：

1. **你的工作目標是「題目細緻度指標 (CQI)」— 採用 10 分加權制 (0.0 ~ 10.0 分)**
   依據最新的權重得分制：題目結構與解析佔 2.0 分、選項對稱性佔 3.0 分、情境深度字數佔 3.0 分、理解與應用層次佔 2.0 分。你身為專業的出題 Agent，你產出題庫的絕對及格安全門檻是 **讓全檔平均 CQI 得分達到 6.0 分以上**！低於 6.0 分代表你的題目太單調或選項長度不對，需自我反省重寫。

2. **你不需要干涉「題庫嚴謹度指標 (QG)」— 採用階級制 (L1 ~ L5)**
   評分腳本會依據絕對達標條件（木桶原理）判定出該題庫的 `quality_level` 階級（例如：L3 是標準題庫、L4 是素養題），這是用來對外發布的防呆門檻。此欄位一律由腳本自動賦予，你**絕對不可以**自己手動在 JSON 裡填寫或修改 `quality_level` 欄位。

3. **產題流程與自我檢核標準**
   - 繼續維持你最高標準的加權得分出題水準（字數達標、選項對稱、富含解析與診斷）。
   - 產出完成後，請務必主動執行 `node scripts/evaluate_question_quality.js <你的目標資料夾>`。
   - 檢查終端機輸出：若看到你的 **"avgCQI"** 超過 6.0 分，代表你表現極佳；若有題目因為盲猜漏洞被強制打落到 **L1 (BIAS)** 級別，請立刻修正該題。

請回覆「我已更新雙軌品質指標認知，後續出題將以提升 CQI (題目細緻度指標) 至 6.0 分以上為作業核心目標！」以確認你已吸收此規則。
```
