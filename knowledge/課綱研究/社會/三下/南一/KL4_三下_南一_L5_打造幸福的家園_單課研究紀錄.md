## 一、課綱連結與學習總目標

- **課綱定位**：南一三下社會最終單元為自主探究實作，整合 U1「居住的地方」、U2「地方生活」、U3「生活理財」、U4「居住地方的地名與故事」四單元所學，進行社區探究與公民行動的完整流程實作。
- **核心概念**：
  - 以社區為場域，學生從「被動受保護者」進階為「主動探究者與參與者」。
  - 探究流程 = 觀察 → 訪談 → 整理 → 溝通 → 指標 → 反思。
  - 公民行動 ≠ 情緒宣洩或抱怨；是有組織、有證據、有對話的集體改變行動。
- **學習總目標**：
  1. 能辨識社區中可探究的具體議題，避免過大或過抽象的主題。
  2. 能區分「個人意見」與「事實證據」，並用訪談與觀察收集資料。
  3. 能辨識利害關係人並設計多方溝通方式。
  4. 能以具體指標評估行動成效，並進行可操作的反思改進。
  5. 能認同自己作為社區一份子的能動性（agency），肯定小行動的意義。

## 二、核心知識點地圖

### 2.1 探究流程的五階段

| 階段 | 關鍵行動 | 守衛點（常見錯誤） |
|:--|:--|:--|
| 觀察 | 多次現場觀察、記錄不同時段與情境的差異 | 單次觀察下結論；把個人感受當成普遍事實 |
| 訪談 | 事先準備問題、尊重受訪者時間、記錄完整不只取對自己有利 | 表演式訪談（只為交作業）；打斷受訪者；忽略紀錄倫理 |
| 整理 | 分類呈現各方立場、標出共識與分歧、註明來源 | 只挑支持自己論點的意見；忽略反面資料 |
| 溝通 | 對不同受眾用不同呈現方式（報告、海報、懶人包） | 單一格式套所有受眾；重形式輕內容 |
| 指標與反思 | 設定可觀察的成效指標、萃取具體改進點 | 把誇獎當成效；反思停留在情緒層次 |

### 2.2 公民參與的概念與工具

| 概念 | 說明 | 守衛點 |
|:--|:--|:--|
| 利害關係人（stakeholder） | 受議題影響或對議題有影響力的所有人 | 學生常忽略自己也是利害關係人 |
| 連署 | 收集社區居民簽名以呈現集體意志 | 誤以為連署是形式、沒有實際作用 |
| 社區發展協會 | 居民自主組成，推動社區營造與自治 | 混淆與管委會、警察單位的功能 |
| 1999 / 里辦公室 / 里民大會 | 公民向公部門表達意見的具體管道 | 誤以為只有「找警察或市長」一種方式 |
| 社區群組 / 社群媒體 | 居民橫向串聯與資訊分享的日常平台 | 以為只能被動接收不能主動動員 |

### 2.3 跨 U1-U4 整合應用

| U | 原課知識點 | 在 L5 探究中如何使用 |
|:--:|:--|:--|
| U1 居住的地方 | 社區空間、地理方位、自然環境條件 | 觀察公園位置、人行道配置、風向日照對空間使用的影響 |
| U2 地方生活 | 敦親睦鄰、為民服務、社區組織 | 辨識社區中的民間組織與公部門分工，設計多方溝通策略 |
| U3 生活理財 | 需要 vs 想要、機會成本、預算分配 | 判斷社區公共空間的「基本需要」與「加值想要」優先順序 |
| U4 居住地方的地名與故事 | 地名由來、家鄉故事、文化資產 | 辨識社區中值得保存的文化元素，規畫文化導覽或公聽會 |

## 三、核心迷思與守衛點分析

### 迷思一：公民行動 = 抱怨或投訴

許多學生（與一些成年人）把公民參與化約為向政府投訴或網路抱怨。本單元要建立的是：公民行動是**觀察 → 資料收集 → 多方溝通 → 具體提案 → 反思改進**的完整流程，而抱怨只是其中最微小的情緒啟動，不是行動本身。

### 迷思二：公權力依賴（把公共事務完全外包給權威）

素材庫「專題三：現代公民參與與社區營造」直接點出：學童遇到社區問題的直覺反應是「找警察」或「找市長」。此迷思的背後是「公共事務與我無關」的預設。本單元透過「自己也是利害關係人」與「多方溝通而非單一權威」兩個角度破解。

### 迷思三：個人意見 = 事實判斷

學生傾向把自己的直覺當成結論，忽略「我覺得」與「證據顯示」的落差。探究教育要讓學生養成「先蒐集再判斷」的習慣，這對 G3 是認知上的重大躍進。

### 迷思四：探究 = 機械套用公式 / 探究 = 交作業

當探究被窄化為「一組公式套用」或「一份待交的作業」，就失去其情境敏感度與情感動能。本單元結尾的反思應引導學生看見自己作為行動者的意義，而不只是完成任務。

### 迷思五：個人行動沒有意義（公民無力感）

這是本單元最核心也最難破除的迷思。G3 學生常感到「我只是小學生，我的意見沒人在乎」。破解方式：具象樣板（題 2、題 11 的完整公民行動流程）+ 肯定小行動的累積效果（題 30 的「我也能成為家鄉變好的力量」）。
