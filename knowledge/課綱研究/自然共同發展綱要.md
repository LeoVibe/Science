# 📄 自然科共同發展綱要 (Science Common Developmental Outline)

**檔案定位**：本綱要為自然學科「研究紀錄」與「題庫產出」的統一技術規格與邏輯基石。
**版本**：v1.0.0
**適用對象**：全版本國小自然與生活科技 (108 課綱)

## 🎯 一、 教授觀點：學科核心命題目標 (Pedagogical Core)

從歷屆科學素養評量中，我們發現許多學生「可以背出光學三原色，卻無法解釋為什麼池水看起來比較淺」。自然科教育最大的失敗在於：**把科學當作文科在背結論。**

高品質 (L4-L5) 的自然科題庫，核心任務在於評量**「探究與實作 (Inquiry and Practice)」**的能力：
1. **探究歷程的重現**：出題時不直接給結論，而是給予一個「實驗情境」，詢問學生「為什麼要這樣設計對照組？」或「從這個圖表，我們可以得出什麼推論？」。
2. **科學與生活的連結**：將課本死板的實驗延伸至生活上的「未知現象」，要求學生運用所學原理來解釋（例如：將毛細現象引導至為什麼運動衣排汗好）。
3. **辨識迷思概念 (Misconception Detection)**：孩童在科學上最常出現「直覺物理學」的錯誤認知（例如以為重的物體落得快）。

## ⚖️ 二、 評分與品質標準 (L1-L5)

| 等級 | 定義名稱 | 自然科具體要求 |
| :--- | :--- | :--- |
| **L5** | **專家審定** | 考題設計為「連續型的探究文本」或「複雜實驗設計的除錯」，並具備完美的隨機答案分佈與迷思選項。 |
| **L4** | **深度分佈** | **題目必須結合明確的控制變因、實驗步驟情境，考驗觀測與推論。** 解析須點出科學迷思的痛點。 |
| **L3** | **完整覆蓋** | 完整包含該課所有的科學名詞與現象定義，選項具備合理的干擾性，並有完整解析。 |
| **L2** | **課文分析** | 單點式「背結論」事實題，例如「哪一種力可以讓球停下來？摩擦力」。 |
| **L1** | **基礎題庫** | 題幹不明確，選項具備不科學的靈異描述或答案嚴重偏差。 |

## 💡 三、 迷思誘答設計範例 (Distractor Design)

自然科的錯誤選項應該具備極高的教育價值，精準踩在學生的思考盲區：
*   **直覺偏誤**：例如將「月相盈虧」的成因選項一，設定為「地球的影子擋住了月球」（這是月食的成因，也是多數孩童的迷失）。
*   **控制變因失效**：選項提供了一個同時改變兩個變數（如水溫與水量）的實驗設計，並詢問學生這項設計哪裡有問題。
*   **目的錯置**：在實驗觀察題中，將「現象」當作「原因」來陳述。
