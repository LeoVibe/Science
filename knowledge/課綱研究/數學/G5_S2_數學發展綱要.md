# 📄 G5S2 數學發展綱要 (Grade 5 Semester 2 Math Development Outline)

**檔案定位**：本文件依據《數學共同發展綱要》精神，定義五年級下學期之數學命題規格。
**版本**：v3.0.0 (重構版)
**研究對象**：康軒、翰林、南一 (108 課綱)

## 🎯 一、 階段性核心命題目標 (Stage Core Matrix)

五年級下學期為總整國小數理概念邁向六年級的橋樑，包含更複雜的**轉換性數理思維**。
- **跨維度的量測換算**：從體積 (cm³) 跨越到容積 (L/mL)，並結合水位的上升下降，要求空間抽象計算力。
- **率與分數小數的共伴**：比率、百分率、小數乘法、分數乘法之間的自由切換，學生必須具備極高的數字敏感度。
- **代數思維啟蒙**：透過「未知數」導入一元一次方程式的解題框架。

## 🛡️ 三、 品質稽核與斷言 (Audit Gateway)
- 遇到 **「比率與百分率」** 與 **「小數乘法」**，務必在 JSON 誘答中混入**直覺型錯誤**(例如 20% off 設計為 2折 的得數，或 0.5 * 0.5 設計成 2.5 或 0.250 的小數點迷向)。
- 遇 **浮體/沉體與水位** 題型，一定要強調「容器是否裝滿」。
