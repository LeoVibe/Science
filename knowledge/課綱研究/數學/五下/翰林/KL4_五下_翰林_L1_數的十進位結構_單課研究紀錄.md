## 第一部：單元概念深度分析

### 1.1 單元定位與教學核心

本課為翰林五下第一課，聚焦於「兆位以上大數」的十進位結構與讀寫，是五下開學首課，銜接四年級億以下大數概念，向上延伸至兆位。核心概念：
- 億（100,000,000）→ 兆（1,000,000,000,000）的位值結構
- 千進位逗點（1,000）與萬進位分組（10,000）的對照閱讀
- 中文讀法（兆、億、萬、個）與阿拉伯數字的互換

### 1.2 認知核心（Cognitive Core）

| 概念 | 說明 |
|:--|:--|
| **十進位位值系統** | 每十個低位合一個高位（個→十→百→千→萬→十萬→百萬→千萬→億→十億→百億→千億→兆） |
| **中文讀法四位一組** | 中文以「萬、億、兆」每四位分一組，有別於西方三位分逗號 |
| **補零規則** | 中間或末尾缺位須補零，且「兩個以上連續零只讀一個零」 |

### 1.3 迷思概念地圖（Misconception Map）

| 迷思編號 | 迷思描述 | 認知根源 |
|:--|:--|:--|
| M1 | 將「一兆二千萬」補零時，在十億位補錯（補成 1,020,000,000,000 而非 1,000,020,000,000）| 四位分組觀念未內化 |
| M2 | 混淆「千萬」與「十億」的大小（覺得千萬 > 十億）| 中文讀法誤導位階感知 |
| M3 | 在三位逗號系統下誤讀中文大數（如把 1,000,000 讀成「百萬」卻寫成「一兆」）| 中英文數字系統混用 |
| M4 | 補零時漏補中間零（如「三兆零五百」寫成 3,000,000,000,500 漏了中間的億、萬位 0）| 短期記憶負荷過重 |

### 1.4 ZPD 分析（Vygotsky 近側發展區）

- **可獨立完成**：四位以下大數的讀寫（萬位以內）
- **需要鷹架**：億位大數的讀寫（四～八位）
- **現階段挑戰**：兆位大數（十三位）──補零規則複雜度超過工作記憶一般負荷

## 第二部：考點分析與出題守衛點

### 2.1 核心考點

1. **阿拉伯數字 ↔ 中文大數互換**（出題頻率：極高）
2. **補零規則（連續零讀法）**（出題頻率：高）
3. **大小比較**（如「五兆三千億」vs「五兆四百億」）
4. **四位一組的中文讀法拆解**

### 2.2 禁入考點（防混淆）

- 勿與「小數的十進位」混淆（小數在 L4）
- 勿引入乘除運算（本課只考讀寫，不考計算）
