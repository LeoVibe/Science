## 🎯 一、 階段性核心命題目標 (Stage Core Matrix)

四年級下學期的學生正處於**具體運算期邁向抽象**的階段。
- **大數量的處理**：從萬擴展至億、兆，必須建立對國情民生數據的「量感」與「概數估算」。
- **幾何結構的邏輯化**：不再只是認圖形，而是要能探討圖形間的關係（垂直與平行）及面積公式。
- **數的精密化**：小數與分數更進一步（等值分數、二位小數），需要透過更精細的情境（如實驗刻度）來驗證。

|:---:|:---|:---|:---|:---|
| **一億以上的數與概數** | 康 U1 / 翰 U1, U2 / 南 U4 | **實證轉化區 (L3 考古題擷取)**：設計百萬/千萬級距的預估預算題型（無條件進位/捨去決策）。 | 跨越十萬到以兆為單位 | **數位的零漏寫與取位偏誤 (L3 論文擷取)**：四捨五入時取位判斷錯誤，誘答需設計「千位進位但百位忘了歸零」等陷阱。 |
| **四邊形：平行與垂直** | 康 (其他冊) / 翰 U3 / 南 U2 | **實證轉化區 (L3 考古題擷取)**：判斷地圖或幾何圖像中「必定」具備兩組對邊平行的圖形。 | 可用於方格紙判定或給定角度 | **視覺心像僵化 (L3 論文擷取)**：受典型圖形侷限。誘答必須佈設被旋轉後的菱形，或混淆「梯形只有一組平行」。 |
| **多位數乘除與簡化計算** | 康 U3 / 南 U1 | **大規模採購、連鎖店業績**：三位數乘除、結合律/分配律的巧算。 | 乘積/被除數 ≦ 999999 | **零的乘除處理失誤**：末尾有 0 的數相乘忘記將 0 加回，或除法商數中間少補 0。 |
| **分數與等值分數** | 康 U2 / 翰 U5 / 南 U3 | **披薩尺寸對比、調酒配方**：真分數/假分數/帶分數互換，以及等值分數的概念。 | 分母 ≦ 24 | **等值分數大小誤判 (L3 論文擷取)**：不理解 2/4 和 1/2 面積相同，誘答設計為「以為分子/分母數字變大即代表值變大」。 |
| **二位小數** | 康 U5 / 翰 (其他) / 南 U8 | **實證轉化區 (L3 考古題擷取)**：設計田徑計時或匯率差價情境，需作 15.5 - 3.25 這類直式運算。 | 小數兩位以內 | **小數點位值對齊錯亂 (L3 論文擷取)**：直式計算時將「小數字末位強制對齊」而非「小數點對齊」。誘答需精準佈設此錯誤運算值。 |
| **周長面積與體積** | 康 U4 / 翰 U4, U7 / 南 U6, U7 | **實證轉化區 (L3 考古題擷取)**：設計鋪草皮的買方需求情境，需區分需要面積或周長。 | 邊長 ≦ 50 公分或公尺 | **1D與2D度量混淆 (L3 論文擷取)**：學童極易把周長公式誤植於面積題。誘答一定要包含「(長+寬)×2」計算出的陷阱數值。 |
| **統計圖（長條與折線）** | 康 (部分) / 翰 (部分) / 南 U5 | **氣溫紀錄表、股票走勢**：圖表的報讀分析。 | 縱列/橫列資料群不多於 5 組 | **刻度辨識錯誤**：未察覺縱軸單位的省略間距（如一格代表50或省略符號）。 |

## 🛡️ 三、 品質稽核與斷言 (Audit Gateway)
- 本學期的 JSON 生成，若遇「大數」題型，必須測試其「以繁化簡」的需求（要求四捨五入而不是準確到個位）。
- 所有 `explanation` 若涉及圖形（如四邊形性質），必須利用直白的生活比喻（如梯子、鐵軌）加以說明。
