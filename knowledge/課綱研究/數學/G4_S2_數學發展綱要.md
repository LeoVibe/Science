## 🎯 一、 階段性核心命題目標 (Stage Core Matrix)

四年級下學期的學生正處於**具體運算期邁向抽象**的階段。
- **大數量的處理**：從萬擴展至億、兆，必須建立對國情民生數據的「量感」與「概數估算」。
- **幾何結構的邏輯化**：不再只是認圖形，而是要能探討圖形間的關係（垂直與平行）及面積公式。
- **數的精密化**：小數與分數更進一步（等值分數、二位小數），需要透過更精細的情境（如實驗刻度）來驗證。

## 📊 二、 課程內容與發展矩陣 (Curriculum Matrix)

| 核心單元主題 | 對應版本摘要 | 高品質真實情境題材庫 (Scenario Pool) | 數值範圍限制 | 常見迷思與守衛點 (Misconception) |
|:---:|:---|:---|:---|:---|
| **一億以上的數與概數** | 康 U1 / 翰 U1, U2 / 南 U4 | **國家預算、跨國人口統計、企業營收**：大數的讀寫、比較與四捨五入（概數）。 | 跨越十萬到以兆為單位 | **數位的零漏寫**：對「三十萬零五百」直翻出錯；四捨五入時取位判斷錯誤。 |
| **四邊形：平行與垂直** | 康 (其他冊) / 翰 U3 / 南 U2 | **街道地圖規劃、建築結構樑柱**：判斷生活場景中的垂直、平行線段，及構成的四邊形種類。 | 可用於方格紙判定或給定角度 | **垂直等於直立**：誤認垂直線必須是一上一下，不知道斜線交互也能垂直。 |
| **多位數乘除與簡化計算** | 康 U3 / 南 U1 | **大規模採購、連鎖店業績**：三位數乘除、結合律/分配律的巧算。 | 乘積/被除數 ≦ 999999 | **零的乘除處理失誤**：末尾有 0 的數相乘忘記將 0 加回，或除法商數中間少補 0。 |
| **分數與等值分數** | 康 U2 / 翰 U5 / 南 U3 | **披薩尺寸對比、調酒配方**：真分數/假分數/帶分數互換，以及等值分數的概念。 | 分母 ≦ 24 | **等值的分子分母差異盲點**：不理解 2/4 和 1/2 面積相同，以為分子大就比較大。 |
| **二位小數** | 康 U5 / 翰 (其他) / 南 U8 | **田徑計時賽(如秒數差異)、匯率**：小數百分位、小數加減。 | 小數兩位以內 | **小數點未對齊**：直式計算時，錯誤地將小數與整數最後一碼底線對齊。 |
| **周長面積與體積** | 康 U4 / 翰 U4, U7 / 南 U6, U7 | **更換新地毯/鋪草皮、包裝盒選擇**：公式推導。周長與面積（平方公尺），及正/長方體體積（立方公分）概念萌芽。 | 邊長 ≦ 50 公分或公尺 | **不理解平方/立方的意涵**：只死背長乘寬乘高，把線段的單位和面積單位混用。 |
| **統計圖（長條與折線）** | 康 (部分) / 翰 (部分) / 南 U5 | **氣溫紀錄表、股票走勢**：圖表的報讀分析。 | 縱列/橫列資料群不多於 5 組 | **刻度辨識錯誤**：未察覺縱軸單位的省略間距（如一格代表50或省略符號）。 |
