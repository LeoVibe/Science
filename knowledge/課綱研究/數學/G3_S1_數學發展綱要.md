# 📄 G3S1 數學發展綱要 (Grade 3 Semester 1 Math Development Outline)

**檔案定位**：本文件依據《數學共同發展綱要》精神，定義三年級上學期之數學命題規格。
**版本**：v2.0.0 (重構版)
**研究對象**：康軒、翰林、南一 (108 課綱)

---

## 🎯 一、 階段性核心命題目標 (Stage Core Matrix)

三年級上學期的學生正處於奠定**四則運算基礎**與**測量概念**的關鍵期。
- **單位量感建立**：對於「毫米」、「公升/毫升」需要具體的實物參照（如迴紋針長度、寶特瓶容量）。
- **乘除情境辨析**：除法剛導入，需透過生活分裝情境來釐清「包含除」與「等分除」的差異。
- **空間與周長**：理解周邊長度的計量方式，避免機械式記憶公式。

## 📊 二、 課程內容與發展矩陣 (Curriculum Matrix)

| 核心單元類別 | 單元對應 (南一/康軒/翰林) | 高品質真實情境題材庫 (Scenario Pool) | 數值範圍限制 | 常見迷思與守衛點 (Misconception) |
|:---:|:---|:---|:---|:---|
| **萬以內的數** | 康 U1, U2 / 翰 U1, U3 / 南 U1, U2 | **超商採購、過年紅包、銀行存款**：利用錢幣湊數或大宗採購來讀寫四位數，以及四位數的加減法。 | 和/被減數 ≦ 10000 | **位值混淆**：學生常混淆「幾個百」與「百位數字是幾」，或在中間有 0 時（如 1005）直式對齊錯誤。 |
| **長度與容量** | 康 U3 / 翰 U5 / 南 U5 | **製作書籤、水壺裝水**：測量迴紋針、課本厚度（毫米），或分裝果汁（公升與毫升的換算）。 | 毫米整數轉公分；容量單次不超過 5 公升 | **單位未隨之進退位**：1cm = 10mm 或是 1L = 1000mL 換算錯誤，導致小數或補零失誤。 |
| **乘法與除法** | 康 U5 / 翰 U4, U6 / 南 U3, U6 | **分糖果、教室排座位、買文具**：強調單位量與單位數的概念。包含除（每4個裝一盒）與等分除（均分給4人）。 | 乘數一位；被除數二位以內，除數一位 | **餘數觀念薄弱**：直式計算中，不知餘數絕對不能大於除數，或不知道除法中「0」佔位的意義。 |
| **周長與圓/角** | 康 U4 / 翰 U2, U8 / 南 U4, U9, U10 | **設計花圃圍欄、畫圓形靶版**：利用實際圍物體的周長計算，與圓規畫出圓形來認識半徑與直徑。 | 邊長數值 ≦ 50 | **周界與周長混淆**：誤以為算周長要把內部線段也加進去；測量角的大小時，誤以為「邊越長角越大」。 |
| **分數初步** | 康 (部分未列) / 翰 U7 / 南 U8 | **分披薩、切蛋糕**：初步認識單位分數，與真分數的讀寫。 | 分母 ≦ 12 | **等分概念缺失**：將未「等分」的圖案也視為可以寫成分數的分母。 |

## 🛡️ 三、 品質稽核與斷言 (Audit Gateway)
- 所有考題不得僅提供算式（如 `求 1050 + 2038 = ?`），必須包裝為生活情境。
- 空間與幾何題目的 JSON `scenario`，必須引導學生去想像或畫出具體圖形，而不僅是套用周長公式。
