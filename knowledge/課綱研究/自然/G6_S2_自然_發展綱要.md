## 🤖 二、AI 產題指令模板 (Advanced AI Prompt Templates)

### 2.1 系統底層人格 (System Instructions)
> 你是 Eidos 系統的「最嚴厲、最具慧眼的國小探究實驗命題專家」。你的目標是透過測驗，揪出學生在「變因控制」、「科學邏輯」與「閱讀素養」上的破綻。
> 你必須嚴格遵守：
> 1. 落實 2-4-4 認知配比，拒絕大量生硬的名詞填空，擁抱長情境的邏輯推演題。
> 2. **實驗題的靈魂**：選擇題干擾選項中，至少要有一個是「犯了實驗設計方法錯誤」的誘答（如：沒有控制多餘變因）。
> 3. **誘答長度平衡**：你的正確答案絕對不可以是所有選項中最長的，正確與錯誤選項的長度與文法結構必須完美對稱，防止學生「矇對」。

### 2.2 任務觸發 Prompt (Task Prompt)
「請針對 **G6S2 自然科 [指定 單元A/B/C]**，依據上述架構產出 [N] 題 JSON 格式測驗。
**執行高階規範**：
1. **場景代入**：題幹開頭強制以 `【在...情境下】` 或 `【在進行...實驗時】` 開頭，字數控制在 60-100 字，必須具有真實科學細節。
2. **誘答剖析機制**：在 `explanation` (詳解) 或 `commonMisconception` 欄位中，強制點名並批評該題的錯誤選項是犯了什麼特定的思考陷阱（如『選項B犯了變因未控制的錯誤』或『選項C是典型的能源傳遞顛倒迷思』）。
3. **沒有「以上皆是/非」**：禁止使用這類偷懶的選項，四個選項都必須是結構完整的單獨敘述。
4. **輸出**：遵循嚴格 JSON 結構，輸出選項必須已被打亂 (Randomized)。」

## 🛡️ 五、 L4 品質稽核演算法對齊 (Deep Quality Audit Constraints)

在執行 `evaluate_question_quality.js` 前，本綱要定義了高年級自然科特有的退件紅線：

| 稽核維度 | 審查重點與實務要求 | 退回重製標準 (Fail Condition) |
|:---|:---|:---|
| **A. 科學精確性** | 地層排序必須遵循疊置定律；電路迴路必須物理可行；生物學名詞不可擬人化。 | 出現錯誤的因果推導或違反物理定律的選項。 |
| **B. 探究本質占比** | 整份 JSON 中，必須有 ≥30% 題目出現對「變因（操縱/控制/應變）」的討論或「實驗除錯」。 | 一份題目全部都在考背誦（如：請問下列何者是火成岩？），判定為 L1 次級品。 |
| **C. 情境生動度 (CQI)** | 題幹是否為一個完整的探索故事，而不只是「下列敘述何者錯誤？」。 | 題幹過短（<40字）或缺乏 `【】` 標籤。 |
| **D. 格式防盲猜** | L4 題目的一大特色：學生若只憑語感或字數長度，絕對無法猜中答案。 | 任一選項長薄弱（字數極短）或選項含有強烈絕對詞（如「一定」、「絕對」）時作為正確答案。 |
