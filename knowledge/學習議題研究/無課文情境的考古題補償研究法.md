## 摘要 (Abstract)

Eidos 題庫研發的標準路徑要求每課具備「KL4 單課研究紀錄（含課文）+ 考古題與討論」雙檔基礎。然而實務上，因**出版社授權、實體課本翻拍限制、電子書版權、個別課本流通範圍**等因素，**不是每一課都能取得原文**。若一律以「無課文 → QL2 天花板」處理，會導致該課的題目不只研究深度標籤降級，連**實質題目品質**也難以維持，甚至被迫放棄該課出題。

本研究提出**β+ 補償路徑**，主張將「無課文情境」視為**特定工作流程**而非「研究失敗」。核心精神是：**資訊層標籤誠實（QL 分級不虛報），但品質層透過補償方法保持不打折**。研究者透過「考古題加量蒐集 + 反推深度強化 + 雙重盲測 + 回測驗證」四支柱，讓 β+ 路徑的題目實質品質接近 α 標準路徑（QL4）的水準。

本報告以 2026-04-21 完成的 G3 S2 社會 南一 L5「打造幸福的家園」為啟動案例，驗證本方法的可執行性與產出品質（30 題、CQI 9.19、Match 100%）。

## 第一章：研究背景與問題定位

### 1.1 為何課文原文不一定能取得

1. **版權限制**：南一、康軒、翰林三大出版社的課本原文受著作權保護，教師版僅提供註冊教師，一般 AI 開發者無存取。
2. **數位化落差**：部分版本有電子書，但公開瀏覽頁僅顯示目錄與單元標題，不提供內文。
3. **實體流通**：實體課本需透過家長、老師、學校等管道取得翻拍，**並非所有課都能確保覆蓋**。
4. **新課綱快速更新**：課本版本一年一改，去年的課文不等於今年的課文，長期依賴實體翻拍難以持久維護。

### 1.2 傳統做法的三種侷限

| 做法 | 缺點 |
|:--|:--|
| 堅持有課文才出題 | 大量課次被「禁止出題」，學生看到「尚無題庫」——前台體驗不佳 |
| 無視課文直接出題 | 極易超綱（出題範圍超出該年級教學），或與課本用詞脫節 |
| 自編「課文大綱」充當原文 | 違反 KL4 真實性原則，且研究者偏見直接嵌入題目，風險高 |

### 1.3 補償路徑的誕生

β+ 補償路徑的核心假設：

> 雖然沒有課文原文，但**整學期學生被考過的題目**（真實段考卷）**本身就是課本教學內容的實證投影**。教學內容 → 考卷題目 是一個「訊息壓縮」過程；反過來從大量考題**反推**課本教學重點，雖有訊息損失，但在樣本數夠大時，**足以支撐不超綱、不偏題**的出題。

這不是「編出課文」，而是**承認沒課文但用外部實證建立教學範圍的輪廓**。

## 第二章：補償路徑的理論基礎

### 2.1 A 方法 vs BCDE 方法的分工

本研究區分兩個層面：

| 層面 | 目的 | 代表 |
|:--|:--|:--|
| **A 方法**（資訊程度說明） | 誠實反映**研究深度** | KL1-KL4、RM0-RM3、QL1-QL5 分級 |
| **BCDE 方法**（出題品質強化） | 讓**實作層**的題目品質不受資訊層級限制 | B/C/D/E 四支柱（下一章） |

此分工的意義在於：**標籤**（A 方法）可以誠實說「這課研究只到 QL3」，**但題目**（BCDE 方法）可以透過補償手段達到接近 QL4 的實用水準。這避免了「為了撐 QL4 而造假原文」的道德風險。

### 2.2 為何考古題補償能替代課文

從認知心理學角度：

- **課文**是教師傳遞給學生的**標準範本**。
- **考古題**是教師檢驗學生是否內化課文的**反向鏡像**。
- 大量的考古題**涵蓋了該課教學焦點、常見迷思、誘答陷阱**——這些正是命題者最需要的知識。
- 在缺課文時，考古題提供的**知識點分佈**與**誘答結構**可作為出題的參考座標。

### 2.3 量與質的補償關係

| α 標準路徑 | β+ 補償路徑 |
|:--|:--|
| ≥ 10 道考古題 + ≥ 2 來源 | **15 分鐘努力上限，多多益善** |
| 品質來自課文 + 考古題對照 | 品質來自考古題數量覆蓋 + 多角度反推 |
| 1 次盲測 | **2 次不同模型盲測** |
| 人工審查選配 | **每題對照 ≥ 3 道類似考古題回測強制** |

**核心不變量**：出題前必須累積足夠的「外部訊息」讓命題者的偏見被稀釋——在 α 這由課文 + 考古題雙重提供，在 β+ 由考古題加量 + 雙盲測 + 回測提供。

## 第三章：β+ 補償路徑的四支柱（BCDE 方法）

### 支柱 B：考古題補償（努力上限 15 分鐘）

**不設題目數量底線，設時間/努力上限。**

操作規範：
- 每課研究時**最多投入 15 分鐘**蒐集考古題（含下載 + 萃取 + 篩選 + 分類）
- 15 分鐘到，手上有多少題就寫進 KL4，多不限、少則標註「已盡力 N 分鐘，取得 M 題」
- 警戒值 ≥ 10 道：若低於此值，**標註「資源嚴重不足」** 並列為高優先重抓項
- 蒐集範圍：**整學期所有考試類型**（期中、期末、3 次段考），反推到本課的題目

**為何用「時間」而非「題數」**：
- 避免為湊數放進不相關題目
- 真實資源分佈不均：有些課在段考中出現頻繁（高頻核心），有些罕見（邊緣單元）
- 時間上限確保每課研究投入成本可控，不失控陷入「永遠湊不滿 20 題」的陷阱

### 支柱 C：反推深度強化（三欄矩陣）

每道考古題除基本誘答分析外，補充三欄：

| 欄位 | 內容 |
|:--|:--|
| 知識點對應 | 本題測的是本課哪個具體概念？（對不到即標 ambiguous） |
| 出現頻率 | 同一知識點在本學期收集的考古題裡出現幾次？（高頻 = 核心必考點） |
| 學生常錯點 | 從答案卷對照反推，學生最常誤選哪個誘答？為什麼？ |

進一步建立「**主題 × 年度 × 學校**」交叉矩陣：
```
             | 108 學年 | 109 學年 | 110 學年 | 111 學年 |
社區發展協會 |   3       |   2       |   4       |   1       |
里民大會    |   2       |   3       |   2       |   2       |
探究流程    |   0       |   1       |   3       |   2       |  ← 新興主題
```

此矩陣揭示：**哪些知識點跨年一直考**（= 穩定核心），**哪些是近年才強調**（= 新課綱重點），**哪些從考古題消失了**（= 淡出）。

### 支柱 D：雙重盲測（2 不同模型）

- 標準路徑：1 次（Gemini Flash-Lite）
- β+ 補償：**2 次不同來源的模型**，例：
  - 第 1 次：Gemini Flash / Flash-Lite（免費額度，量大測試）
  - 第 2 次：Claude Haiku 4.5 / GPT-4o-mini（跨家族驗證）
- **兩次都 Match 才算通過**；若只 1 次通過需標「邊緣題目」，上架需人工審核
- 用意：排除「只在某一家模型推理路徑下成立」的題目，提升普適性

### 支柱 E：回測驗證（≥ 3 題對照）

出題完成後，從考古題庫中抽取 ≥ 3 道**主題最相近**的真實段考題，與新出題目逐一對照：

| 對照維度 | 檢驗問題 |
|:--|:--|
| 主題覆蓋 | 新題的核心概念是否出現在考古題中？ |
| 難度風格 | 題幹長度、句型複雜度是否與段考相當？ |
| 誘答設計 | 誘答選項的陷阱邏輯是否與段考一致（符合該年級學生會犯的錯）？ |
| 情境寫實 | 題幹情境是否貼近該年級生活經驗，不抽象化？ |

**不一致時回頭重出該題。**

## 第四章：實作 SOP（階段一：研究）

### 步驟 1：確認課次是否走 β+ 路徑

- 查 `knowledge/課綱研究/[科目]/[學期]/[版本]/` 下是否有 `_單課研究紀錄` 檔且含課文
- 若無，進入 β+ 路徑（記錄於 JOB 派工單）

### 步驟 2：啟動計時器（15 分鐘）

研究時間總計 15 分鐘（可分數次累計，總時數不超過）。

### 步驟 3：查詢考古題來源

查 `knowledge/考古/_manifest/pdf_manifest_G1_G6.json` 取得對應科目的 Drive 清單。

### 步驟 4：批次下載 PDF（限速）

```bash
~/Library/Python/3.11/bin/gdown --folder <DRIVE_URL>
```
每 Drive 間 sleep 10s，每批 3 個 Drive 休 5 分鐘（避 Google rate-limit）。

### 步驟 5：萃取為 JSON

```python
import pdfplumber, json
# 見 scripts/ 內現有萃取腳本
```

**保留原 PDF** 於 `knowledge/考古/原始/` 永久保存（依新 Rule 7），萃取 MD 到 `knowledge/考古/淬煉/`，兩軌並存。

### 步驟 6：關鍵字篩選本課題目

用 Python 腳本從所有 JSON 中搜尋本課核心詞彙（依 KL3 發展綱要提示）。

### 步驟 7：填寫 KL4 考古題與討論檔

- 每題標明學校 + 學年度 + 考試類型
- 加「知識點對應 / 出現頻率 / 學生常錯點」三欄

### 步驟 8：填寫 KL4 單課研究紀錄檔

- 跳過「課文全文錄製」
- 寫「課文主要概念（β+ 推測版）」：基於發展綱要 + 素材庫 + 考古題反推
- 明確標註「非出版社原文」

### 步驟 9：標記研究成熟度 RM3(β+)

檔案 meta 處標注：
```yaml
research_maturity: RM3(β+)
has_original_textbook: false
compensation_method: 考古題反推 + 發展綱要對照
```

### 步驟 10：時間到，停

15 分鐘到即停（不論結果）。手上有多少資料就呈交多少，未完成部分列「後續重訪清單」。

## 第八章：品質保證與智財保護機制

### 8.1 考古題原檔目錄 gitignore

- 整個 `knowledge/考古/` 列入 `.gitignore`，不進 GitHub
- 原因：尊重學校段考卷作者權，僅供本機內部研究分析

### 8.2 PDF 生命週期

1. **下載**：gdown → 本機 `knowledge/考古/[年級]/[科目]/[版本]/[考試類型]/*.pdf`
2. **萃取**：pdfplumber → `extracted/*.json`（結構化文字 + metadata）
3. **保留 PDF**：依新規範 §一 Rule 7（2026-04-21 修訂），原檔永久保存於 `knowledge/考古/原始/`
4. **長期保存**：僅 JSON 或 MD（結構化格式）

### 8.3 記錄責任鏈

每份萃取的 JSON 必含：
```json
{
  "source_school": "彰化縣永光國小",
  "academic_year": "108 學年度下學期",
  "exam_type": "第三次段考",
```

## 第九章：常見疑問 (FAQ)

### Q1：β+ 路徑出的題會不會品質實際上較差？

不一定。本案 L5 在 β+ 路徑下 CQI-P 達 9.19、Match 100%，實際品質與 α 路徑的頂標課程相當。**關鍵不是「是否有課文」，而是「是否有足夠多元的外部實證反推」**。

### Q2：如果 15 分鐘內完全找不到考古題怎辦？

標 RM1(β+) 不繼續往下。該課**禁止出題**，列入高優先重訪清單（等使用者下次有時間再找其他管道）。

### Q3：β+ 題目上架後可以「假裝 QL4」嗎？

**絕對不行**。標籤誠實是本方法的基石。若虛報，使用者/家長/老師看到的題庫品質分佈會失真，違反 Eidos 的品質透明原則。

### Q4：通過雙盲測但回測失敗怎辦？

重出該題。回測是最終防線，因為盲測的 LLM 可能剛好跟出題者陷入同樣的推理陷阱；真實段考題是**獨立的第三方證據**，比 LLM 判斷更接近「學生會怎麼想」。
