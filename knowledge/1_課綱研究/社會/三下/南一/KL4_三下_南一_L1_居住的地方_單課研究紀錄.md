## §一 課綱連結與學習總目標

### 1.1 課綱連結

| 類型 | code | 本課對應 | 守衛點 |
|:--|:--|:--|:--|
| 學習表現 | **1a-II-1** | 辨識居住地方的都市/鄉村、早期/現代、自然與人文環境特性。 | 不把都市/鄉村做成優劣判斷；重點是環境特徵與居民活動。 |
| 學習表現 | **1b-II-1** | 對居住地方的老建築、地名、環境變遷與生活型態提出疑問。 | L1 可作為 L4 地名故事的前導，但不應把 L4 個例背誦提前塞滿。 |
| 學習表現 | **2a-II-1** | 感受居住地方的生活特色，能說出自己與地方環境的連結。 | 避免只背地圖名詞，需回到「我如何認識居住地方」。 |
| 學習表現 | **2b-II-2** | 了解居民對地方發展可能有不同看法，並以尊重態度訪談或聆聽。 | 不把「每個居民看法一致」當成社區常態。 |
| 學習表現 | **3a-II-1** | 透過觀察、地圖判讀、地址查詢、訪談與資料蒐集認識居住地方。 | 訪談不是聊天；需事先約定、準備問題、認真傾聽與記錄。 |
| 學習內容 | **Aa-II-1** | 居住地方的環境特性與居民活動，如都市、鄉村、海邊、平原、山區生活差異。 | 分類軸要清楚：人口密集度不等於地形位置。 |
| 學習內容 | **Ab-II-1** | 居住地方的人文與自然環境特色，如建築、道路、商店、古蹟、自然資源。 | 自然/人文特色不只影響工作，也會影響生活、休閒、文化與認同。 |
| 學習內容 | **Dc-II-1** | 地名由來、地方故事與文化資產的初步認識，尤其是老建築與導覽地圖。 | 本課只處理「如何認識」，深度故事歸 L4 延伸。 |

### 1.2 單課學習總目標

學生完成本課後，應能：

1. 說明「居住的地方」不只等於住家，而是包含鄰近街道、商店、公共設施、自然環境、老建築與居民活動的生活範圍。
2. 比較都市與鄉村常見特徵，如人口密度、商店種類、交通便利性、生活步調、居民互動方式，並避免以「進步/落後」評價地方。
3. 比較早期與現代居住環境的差異，如道路材質、建築型態、商店分布、交通工具與生活便利性。
4. 依任務選擇合適的地圖或工具：行政區域圖、街道圖、古蹟導覽地圖、電子地圖、實景或導航功能。
5. 讀懂地圖的圖名、方向標、圖例與符號，能用地圖輔助認識地方。
6. 知道門牌、地址資料與郵件等可協助定位居住地方，但教學與出題須避免要求學生公開完整個資。
7. 能以觀察、訪談、查資料等方式蒐集地方資訊，並尊重受訪者時間與不同意見。

### 1.3 課程定位

南一 L1 是三下社會「從個人生活走向家鄉與社區」的入口課。考古題顯示，本課不是單純背地圖名詞，而是建立三組基礎能力：

1. **環境辨識**：都市/鄉村、早期/現代、自然/人文環境。
2. **工具使用**：地圖種類、圖例、方向標、電子地圖與地址資訊。
3. **探究態度**：觀察與訪談地方居民，承認地方有多元觀點。

## §二 核心知識點地圖

### 2.1 本課主要概念拆解

| 核心知識點 | 正確概念 | 考古題反推依據 | 守衛點 |
|:--|:--|:--|:--|
| 居住地方的生活範圍 | 居住地方包含住家周邊的街道、商店、公共設施、自然景觀、歷史建築與居民活動。 | L1 題組常把地圖、古蹟、訪談、地方特色放在同一課考。 | 不把「居住的地方」縮小成住址或房屋本身。 |
| 都市環境特色 | 都市通常人口密集、商店種類多、交通與服務便利，生活步調較快。 | 代表題：都市商店多、購物方便；錯誤選項常寫「生活步調緩慢」。 | 都市不是絕對比較好；只判斷特徵，不做價值排序。 |
| 鄉村環境特色 | 鄉村人口較少、空間較開闊，居民往來可能較頻繁，感情較深厚。 | 田中 108 是非題支持「和都市相比，鄉村居民往來較頻繁」。 | 不把鄉村等同落後，也不把居民互動寫成一律疏離。 |
| 早期與現代生活比較 | 早期道路、建築、商店型態與交通工具通常不同於現代；現代化設施不能套回早期小村落。 | 廣興 109 題以「海邊早期小村落道路皆為柏油路」作錯誤描述。 | 時代軸要清楚：早期/現代不可互相套用。 |
| 地圖種類與功能 | 行政區域圖找縣市鄉鎮區；街道圖找街路位置；古蹟導覽地圖找老建築；電子地圖可查路線與導航。 | 南一 L1 報告標示「地圖功能辨別」高頻，代表題含古蹟導覽地圖、電子地圖規劃路線。 | 依任務選地圖，不可把所有地圖功能混在一起。 |
| 地圖基本讀法 | 圖名說明主題；圖例解釋符號；方向標協助辨別方向，地圖上方通常為北方且標示 N。 | 中正 112 題考「上方通常北邊，標 S」為錯；廣興 109 題考圖例。 | N/S 易混；「圖例」不可誤稱圖說、圖格。 |
| 地址與門牌資訊 | 門牌、地址、郵件或戶籍相關資料可協助確認居住地方位置與行政區。 | L1 出題方向列「居住地址查詢」為中頻，代表題數 6+。 | 不要求學生公開完整住址；出題宜用學校或虛擬地址。 |
| 觀察居住環境 | 可透過實地觀察、照片、地圖、訪談與資料查詢認識地方。 | L1 出題方向列「觀察居住環境的工具與方法」為中頻。 | 不能只憑單次印象下結論；要能說明觀察工具與目的。 |
| 訪談地方居民 | 訪談需事先約定、準備問題、禮貌提問、認真傾聽與記錄。 | 廣興 109 題考訪談地方居民的適當表現，正解指向認真傾聽。 | 熟人也需尊重時間與同意；訪談不是隨意拜訪。 |
| 地方觀點多元 | 居民可能因職業、年齡、居住時間與需求不同，對地方發展有不同想法。 | L1 迷思矩陣列「每個居民對社區發展看法都一樣」。 | 不能把社區想成沒有衝突或只有單一答案。 |
| 地方特色與老建築初探 | 老建築、古蹟、自然景觀與地方資源可作為認識地方的入口。 | L1 代表題含「想觀賞地方老建築，哪種地圖最詳盡」。 | L1 重點是工具與觀察；深入地名故事、文化資產保存交由 L4 延伸。 |

### 2.2 守衛點總表

| 守衛點 | 常見錯誤 | 教學與命題檢核 |
|:--|:--|:--|
| 分類軸清楚 | 把人口密集度分類寫成海邊、平原、山區。 | 人口密集度對應都市/鄉村；地形位置對應海邊、平原、山區。 |
| 時代軸清楚 | 把柏油路、水泥大樓、現代商店套到早期小村落。 | 題幹要標明早期/現代，選項須能測出時空混淆。 |
| 城鄉不做優劣化 | 都市一定繁榮、鄉村一定落後或感情淡。 | 使用「通常、常見」描述特徵，避免絕對化。 |
| 地圖功能不混搭 | 用古蹟導覽地圖查最短路線，或用電子地圖找古蹟解說細節。 | 題目要先給任務，再要求選工具。 |
| 地圖符號精準 | 圖例誤稱圖說、方向標 N/S 反置。 | 每張圖題需檢查圖名、方向標、圖例是否可判斷。 |
| 訪談倫理 | 熟人不必預約、可直接拜訪、只問自己想聽的答案。 | 正解需包含事先聯絡、禮貌、傾聽、記錄與尊重不同意見。 |
| 個資保護 | 要學生寫出或公開完整住址。 | 改用學校地址、虛擬地址或局部地址資料。 |
| 跨課邊界 | 把 L4 地名故事、L2 資源分類大量拉回 L1。 | L1 可暖身認識方法，深度分類與人物故事需留給後課。 |

## §三 探究活動與生活連結

### 3.1 居住地方觀察任務

以學校周邊或虛擬社區作為觀察場域，讓學生記錄道路、商店、公園、廟宇、老建築、自然景觀、交通狀況與居民活動。學生需標明「我看到什麼」與「我推測什麼」，避免把個人感覺直接當成結論。

**守衛點**：觀察表至少區分「事實紀錄」與「個人感受」；不要讓學生只寫「很熱鬧」「很無聊」。

### 3.2 地圖任務站

提供行政區域圖、街道圖、古蹟導覽地圖與電子地圖截圖，設定任務：

| 任務 | 合適工具 | 判斷理由 |
|:--|:--|:--|
| 找出某縣市或鄉鎮區的位置 | 行政區域圖 | 呈現行政區界線與名稱。 |
| 找學校到圖書館的街路位置 | 街道圖 / 電子地圖 | 呈現道路與路線。 |
| 想參觀地方老建築 | 古蹟導覽地圖 | 以古蹟、老建築與導覽資訊為主。 |
| 從住家到公園選一條路線 | 電子地圖導航 | 可設定出發地、目的地並規劃路線。 |

**守衛點**：任務與工具要一一對應；不能只問「哪種地圖最好」而不給使用目的。

### 3.3 早期與現代地方變遷訪談

訪問長輩、店家或社區居民，了解道路、建築、交通、商店與生活習慣的變化。訪談前需先約定時間、準備問題；訪談中要認真聽、適當追問並記錄；訪談後整理「相同處、不同處、我還想知道的問題」。

**守衛點**：熟人訪談也要尊重隱私與時間；不可把受訪者的一句話當成全社區共同意見。

### 3.4 都市與鄉村比較

使用兩張情境圖或短文，讓學生比較人口密度、建築型態、商店種類、交通便利性、居民互動與生活步調。重點是建立「特徵比較」能力，不是判斷哪一種生活比較高級。

**守衛點**：都市、鄉村都有優點與限制；題目若用「一定、全部、都」通常容易造成錯誤或刻板印象。

### 3.5 地方小導覽設計

學生選一個地方特色點，如老建築、公園、市場、溪流、廟宇或老街，設計一張簡易導覽卡。導覽卡需包含位置、可用地圖、觀察到的特色、想問居民的問題。

**守衛點**：本活動銜接 L4，但 L1 只要求「用工具與方法認識地方」，不要求背完整地名由來或歷史人物事蹟。

## §四 迷思分析

| # | 迷思描述 | 來源反推 | 正確觀念 | 守衛點 |
|:--:|:--|:--|:--|:--|
| M1 | 都市生活步調緩慢，像鄉村一樣悠閒。 | 南一 L1 代表題 L1-02；KL3 版本特色迷思 H6。 | 都市通常人口密集、商店多、交通便利，生活步調較快。 | 比較「通常特徵」，不要把生活感受絕對化。 |
| M2 | 鄉村居民往來少、感情淡。 | 南一 L1 迷思 M1-07；KL3 共通迷思 C8。 | 鄉村人口較少，但居民往來可能更頻繁、互動較緊密。 | 城鄉比較不可用單一刻板印象判斷。 |
| M3 | 早期村落已有大量柏油路、水泥大樓與現代商店。 | 南一 L1 代表題 L1-03；迷思 M1-02。 | 早期與現代在道路、建築、交通、商業型態上常有差異。 | 題幹標明時代，選項檢查是否混入錯誤時代特徵。 |
| M4 | 居住環境依人口密集度可分為海邊、平原、山區。 | 中正 112 代表題 L1-07。 | 人口密集度可連到都市/鄉村；海邊、平原、山區是地形或位置分類。 | 出題時要明確問「人口密集度」或「地形位置」。 |
| M5 | 地圖上方通常是南邊，標示為 S。 | 中正 112 代表題 L1-08；南一 L1 誘答機制。 | 地圖上方通常指北方，方向標以 N 表示北。 | N/S 是固定誘答點，需搭配方向標圖像或文字情境。 |
| M6 | 圖例就是圖說、圖格，或只是裝飾。 | 廣興 109 代表題 L1-05。 | 圖例是解釋地圖符號代表哪些實際地點或事物的工具。 | 需讓學生用圖例判斷符號，而非只背名詞。 |
| M7 | 所有地圖功能差不多，用哪一種都能完成任務。 | 南一 L1 出題方向：地圖功能辨別 15+ 題。 | 不同地圖有不同用途；電子地圖可導航，古蹟導覽地圖適合找老建築資訊。 | 先給任務，再選地圖；避免無任務的空泛選擇。 |
| M8 | 訪談熟人不需要事先聯絡，也不必特別傾聽。 | 廣興 109 代表題 L1-12；KL3 版本特色迷思 H7。 | 訪談需事先約定、準備問題、禮貌提問、認真傾聽與記錄。 | 熟悉關係不等於免除訪談禮節。 |
| M9 | 社區居民對地方發展的看法都一樣。 | 南一 L1 迷思 M1-04。 | 居民會因年齡、職業、需求、居住時間不同而有不同觀點。 | 訪談題應鼓勵多方資料，不只採一位受訪者意見。 |
| M10 | 地方自然或人文資源只影響工作，沒有其他功能。 | 南一 L1 迷思 M1-03；KL3 補強候選「自然/人文資源功能單一化」。 | 地方資源也影響休閒、觀光、文化、生活方式與地方認同。 | 若在 L1 出現，應連到環境觀察與居民活動，不要過度轉成 L2 資源分類題。 |
| M11 | 老建築沒有現代用途，所以不需要特別認識。 | L1 地圖題與 L4 文化資產題的跨課趨勢。 | 老建築可承載地方記憶，認識它需要合適地圖、觀察與訪談。 | L1 不要求保存論證，但要避免把老舊直接等同無價值。 |
