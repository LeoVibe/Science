### 1.2 單課學習總目標

學生完成本課後，應能：

1. 說明消費是以金錢、卡片、電子工具或其他資源取得物品與服務的行為，消費不等於浪費。
2. 分辨「需要」與「想要」：需要是維持生活或解決實際問題的必要項目，想要是個人偏好、流行、炫耀或非必要升級。
3. 在購買前確認需求、蒐集商品資訊、比較價格與品質、閱讀標示，並避免被炫耀、流行或衝動影響。
4. 說明記帳可以記錄收入、支出、消費項目與餘額，幫助掌握消費情形；地點不是南一考古題中的必要記帳項目。
5. 說明儲蓄不是「不需要花錢」，而是為未來需要、較大支出或目標預先累積資源。
6. 分辨可儲蓄與通常應支出的金錢，如紅包、零用錢結餘可規劃儲蓄；看病、三餐、學用品等基本需求通常應優先支出。
7. 依時間順序理解交易工具演進：以物易物 → 貝殼或實物媒介 → 金屬貨幣 → 紙鈔 → 信用卡、儲值卡等塑膠貨幣。
8. 分辨儲值卡與信用卡：悠遊卡等儲值卡通常先儲值後扣款；信用卡則是先消費後付款。
9. 說明統一發票是購物證明，可對獎、協助防止逃漏稅；電子發票也會記錄發票號碼、交易日期、消費金額等資訊。
10. 辨識綠色消費：選擇對環境傷害較少、包裝較少、可回收或具環保標章的商品，而不是買綠色外觀或外國進口商品。
11. 遇到消費糾紛時，能保留購物證明、理性溝通、請大人協助，必要時撥打消費者服務專線 **1950**，並區分 1999、1922、110、119 等不同用途。
12. 在生活情境中建立「有限金錢、延後滿足、資訊判斷、環境責任、消費權益」的初階理財素養。

### 1.3 課程定位

南一 L3 是三年級下學期的消費理財集中課。相較康軒分為 L3「消費與生活」與 L4「消費與選擇」，以及翰林集中在 L5「儲蓄與消費的選擇」，南一以 L3 一課同時承載交易工具、理性消費、記帳、儲蓄、綠色消費、發票與消費者保護。

考古題顯示本課約 50～70 題、6 校，已達實證門檻。題型不是單純背理財名詞，而是穩定測三組能力：

1. **選擇判斷**：需要/想要、消費步驟、比價、商品資訊、衝動與炫耀誘因。
2. **金錢管理**：記帳欄位、收支與餘額、儲蓄目標、大額支出規劃。
3. **制度識讀**：交易工具演進、儲值卡與信用卡、統一發票、1950、綠色消費與環保標章。

## §二 核心知識點地圖

### 2.1 本課主要概念拆解

| 核心知識點 | 正確概念 | 考古題反推依據 | 守衛點 |
|:--|:--|:--|:--|
| 消費的意義 | 消費是取得物品或服務的行為，可能用現金、卡片、儲值卡、發票與網路交易等工具。 | L3 題目涵蓋實體商店、電視購物臺、網路商店、付款工具。 | 消費不等於浪費；浪費是未評估需求或資源就購買。 |
| 金錢有限 | 每個人能運用的金錢有限，必須在需要、想要、儲蓄與未來支出間安排。 | KL3 稽核要求消費題需含預算限制或需要/想要對比。 | 不出空泛「要節儉」題；需有可判斷的資源限制。 |
| 需要 vs 想要 | 需要是生活、健康、學習或安全的必要項目；想要是偏好、流行、炫耀或非必要升級。 | 南一報告列為極高頻，代表題 20+。 | 書包壞了需要處理，但指定「想要圖案的新書包」含偏好成分，題幹需細讀。 |
| 聰明消費步驟 | 購買前先確認需求、蒐集資訊、比價、檢查標示與評估環境影響，購買後可記錄消費。 | L3-06、L3-07；勝利 111 期中固定考「是否可以炫耀」與「多做比價」。 | 「是否可以炫耀」不是必要考量；「想買就買」不是謹慎消費。 |
| 商品資訊判斷 | 價格、功能、品質、保存期限、商品外觀、環保標章等可作為判斷資訊。 | 大園 108 第二次、勝利 111 期中均考商品資訊。 | 價格高不代表品質最好；需要閱讀資訊與比較。 |
| 記帳功能 | 記帳能記錄收入、支出、消費項目與餘額，掌握自己的消費情形。 | L3-03、L3-09、田中 108 第二次記帳大檢驗。 | 記帳不是只為了算錢；也能回顧消費是否合理。 |
| 記帳欄位 | 南一考古題核心欄位為收入、支出、餘額、項目或消費金額；地點不是必要欄位。 | L3-09：記帳時不用記錄「地點」。 | 不把「越詳細越好」當正解；應看是否能管理收支。 |
| 儲蓄目的 | 儲蓄是把可安排的金錢留下來，以備未來需要、大額支出或目標。 | L3-05、L3-08、大園 108 第二次儲蓄敘述題。 | 儲蓄不是否定所有消費，也不是「克制欲望所以不需要儲蓄」。 |
| 可儲蓄金錢 | 紅包、零用錢結餘、獎金等較可規劃為儲蓄；基本生活與學習必要支出需優先保留。 | L3-08：過年紅包可儲蓄；看病費、三餐、參考書非同類。 | 不把所有手上的錢都拿去儲蓄，也不把所有錢都花光。 |
| 大額支出規劃 | 想買價格高的物品時，需延後、儲蓄、比價或調整目標。 | 勝利 111 期中問購買汽車通常需動用哪筆金錢；大園 108 第二次考大額支出。 | 不使用「機會成本」術語硬考三年級學生，用生活取捨承載概念。 |
| 交易工具演進 | 交易從以物易物，逐步發展到貝殼、金屬貨幣、紙鈔、信用卡或儲值卡等工具。 | L3-10；田中、成功、大園、永光 108 均出排序。 | 排序不能把銅幣放在貝殼前，也不能把信用卡放在紙鈔前。 |
| 以物易物 | 早期直接用物品交換物品，但價值難估算、需求不一定互相符合。 | 永光 108 第二次考貨幣取代以物易物原因。 | 不把以物易物當現代最常見交易方式。 |
| 貝殼與金屬貨幣 | 貝殼是教材中早期媒介代表；金屬貨幣在其後出現，常以銅幣或貴重金屬表述。 | 大園 108 第二次考「現代人常用貝殼購物」與「金屬貨幣出現時間」。 | 貝殼不是現代常用貨幣；金屬貨幣不是最早交易方式。 |
| 紙鈔 | 紙鈔比金元寶、銅錢、貝殼等更便於攜帶，是貨幣演進的重要階段。 | 大園 108 第二次問哪種貨幣攜帶最方便。 | 便利性不是唯一判斷，但三年級題型常用「攜帶方便」理解紙鈔。 |
| 儲值卡 | 悠遊卡等塑膠貨幣需先儲值，再依使用金額扣款，可用於交通或便利商店。 | L3-01；田中 108 第二次。 | 儲值卡與信用卡付款順序不同，不可混同。 |
| 信用卡 | 信用卡常見特性是先消費後付款。 | KL3 共通迷思 C3，南一 L3 承擔。 | 不把信用卡誤認為現場同時付現金或先儲值。 |
| 統一發票 | 統一發票是購物證明，可對獎、退換貨佐證，也能避免店家逃漏稅。 | 永光 108 第二次、大園 108 第二次、田中 108 第二次均考。 | 發票不是貨幣，也不是商品保證書本身。 |
| 電子發票資訊 | 電子發票常見資訊包含發票號碼、交易日期、消費金額；不一定包含商品製造產地。 | 永光 108 第二次電子發票勾選題。 | 不把所有商品資訊都塞進發票欄位。 |
| 消費糾紛處理 | 發現商品問題應保留發票或保證書，理性溝通，請大人協助，必要時撥打 1950。 | L3-12；成功、田中、大園 108 第二次均考 1950 或退換貨證明。 | 不自認倒楣、不吵鬧、不暴力、不只上網罵店家。 |
| 1950 專線 | 1950 是消費者服務專線；1999 是政府便民，1922 是疫情相關，110/119 是緊急救助。 | KL3 共通迷思 C4；南一 L3 報告列中頻。 | 電話題需以用途辨別，不可只背單一號碼。 |
| 綠色消費 | 選擇對環境傷害較少、低汙染、可回收、包裝少或具環保標章的商品。 | L3-11；永光 108 第二次、大園 108 第二次、成功 108 第二次。 | 綠色消費不是買綠色外觀商品，也不是外國進口商品。 |
| 環保標章 | 環保標章是判斷環境友善商品的重要線索，可與節能、省水、ST 安全等標章區分。 | KL3 指出環保標章是跨版本高頻；南一 L3 需併入綠色消費。 | 不把所有標章混為一談；題目若列標章，需校對用途。 |
| 網路購物安全 | 網路購物需注意個人資料、網站可信度、付款安全、退換貨資訊。 | 南一報告 M3-04 指出圖書館電腦留資料安全迷思。 | 公共電腦不宜輸入敏感個資；便利不等於安全。 |

### 2.2 守衛點總表

| 守衛點 | 常見錯誤 | 教學與命題檢核 |
|:--|:--|:--|
| 需要/想要要看題幹細節 | 書包壞了就把所有新書包都判為需要。 | 區分「需要替換」與「想要特定圖案、品牌、流行款」。 |
| 消費題要有預算或取捨 | 題目只寫「節儉是美德」或「不要浪費」。 | 情境需給出零用錢、目標、商品資訊、需要/想要衝突。 |
| 比價不等於買最便宜 | 看到最低價就選，不看品質、功能、保存期限。 | 正解應綜合價格、功能、品質、安全與需求。 |
| 價格高不等於品質好 | 認為越貴越值得買。 | 商品題需安排標示、用途、預算或保固資訊。 |
| 炫耀不是消費考量 | 把「是否可以炫耀」當成聰明消費資訊。 | 誘答可使用流行、炫耀、同學都有等社交壓力。 |
| 記帳欄位需服務理財 | 地點也必須記，越多欄位越好。 | 核心是收入、支出、項目、餘額與消費回顧。 |
| 儲蓄不是不消費 | 儲蓄等於克制欲望，所以乾脆不需要儲蓄。 | 儲蓄是安排未來需要與目標，不是否定所有欲望。 |
| 貨幣排序從直接交換開始 | 把銅幣或貝殼當最早交易方式。 | 排序題需明確包含以物易物或物品直接交換。 |
| 儲值卡和信用卡付款順序不同 | 悠遊卡、信用卡都以為是先消費後付款。 | 儲值卡先儲值扣款，信用卡先消費後付款。 |
| 發票不是貨幣 | 把統一發票當成付款工具或商品保證書。 | 發票是購物證明、退換貨佐證與防逃漏稅工具。 |
| 1950 要連用途 | 把 1950、1999、1922、110、119 混用。 | 電話題需搭配消費糾紛、市政、防疫、警消救護等情境。 |
| 綠色消費看環境影響 | 綠色外觀、進口商品或包裝精美被當成環保。 | 正解需連到低汙染、省資源、可回收、環保標章、減少包裝。 |
| 網購安全不可只看方便 | 在公共電腦輸入個人資料或只看價格便宜。 | 題目需檢核個資、安全網站、付款與退換貨資訊。 |

## §三 探究活動與生活連結

### 3.1 一週零用錢記帳任務

學生記錄一週收入、支出、消費項目與餘額，並在週末回顧哪幾筆屬於需要、想要、可延後或可避免的花費。

| 任務 | 判斷重點 | 守衛點 |
|:--|:--|:--|
| 記錄收入 | 零用錢、紅包、家人給的特定用途費用需分清。 | 不能把三餐或看病費用視為可任意消費的收入。 |
| 記錄支出 | 寫出項目、金額、日期或餘額。 | 地點可作補充，但不是核心理財欄位。 |
| 回顧消費 | 分辨需要、想要與可調整支出。 | 不用羞辱消費，重點是做出下一次更好的選擇。 |

### 3.2 消費前四步驟演練

以「買書包」「買文具」「買母親節禮物」「買運動水壺」等生活情境，讓學生依序練習：確認需求、蒐集資訊、比價比較、購買後記錄。

**守衛點**：每一題至少給出一個限制，如預算、原物品是否損壞、使用目的、商品標示或環保資訊，避免答案只剩「買或不買」。

### 3.3 需要/想要判斷卡

提供情境卡，例如「鞋子太小」「同學都有新款筆盒」「水壺破了」「想買限量貼紙」「參考書是老師指定」「書包壞了但想買特定圖案」。學生先分類，再說明理由。

**守衛點**：同一物品可能因情境不同而分類不同；「書包」不是永遠需要，「玩具」也不是永遠錯，重點是理由與資源安排。

### 3.4 貨幣演進排序活動

用卡片呈現「拿魚換米」「貝殼交換」「銅幣交易」「紙鈔購物」「悠遊卡扣款」「信用卡刷卡」，學生排序並說明每種工具的便利性與限制。

| 階段 | 可觀察問題 | 守衛點 |
|:--|:--|:--|
| 以物易物 | 雙方都需要對方物品才容易交換。 | 不把以物易物當現代最常見交易方式。 |
| 貝殼與金屬貨幣 | 物品媒介讓價值較容易比較。 | 貝殼早於金屬貨幣。 |
| 紙鈔 | 較方便攜帶與計價。 | 紙鈔晚於金屬貨幣。 |
| 塑膠貨幣 | 儲值卡與信用卡都便利，但付款順序不同。 | 悠遊卡先儲值；信用卡先消費後付款。 |

### 3.5 發票與消費權益小劇場

設定「買到瑕疵文具」「發票遺失」「店家拒絕處理」「同學想上網罵店家」等情境，學生討論正確處理步驟。

**守衛點**：處理消費糾紛的順序是保留證明、理性溝通、請大人協助、必要時 1950；不是自認倒楣、吵鬧或報復。

### 3.6 綠色消費校園採購任務

讓學生比較兩組商品，例如一般電池與可回收包裝商品、過度包裝禮盒與簡易包裝禮盒、有環保標章商品與只有綠色外觀商品。

**守衛點**：綠色消費要看環境影響、資源使用、包裝與標章，不看商品是不是綠色、不看是否進口。

### 3.7 網路購物安全討論

以「在圖書館電腦購物」「看到超低價網站」「需要輸入地址與電話」「不知道退貨方式」為情境，討論網購前應檢查的資訊。

**守衛點**：公共電腦不適合輸入個人資料；網路購物也要看網站可信度、付款安全、商品資訊與退換貨規定。

## §四 迷思分析

| # | 迷思描述 | 來源反推 | 正確觀念 | 守衛點 |
|:--:|:--|:--|:--|:--|
| M1 | 書包壞了就一定屬於「需要」，不用再判斷款式與偏好。 | 南一 L3 代表題 L3-04；勝利 111 期中。 | 書包壞了需要處理，但購買「想要圖案」的新書包含個人偏好，需看是否必要與預算。 | 題幹要明確區分物品功能需求與品牌、圖案、流行等想要。 |
| M2 | 想要和需要一樣重要，看到想買就可以買。 | KL3 共通迷思 C1；南一 L3 出題方向 20+。 | 需要優先，想要可在預算、儲蓄與家庭規範允許下安排。 | 消費題需放入預算限制或需要/想要對比。 |
| M3 | 只要家中負擔得起，買用不到的東西也不是浪費。 | L3-02；田中 108 第二次。 | 浪費不只看付不付得起，也看是否符合需求、是否造成資源浪費。 | 不把財力當成唯一判斷標準。 |
| M4 | 聰明消費要考慮是否可以炫耀。 | L3-06；勝利 111 期中。 | 聰明消費應考量需求、功能、價格、品質、安全與環境，不以炫耀為目的。 | 誘答可使用同儕壓力，但正解不可把炫耀合理化。 |
| M5 | 謹慎消費就是想買就買，猶豫就代表不需要。 | L3-07；勝利 111 期中。 | 謹慎消費包含多做比價、確認需求、蒐集資訊與評估預算。 | 不把情緒衝動當作判斷依據。 |
| M6 | 價格越高，商品品質一定越好。 | 大園 108 第二次是非題；KL3 消費主軸。 | 價格只是資訊之一，仍需看標示、功能、品質、保存期限、保固與需求。 | 商品比較題需提供多項資訊，不只比價格。 |
| M7 | 記帳只是形式，或只要記得大概花多少就好。 | L3-03、田中 108 第二次記帳大檢驗。 | 記帳可掌握收入、支出、項目與餘額，幫助回顧消費行為。 | 記帳題宜含表格或收支資料，測是否能解讀。 |
| M8 | 記帳項目越多越好，地點也一定要記。 | L3-09；南一報告 M3-07。 | 核心欄位是收入、支出、項目、金額與餘額；地點可補充但非必要。 | 題目若問「不用記錄」，正解可考地點，但避免否定完整記錄的彈性。 |
| M9 | 儲蓄就是壓抑想要，所以不需要儲蓄。 | L3-05；南一報告 M3-02。 | 儲蓄是為未來需要、大額支出或目標安排資源，能讓選擇更有彈性。 | 不把儲蓄教成禁欲；要連到具體目標。 |
| M10 | 所有拿到的錢都可以花掉，或所有錢都應該存起來。 | L3-08；勝利 111 期中。 | 紅包、零用錢結餘可規劃儲蓄；三餐、看病、學用品等必要支出需優先保留。 | 題目需區分金錢用途，不可只問「有錢就存」。 |
| M11 | 以物易物是現今最常見的交易方式。 | 南一報告 M3-03；成功 108 第二次。 | 以物易物是早期交易方式，現代日常多使用貨幣與電子工具。 | 時代題需清楚標出早期與現代。 |
| M12 | 貨幣演進可排成銅幣 → 貝殼 → 紙鈔 → 信用卡。 | L3-10；南一報告 M3-05。 | 常見排序為以物易物 → 貝殼 → 金屬貨幣或銅幣 → 紙鈔 → 信用卡或儲值卡。 | 排序題必守住貝殼早於銅幣、紙鈔早於信用卡。 |
| M13 | 貝殼是現代人常用的購物工具。 | 大園 108 第二次。 | 貝殼是早期交易媒介例子，不是現代日常貨幣。 | 現代工具辨識題需區分時代與使用情境。 |
| M14 | 悠遊卡和信用卡都一樣，都是先消費後付款。 | L3-01；KL3 共通迷思 C3。 | 悠遊卡等儲值卡先儲值再扣款；信用卡通常先消費後付款。 | 卡片題要問付款順序，不只問外觀都是塑膠卡。 |
| M15 | 統一發票可以當貨幣，或發票上會有所有商品資訊。 | 大園、永光、田中 108 第二次。 | 發票是購物證明，可對獎、防逃漏稅、作退換貨佐證；不等於貨幣或保證書。 | 發票題需區分功能與資訊欄位。 |
| M16 | 消費糾紛只能自認倒楣、吵鬧或上網罵店家。 | L3-12；成功、大園 108 第二次。 | 應保留證據、理性溝通、請大人協助，必要時打 1950。 | 糾紛題不可把情緒反應設為可接受正解。 |
| M17 | 消費者服務專線是 1999、1922、110 或 119。 | KL3 共通迷思 C4；南一報告 L3-12。 | 消費者服務專線是 1950；1999 是政府便民、1922 是疫情、110/119 是緊急救助。 | 電話題需連用途設誘答陷阱。 |
| M18 | 綠色消費就是買綠色外觀商品。 | 大園 108 第二次是非題。 | 綠色消費是選擇對環境傷害較少、低汙染、省資源、可回收或具環保標章的商品。 | 不以顏色判斷環保。 |
| M19 | 外國進口農產品就是綠色消費。 | 成功 108 第二次；南一報告 M3-06。 | 是否綠色消費要看環境影響、資源使用、包裝、運輸與標章，不看是不是進口。 | 避免把「外國、品質好、價格高」和環保畫上等號。 |
| M20 | 網路購物只要方便便宜，在公共電腦留下資料也很安全。 | 南一報告 M3-04；田中 108 第二次。 | 網購需注意個資、網站可信度、付款安全與退換貨；公共電腦不宜輸入敏感資料。 | 數位消費題需加入個資與安全判斷。 |
