### 1.2 單課學習總目標

學生完成本課後，應能：

1. 說明「地方生活」包含民俗活動、族群文化、地方資源、商店服務、公共資源、居民互動與生活方式改變。
2. 辨別民俗文化並理解其來源可能包含漢人、原住民族、新住民與其他外來文化，但「民俗」不等於「全部從國外傳入」。
3. 說明不同民俗與祭典有不同目的，如祈求平安、感謝自然、傳承族群文化，不可全部概括為慶豐收。
4. 分辨自然資源與人文資源：自然資源包含地形、氣候、動植物、生態；人文資源包含小吃、工藝、古蹟、節慶、建築與地方故事。
5. 說明地方資源會影響工作、休閒、觀光、文化認同與居民生活，不只影響職業選擇。
6. 說明地方生活會因科技、產業、人口流動、青年返鄉與保存意識而改變。
7. 判斷哪些做法有助於維護地方特色與資源，如學習傳統技藝、參加社區慶典、愛護公共資源、支持合理保存。
8. 以尊重與多元文化敏感度看待不同族群的生活方式與地方活動。

### 1.3 課程定位

南一 L2 是 L1「認識居住地方」之後的生活內容深化課。考古題顯示，本課不是單純考地方名產或祭典名稱，而是建立三組判斷能力：

1. **文化辨識**：能區分傳統民俗、原住民族祭典、新住民或外來文化活動，並理解活動目的。
2. **資源分類與功能**：能分辨自然/人文資源，並說明資源如何連到工作、生活、休閒、觀光與地方認同。
3. **地方維護與變遷**：能理解地方特色可能消失，也能以適合年齡的方式參與保存與敦親睦鄰。

## §二 核心知識點地圖

### 2.1 本課主要概念拆解

| 核心知識點 | 正確概念 | 考古題反推依據 | 守衛點 |
|:--|:--|:--|:--|
| 地方生活的範圍 | 地方生活包含民俗節慶、資源利用、商店服務、公共資源、居民互動與生活變遷。 | L2 估計 60～80 題、10 校；考點橫跨民俗、資源、鄰里。 | 不把本課只窄化為「節慶名稱」。 |
| 民俗的意義 | 民俗是地方長期形成並被居民實踐的生活習慣、信仰、技藝與活動。 | 代表題 L2-01：「民俗是從國外傳入」為錯。 | 民俗不等於外來文化；也不等於所有活動都很古老。 |
| 多元文化來源 | 地方文化可能來自漢人、原住民族、新住民或其他外來文化，並在地方生活中互動。 | 代表題 L2-05 考東南亞傳入臺灣的潑水節。 | 外來文化可以成為地方生活的一部分，但不可反推所有民俗皆外來。 |
| 民俗技藝與傳承 | 宋江陣、傳統工藝、地方社團等可作為學習民俗技藝的管道。 | 代表題 L2-03：學習民俗技藝可參加宋江陣相關社團。 | 不把民俗只看成觀看表演；學生可透過學習與參與傳承。 |
| 信仰活動與祈願 | 媽祖繞境、穿越轎下等活動常與祈求平安、凝聚信眾與地方認同有關。 | 代表題 L2-04：信徒穿越轎下目的為祈求平安。 | 不把宗教活動簡化成熱鬧遊行或商業活動。 |
| 原住民族祭典 | 不同族群祭典有不同名稱、週期與目的，如排灣族五年祭、達悟族飛魚祭、阿美族豐年祭。 | L2 出題方向列原住民各族祭典高頻；代表題 L2-08 考排灣族五年祭。 | 禁止把所有祭典都說成慶豐收；族群與祭典不可張冠李戴。 |
| 自然資源 | 自然資源包含地形、氣候、河川、動植物、生態等自然形成或自然條件。 | 代表題 L2-06：蛙類生態屬自然資源。 | 小吃、古蹟、工藝不是自然資源。 |
| 人文資源 | 人文資源包含居民創造、傳承或改造出的事物，如著名小吃、傳統工藝、古蹟、節慶與文化活動。 | 迷思矩陣列「著名小吃屬於自然資源」為錯。 | 人文不是只限藝術品；生活飲食與建築也可屬人文資源。 |
| 資源與工作 | 地方自然環境與資源會影響居民工作，如漁夫工作可能受季節與海象影響。 | 代表題 L2-07：工作性質受季節影響，較可能是漁夫。 | 資源影響工作，但不只影響工作。 |
| 資源的多元功能 | 地方資源也影響休閒、觀光、教育、文化保存、地方認同與社區發展。 | L2 迷思 M2-07 指出「自然資源只影響工作」為窄化。 | 出題時需避免只把資源功能寫成職業配對。 |
| 傳統工藝的價值 | 美濃油紙傘等工藝兼具實用、藝術、文化與節慶意義。 | 代表題 L2-02：「美濃紙傘藝術價值高，但不實用」為錯。 | 不把傳統工藝當成只有展示價值或只有經濟價值。 |
| 地方特色保存 | 地方特色可能因開發破壞、生活方式改變、未被保存而消失。 | 代表題 L2-11：地方特色消失原因包含開發、生活改變與未保存。 | 保存不是反對所有發展；需思考兼顧生活需要與文化延續。 |
| 地方生活改變 | 科技、交通、產業型態、人口移動與青年返鄉會改變地方生活。 | 出題方向列「地方生活的改變」高頻，代表題 L2-12 青年返鄉對地方有幫助。 | 不把返鄉或傳統產業視為落後；要看其對地方發展的可能貢獻。 |
| 商店與生活 | 商店提供居民日常所需，也需要注意商品安全與消費檢查。 | 代表題 L2-10：購物時檢查商品外觀是否變形。 | 詳細理財判斷留給 L3；L2 重點是商店與地方生活的連結。 |
| 敦親睦鄰 | 居民可透過問候、互助、參加活動、愛護公共資源維持良好鄰里關係。 | L2 出題方向列敦親睦鄰/鄰里關係為中頻。 | 不把鄰里互動只寫成口號；需具體到行為。 |
| 公共資源使用 | 公園、圖書館、活動中心、生態環境等公共資源需共同愛護與合理使用。 | L2 出題方向列公共資源使用為中頻。 | 公共資源不是沒人管理；使用者有維護責任。 |

### 2.2 守衛點總表

| 守衛點 | 常見錯誤 | 教學與命題檢核 |
|:--|:--|:--|
| 民俗不等於外國傳入 | 把民俗定義成從國外傳入的生活習慣。 | 題目要區分「本地長期形成的民俗」與「外來文化活動」。 |
| 文化來源要具體 | 把耶誕節、新住民文化、漢人信仰、原住民族祭典混成同一類。 | 可用情境描述活動來源，再問分類或文化意義。 |
| 祭典目的不可一把抓 | 所有族群祭典都是慶豐收。 | 至少檢核族群、祭典名稱、目的三者是否一致。 |
| 自然/人文分類要看形成原因 | 著名小吃、保安火車站、美濃油紙傘被誤認為自然資源。 | 判斷「自然形成」或「人類創造/傳承」。 |
| 資源功能不可窄化 | 自然資源只影響工作。 | 題目可同時考工作、休閒、觀光、文化認同。 |
| 傳統工藝不可只看實用性 | 美濃紙傘因藝術價值高就不實用。 | 工藝可兼具實用、藝術、文化與儀式功能。 |
| 地方保存不可唯利 | 只有能賺錢的地方特色才值得保存。 | 保存價值需含文化記憶、生活認同與不可逆性。 |
| 返鄉不可負面刻板 | 青年返鄉從事農漁業對地方沒有幫助。 | 返鄉可能帶來技術、創意、產業更新與文化傳承。 |
| 公共資源使用需有責任 | 公共設施是大家的，所以可任意使用。 | 正解需包含愛護、共享、遵守規範與維護。 |
| 小學生參與要可行 | 要小學生負責保存古蹟或主導大型開發決策。 | 小學生可學習技藝、參加活動、宣導、觀察、愛護資源。 |

## §三 探究活動與生活連結

### 3.1 地方民俗分類任務

提供宋江陣、媽祖繞境、潑水節、排灣族五年祭、達悟族飛魚祭、阿美族豐年祭、美濃油紙傘等卡片，讓學生依「活動來源、參與方式、主要目的、地方意義」分類。

**守衛點**：不要只做族名配對；每張卡至少要說出一個判斷理由，例如祈求平安、感謝自然、傳承技藝或促進族群交流。

### 3.2 自然/人文資源校園與社區走查

以學校周邊或虛擬社區圖為素材，讓學生標出自然資源與人文資源。自然資源可包含樹木、溪流、生態、地形；人文資源可包含市場、小吃、廟宇、老建築、傳統技藝、公共設施。

| 任務 | 判斷重點 | 守衛點 |
|:--|:--|:--|
| 找自然資源 | 是否由自然條件或生態形成 | 不把「有名」誤當自然資源。 |
| 找人文資源 | 是否由居民創造、保存或傳承 | 小吃、工藝、古蹟皆可屬人文資源。 |
| 說明功能 | 對工作、休閒、觀光、文化或生活的影響 | 不只寫「可以賺錢」。 |

### 3.3 地方生活改變訪談

訪談家人、店家或社區居民，詢問地方商店、交通、節慶、產業或公共資源近年的變化。學生整理「以前如何、現在如何、造成改變的原因、對居民的影響」。

**守衛點**：訪談結果不是全地方唯一答案；可鼓勵比較不同年齡、職業或居住時間的受訪者看法。

### 3.4 地方特色保存討論

以「老建築改建」「傳統工藝後繼無人」「自然生態被開發」「地方節慶參與人數下降」等情境，討論地方特色可能消失的原因與可行保存方式。

**守衛點**：保存不是反對所有發展；討論需同時看生活需求、文化價值、公共安全與居民共識。

### 3.5 敦親睦鄰與公共資源行動

讓學生設計一項可執行的小行動，例如參加社區慶典、提醒公共設施使用規範、整理圖書角、繪製地方資源地圖、向家人介紹一項民俗技藝。

**守衛點**：行動要符合三年級學生能力，避免設計成「由學生主導政府政策」或「一個人解決全社區問題」。

### 3.6 商店與地方生活觀察

觀察地方商店提供哪些服務、滿足哪些居民需求，並練習購物安全檢查，例如商品外觀、保存狀態、標示是否清楚。

**守衛點**：本活動銜接 L3 生活理財，但 L2 重點放在「商店如何構成地方生活網絡」，不提前大量考需要/想要或付款工具。

| M6 | 保安火車站、古蹟或傳統工藝只是建築/物品，不算文化資源。 | 南一 L2 迷思 M2-05；跨 L4 地方特色題趨勢。 | 人文資源可包含交通建築、古蹟、工藝、地方故事與集體記憶。 | 人文資源不只限於藝術表演。 |
| M7 | 美濃油紙傘只有藝術價值，不實用。 | 南一 L2 代表題 L2-02。 | 傳統工藝可兼具實用、藝術、文化象徵與節慶用途。 | 不用單一功能否定傳統工藝價值。 |
| M8 | 地方自然資源只影響工作，沒有其他功能。 | 南一 L2 迷思 M2-07；南一報告也在 L1/L2 都指出功能窄化。 | 自然資源也影響休閒、觀光、生態教育、文化活動與地方認同。 | 資源題應讓學生說明多元影響。 |
| M9 | 青年返鄉從事農漁業對地方發展沒有幫助。 | 南一 L2 代表題 L2-12；誘答統計「青年返鄉負面刻板印象」。 | 青年返鄉可能帶入新技術、行銷、創意、文化傳承與產業更新。 | 不把農漁業或返鄉視為落後。 |
| M10 | 地方特色只有能帶來收入才值得保存。 | 南一 L2 迷思 M2-06；KL3 共通迷思 C6。 | 地方特色也承載文化記憶、居民認同與不可逆的歷史價值。 | 保存與發展需兼顧，不以短期收入作唯一標準。 |
| M11 | 地方特色消失只是一種自然淘汰，不需關心原因。 | 代表題 L2-11：消失原因包含開發破壞、生活改變、未保存。 | 地方特色消失常與開發、生活型態改變、傳承中斷和保存不足有關。 | 要能說明原因與可行維護方式。 |
| M12 | 公共資源既然屬於大家，就可以照自己方便使用。 | L2 出題方向列公共資源使用為中頻。 | 公共資源需共享、愛護、遵守規範與共同維護。 | 公共資源題需考具體行為，不只考「要愛護」。 |
| M13 | 參加民俗或社區活動只是看熱鬧，與地方保存無關。 | 代表題 L2-09：學習宋江陣、參加社區慶典可維護地方資源。 | 學習、參與與介紹地方活動都是學生可行的文化傳承方式。 | 學生參與要具體且符合年齡。 |
