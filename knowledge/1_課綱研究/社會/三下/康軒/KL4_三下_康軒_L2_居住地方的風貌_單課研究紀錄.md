## §一 課綱連結與學習總目標

### 1.1 課綱連結

| 類型 | code | 本課對應 |
|:--|:--|:--|
| 學習表現 | **1a-II-1** | 辨識居住地方的自然、人文、場所與公共設施特性。 |
| 學習表現 | **2a-II-1** | 感受居住地方的生活風貌，理解公共場所與居民日常需求的關係。 |

### 1.2 單課學習總目標

學生完成本課後，應能：

1. 說明「居住地方的風貌」包含自然環境、人文活動、公共場所、服務設施與居民互動，不只是風景或建築外觀。
2. 比較都市、鄉村與不同地形環境的生活特徵，避免把都市等同進步、把鄉村等同落後。
3. 依生活需求判斷適合前往的場所或服務單位，例如郵局、銀行、農漁會信用部、電信公司、電力公司、火車站、博物館等。
4. 辨識常見公共設施與場所設備的功能，例如無障礙空間、自動售票機、列車時刻表、語音導覽系統等。
5. 區分高頻易混服務：電信公司提供通訊與網路服務，電力公司提供用電服務；郵局提供寄送、儲匯與郵政服務，不負責申請網路。
6. 理解公共設施需要居民共同維護，能以排隊、保持清潔、遵守標示、愛惜設備、尊重不同使用需求等方式實踐公共生活素養。

## §二 核心知識點地圖

### 2.1 本課主要概念拆解

| 核心知識點 | 正確概念 | 典型生活情境 | 守衛點 |
|:--|:--|:--|:--|
| 居住地方的風貌 | 風貌由自然環境、人文活動、公共場所、服務設施與居民生活共同構成。 | 觀察住家或學校附近的街道、商店、車站、公園、農田、山坡或海邊。 | 不把「風貌」縮小成漂亮景色；也不只列建築名稱。 |
| 都市與鄉村特徵 | 都市通常人口較密集、商店與交通較多；鄉村常有較多農田、空地或自然景觀，居民互動可能更密切。 | 比較市區街道與鄉村聚落的建築、交通、工作與生活節奏。 | 不用「進步/落後」評價都市與鄉村；題目要比較特徵，不比較價值高低。 |
| 地形與空間利用 | 不同地形會影響居民活動：平地常見農田與聚落，山坡可見茶園、果園，海邊常見漁港、魚塭或鹽田。 | 看圖片或地圖判斷地方產業與活動。 | 不把所有地形固定成唯一用途；要用「常見」「較可能」而非絕對化。 |
| 公共場所服務功能 | 每個場所有主要服務功能，應依需求選擇合適場所。 | 寄包裹、存提款、搭火車、參觀博物館、辦理通訊服務。 | 不能因場所名稱熟悉就任意擴大功能；正解要依服務內容判斷。 |
| 郵局服務 | 郵局可寄信、寄包裹、買郵票，也可辦理郵政儲匯等服務。 | 家人要寄包裹、買郵票、存款。 | 郵局不能申請網路；網路與電話服務屬電信公司。 |
| 電信公司與電力公司 | 電信公司提供通訊、電話、網路等服務；電力公司供應用電。 | 申請網路、電話故障、停電或電費問題。 | 「電信」不是「電力」；看到「用電」應排除電信公司。 |
| 金融服務場所 | 銀行、郵局、農漁會信用部可提供存款、提款等金融服務；戶政事務所不提供存提款。 | 要存錢、提款、辦理金融服務。 | 不要把所有公共機關都當作金融場所；戶政事務所屬行政登記職能。 |
| 場所設備辨識 | 設備會依場所目的配置，例如火車站常見自動售票機、時刻表、電梯；博物館或美術館較常見語音導覽。 | 判斷某設備較可能出現在哪一種場所。 | 不把參觀經驗誤套到交通場所；先看場所任務，再判斷設備。 |
| 無障礙設施 | 無障礙標誌表示該處設有較方便身心障礙者、長者、推嬰兒車者等使用的空間或設施。 | 車站、圖書館、公所、醫院看到無障礙標誌。 | 無障礙標誌不是博愛座、等待區或單純電梯標誌。 |
| 公共設施使用禮儀 | 公共設施屬多人共享，使用時要排隊、保持清潔、遵守規定、愛惜設備並體諒不同使用者。 | 搭車、借書、使用公園遊具或公共廁所。 | 公共設施不是「免費所以可以任意使用」；共同使用就有共同維護責任。 |
| 場所與行政機關邊界 | L1 偏行政單位與機關職能；L2 偏生活服務場所、公共設施與場所設備。兩者可綜合出題。 | 戶政事務所能辦戶籍，但不能存款；郵局能寄送與儲匯，但不能申請網路。 | 題幹若問「服務功能」，先判斷需求性質，再選場所或機關。 |
| 居民活動與文化風貌 | 居民的工作、交通、休閒、節慶與多元文化互動，都會形塑地方風貌。 | 市場、車站、廟埕、社區活動中心、不同文化商店。 | 不把地方風貌看成固定不變；居民活動會讓地方持續變化。 |

### 2.2 守衛點總表

| 守衛點 | 來源訊號 | 診斷問法 | 出題與教學應避免 |
|:--|:--|:--|:--|
| SG1：電信公司不供電 | 康軒 L2 考古題高頻；KL3 K4 | 「申請網路」與「停電」分別找誰？ | 把「電」字當唯一線索，造成電信/電力混淆。 |
| SG2：郵局不申請網路 | 康軒 L2 題型 B；KL3 K5 | 郵局可以做什麼？哪一項不是郵局服務？ | 把郵局寫成萬能生活服務站。 |
| SG3：戶政事務所不存提款 | 康軒 L2 題型 D | 哪個場所沒有提供存錢、提款服務？ | 把「公共機關」和「金融場所」混為一談。 |
| SG4：農漁會信用部可提供金融服務 | 康軒 L2 迷思 M6 | 農漁會信用部是否能存款？ | 只用「農會」名稱判斷，忽略信用部功能。 |
| SG5：無障礙標誌代表無障礙空間 | 康軒 L2 題型 C | 看到無障礙標誌代表什麼？ | 把無障礙標誌誤解為博愛座、等待區或電梯。 |
| SG6：設備依場所功能配置 | 康軒 L2 題型 E | 火車站不太可能出現哪項設備？ | 把博物館語音導覽經驗套到火車站。 |
| SG7：都市與鄉村是特徵比較，不是優劣比較 | KL3 主題 4.1、迷思 C8 | 都市與鄉村生活有哪些不同？ | 用「都市較好、鄉村較差」的價值階序。 |
| SG8：地形影響活動，但不能絕對化 | KL3 主題 4.1 | 山坡、海邊、平地各常見哪些利用？ | 把一種地形寫成只有一種活動。 |
| SG9：公共設施需共同維護 | 康軒 L2 出題方向「公共設施使用禮儀」 | 使用車站、公園、圖書館時應注意什麼？ | 只考設備名稱，不考共享與維護責任。 |
| SG10：場所服務與行政職能可綜合，但邊界要清楚 | 康軒報告 3.2.3 近年融合 L1 | 同一題放郵局、銀行、戶政、電信公司時，需求是否明確？ | 造成多個選項可成立或跨課概念混亂。 |

## §三 探究活動與生活連結

### 3.1 生活服務地圖

以學校為中心，讓學生標記附近的郵局、銀行、車站、公園、圖書館、超商、電信服務據點、公共廁所、無障礙設施等，再依「寄送、金融、交通、休閒、通訊、閱讀、健康、行政」分類。

**產出**：一張「我居住地方的服務地圖」，每個地點至少寫出一項主要服務與一項使用注意事項。  
**守衛點**：分類依「服務內容」而非場所名稱熟悉度；郵局不可被標成申請網路場所，電信公司不可被標成供電場所。

### 3.2 「我該去哪裡？」情境卡

設計生活事件卡，讓學生分組配對適合場所：

| 事件 | 較合適的場所或服務 | 判斷理由 |
|:--|:--|:--|
| 家人要寄包裹給親戚 | 郵局 / 宅配服務據點 | 需求是寄送物品。 |
| 家裡要申請網路 | 電信公司 | 需求是通訊與網路服務。 |
| 社區突然停電 | 電力公司 / 相關報修管道 | 需求是用電供應與維修。 |
| 要存錢或提款 | 銀行、郵局、農漁會信用部 | 需求是金融服務。 |
| 要辦理戶籍登記事項 | 戶政事務所 | 需求是身分與戶籍行政。 |
| 要搭火車去外縣市 | 火車站 | 需求是交通運輸。 |
| 到博物館參觀展覽 | 博物館 / 美術館 | 需求是文化學習與參觀。 |

**守衛點**：題目要讓學生說出「為什麼」，避免只靠背誦場所名稱。

### 3.3 公共設施與無障礙觀察

觀察學校、圖書館、車站、公園或社區活動中心是否有斜坡、電梯、無障礙廁所、導盲磚、清楚標示、座椅、垃圾桶等設施。討論哪些人會需要這些設施，以及使用時應如何互相體諒。

**守衛點**：無障礙不是只服務身心障礙者，也可能服務長者、暫時受傷者、推嬰兒車者；但標誌意義仍需準確連到「無障礙空間或設施」。

### 3.4 都市、鄉村與地形風貌比較

使用圖片、地圖或地方資料，比較都市、鄉村、平地、山坡、海邊等環境的建築、交通、產業與居民活動。學生可用「我看到」「我推測」「我需要查證」三欄記錄。

**守衛點**：不把都市/鄉村寫成優劣排序；不把地形用途絕對化。若學生說「鄉村比較落後」，要追問依據並改寫為可觀察特徵。

### 3.5 公共設施改善提案

讓學生選一個常用公共設施，例如公園、候車亭、圖書角、公共廁所或校門口通行空間，提出「目前使用情形」「需要改善處」「誰會受益」「我能做什麼」四項短提案。

**守衛點**：三年級學生可提出觀察、提醒、整理資料與向大人反映，不應被設定為獨自處理危險或專業維修。

## §四 迷思分析

| # | 迷思描述 | 來源反推 | 正確觀念 | 守衛點 |
|:--:|:--|:--|:--|:--|
| M1 | 電信公司提供用電服務。 | 康軒 L2 題型 A；KL3 K4 強度 ★★★★★。 | 電信公司提供通訊、電話、網路；用電由電力公司供應。 | 題幹出現「用電、停電、電費」時，不選電信公司。 |
| M2 | 郵局可以申請網路。 | 康軒 L2 題型 B；KL3 K5 強度 ★★★★。 | 郵局提供寄送、郵票、郵政儲匯等服務；網路申辦屬電信公司。 | 問「郵局無法提供何種服務」時，鎖定申請網路。 |
| M3 | 衛生所負責防火救災。 | 康軒 L2 迷思矩陣 M3。 | 衛生所偏健康、防疫與保健；防火救災屬消防單位。 | 「衛生、安全、救災」不能混成同一類，須依事件性質判斷。 |
| M4 | 語音導覽系統常見於火車站。 | 康軒 L2 題型 E、迷思 M4。 | 語音導覽較常見於博物館、美術館等參觀場所；火車站重點是售票、時刻、乘車與無障礙通行。 | 先判斷場所任務：交通場所不等於參觀導覽場所。 |
| M5 | 戶政事務所可以存款或提款。 | 康軒 L2 題型 D、迷思 M5。 | 戶政事務所辦理戶籍與身分登記事務，不提供金融存提款。 | 「公共機關」不是「金融場所」；存提款找銀行、郵局或信用部。 |
| M6 | 農漁會信用部不能存款。 | 康軒 L2 迷思 M6。 | 農漁會信用部可提供金融服務，包含存款等。 | 看到「信用部」要判斷金融功能，不只看「農會/漁會」名稱。 |
| M7 | 無障礙標誌代表博愛座、等待區或電梯。 | 康軒 L2 題型 C。 | 無障礙標誌表示該處設有無障礙空間或設施，方便有不同行動需求的人使用。 | 標誌題要回到「空間可及性」，不可只聯想到座位或單一設備。 |
| M8 | 所有公共設施都可以隨個人方便使用。 | 康軒 L2 出題方向「公共設施使用禮儀」。 | 公共設施屬共享資源，需遵守規定、保持清潔、排隊並愛惜設備。 | 正解應包含共同維護與尊重他人，不只是不破壞。 |
| M9 | 都市比鄉村進步，鄉村居民互動較少、感情較淡。 | KL3 主題 4.1 與共通迷思 C8。 | 都市與鄉村各有生活特徵；鄉村人口較少但鄰里互動可能更緊密。 | 比較特徵，不比較價值；避免「進步/落後」語言。 |
| M10 | 地形和居民活動沒有關係，所有地方都能發展同樣活動。 | KL3 主題 4.1 地形與空間利用。 | 地形會影響土地利用與產業活動，例如平地、山坡、海邊常見活動不同。 | 使用「較常見」而非絕對化；允許地方因交通、技術、政策而變化。 |
| M11 | 場所設備可以任意互換，只要都是公共場所就會有。 | 康軒 L2 題型 E。 | 設備依場所功能配置，火車站、博物館、銀行、郵局的設備不同。 | 設備題要從「場所目的」推論，不從個人零散經驗猜測。 |
| M12 | 場所名稱越正式，服務範圍就越大。 | 康軒 L2 近年「場所 vs 機關」綜合題趨勢。 | 正式機關或公共場所都有明確職能邊界，不因名稱正式就萬能。 | 題目要問具體需求；學生要能說明為何某場所不能處理該需求。 |
