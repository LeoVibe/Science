## §一 課綱連結與學習總目標

### 1.1 課綱連結

| 類型 | code | 本課對應 |
|:--|:--|:--|
| 學習表現 | **1a-II-1** | 辨識消費活動、交易工具與購物場所如何影響日常生活。 |
| 學習表現 | **2b-II-2** | 了解不同付款方式與購物管道會產生不同責任，並對自己的選擇負責。 |
| 學習表現 | **3a-II-1** | 透過生活觀察、資料蒐集與比較，認識交易工具演進與消費方式差異。 |
| 學習內容 | **Aa-II-1** | 居住地方的居民活動，包含購物、付款、取貨與日常服務使用。 |
| 學習內容 | **Bd-II-1** | 個人需求與資源運用、消費判斷；本課聚焦交易工具與消費方式的基礎識讀。 |

### 1.2 單課學習總目標

學生完成本課後，應能：

1. 說明消費是為了滿足生活需求而進行的購買、交換或取得服務活動，不只是「花錢買東西」。
2. 依時間順序排列交易工具演進：以物易物 → 貝殼 → 銅錢 → 紙鈔 → 信用卡 → 行動支付。
3. 分辨早期交易工具與現代交易工具，例如銅錢屬較早期工具，禮券、儲值卡、信用卡與行動支付屬現代常見支付方式。
4. 說明信用卡是「先消費，收到帳單後付款」，不是現場同時交付紙鈔。
5. 說明儲值卡是「先儲值，再消費扣款」，和信用卡的付款時序不同。
6. 理解行動支付通常需要綁定帳戶、卡片或儲值來源，也有帳號、密碼、裝置保管與詐騙風險。
7. 依購物需求判斷合適場所與取得方式，例如超商、小商店、傳統市場、大賣場、網路購物、電視購物與宅配取貨。
8. 能把本課和 L4《消費與選擇》區隔：L3 偏交易工具與購物方式，L4 偏需要/想要、廣告、標章、消費爭議與理性選擇。

## §二 核心知識點地圖

### 2.1 本課主要概念拆解

| 核心知識點 | 正確概念 | 典型生活情境 | 守衛點 |
|:--|:--|:--|:--|
| 消費與生活需求 | 消費是人們為取得物品或服務而付出金錢、票券、點數、電子支付或其他資源的活動。 | 買早餐、搭公車、買文具、上網訂書、用悠遊卡付款。 | 不把消費縮小成「浪費」或「只有買玩具才叫消費」。 |
| 交易工具演進 | 交易工具從直接交換逐步發展為較便利、可計價、可保存與可遠距交易的工具。 | 從拿魚換米，到用錢、卡片或手機付款。 | 排序題以「以物易物」為最早，不以銅錢或貝殼作起點。 |
| 以物易物 | 貨幣出現前，人們用自己有的物品交換需要的物品。 | 拿魚和鄰居交換豬肉或米。 | 「以牙還牙」不是交換物品方式；正確詞是「以物易物」。 |
| 貝殼作為早期交易媒介 | 部分地區曾使用稀少、易攜帶、可辨識的物品作為交換媒介，教材常以貝殼作代表。 | 用貝殼交換食物或用品的歷史情境。 | 不把貝殼誤解為現代台灣常用交易工具；排序時位於以物易物之後、銅錢之前。 |
| 銅錢與紙鈔 | 銅錢、紙鈔屬貨幣工具；紙鈔需由國家或合法機構發行，不能自行印製。 | 用新臺幣買衣服；古代故事中用銅錢買物品。 | 銅錢不是最古老交易方式；紙鈔不是普通紙張，不能自己印來使用。 |
| 信用卡 | 信用卡是先消費，之後依帳單付款；使用者仍需負擔付款責任。 | 家人刷信用卡買家電，月底或次月繳信用卡帳單。 | 信用卡不是免費錢，也不是刷卡時同時再付現金。 |
| 儲值卡 | 儲值卡先存入金額，再依使用金額扣款。 | 悠遊卡、一卡通或商店儲值卡先加值後消費。 | 儲值卡和信用卡付款順序相反，不可混同。 |
| 行動支付 | 行動支付以手機或行動裝置完成付款，通常連結帳戶、卡片或電子錢包。 | 在超商用手機掃碼付款。 | 行動支付不是「從虛空扣費」，且仍有安全風險。 |
| 禮券與票券 | 禮券、餐券、商品券等可在特定範圍內折抵或換取商品服務，屬現代常見交易工具之一。 | 用書店禮券買書；用餐券兌換餐點。 | 禮券不是古代交易工具，也不是所有商店都能使用。 |
| 現代與傳統交易工具辨識 | 現代常見工具包含紙鈔、信用卡、儲值卡、禮券、行動支付；早期工具包含以物易物、貝殼、銅錢。 | 題目列出銅錢、禮券、儲值卡、信用卡，問哪一項不是現代工具。 | 不因「看起來像錢」就歸類為現代；要看時代與使用方式。 |
| 購物場所與取得方式 | 不同購物場所提供不同服務與取貨方式：超商方便快速，大賣場大量採買，網路購物常宅配或超商取貨，電視購物需下單配送。 | 去大賣場現場採買、網購後宅配到家、超商取貨付款。 | 不把所有購物都寫成宅配；現場購物通常是現場取貨。 |
| 宅經濟與網路購物 | 近年題目增加宅經濟、網路購物情境，強調不出門也能購買，但需注意交易安全與取貨方式。 | 網路訂書、外送平台、線上購物宅配。 | 網路購物便利不等於完全沒有風險；仍需確認來源、付款與個資安全。 |
| L3 與 L4 邊界 | L3 重在工具與場所；L4 重在理性選擇、廣告判斷、標章、發票與消費爭議。 | 同一份段考可能把信用卡放 L3，把需要/想要放 L4。 | 不把「使用信用卡想買就買」只當 L3 工具題，這也會連到 L4 理性消費守衛。 |

| 守衛點 | 來源訊號 | 診斷問法 | 出題與教學應避免 |
|:--|:--|:--|:--|

| SG3：信用卡先消費後付款 | 康軒 L3 題型 C；KL3 共通迷思 C3 | 刷信用卡後，是否還要現場交紙鈔？ | 把信用卡說成免費、立即扣現金或現場另付現。 |

| SG6：紙鈔不能自行印製 | 康軒 L3 迷思 M6 | 為什麼不能自己印紙鈔使用？ | 混淆「紙」和「合法貨幣」。 |
| SG7：現代/傳統工具依時代與功能判斷 | 康軒 L3 題型 B | 銅錢、禮券、儲值卡、信用卡哪一個不是現代工具？ | 只依物品外觀或是否可付款判斷。 |
| SG8：購物場所和取貨方式要配對 | 康軒 L3 題型 D | 去大賣場採買通常如何取得商品？網購又如何？ | 把現場採買誤配宅配寄送。 |
| SG9：網路購物便利但需查證與保護個資 | 康軒報告 111-112 宅經濟趨勢 | 網路購物有哪些便利？有哪些要注意？ | 只強調方便，不處理來源、付款、個資與詐騙風險。 |
| SG10：信用卡工具識讀要銜接理性消費 | KL3 共通迷思 C3 與康軒 L4 誘答 | 有信用卡是否代表想買什麼都可以買？ | 把付款工具教成消費能力無上限。 |

## §三 探究活動與生活連結

### 3.1 家庭付款工具訪談

請學生訪問家人最近一週使用過哪些付款方式，例如現金、悠遊卡、信用卡、行動支付、禮券、網路付款。記錄「用在哪裡」「先付款還是後付款」「是否需要帳戶或儲值」「有沒有需要注意的安全事項」。

**產出**：一張「我家的付款工具表」，每種工具至少寫出一個使用情境與一個注意事項。  
**守衛點**：訪談不要求學生揭露帳號、卡號、金額等個資；重點是理解付款時序與責任。

### 3.2 交易工具時間線

使用圖卡或短情境卡排列交易工具演進：

| 情境卡 | 對應工具 | 排序線索 |
|:--|:--|:--|
| 拿魚向鄰居交換豬肉 | 以物易物 | 沒有貨幣，直接交換物品。 |
| 用貝殼買饅頭 | 貝殼 | 以特定物品作交換媒介。 |
| 用銅錢買青菜 | 銅錢 | 金屬貨幣。 |
| 用新臺幣買褲子 | 紙鈔 | 現代法定貨幣。 |
| 刷信用卡買用品 | 信用卡 | 先消費後付款。 |
| 去超商用手機支付 | 行動支付 | 以行動裝置完成付款。 |

**守衛點**：若學生把銅錢排第一，需追問「貨幣出現前怎麼交換？」把概念拉回以物易物。

### 3.3 付款方式比較表

讓學生分組比較信用卡、儲值卡、行動支付、紙鈔與禮券：

| 付款方式 | 付款時序 | 需要注意 | 常見迷思 |
|:--|:--|:--|:--|
| 紙鈔 | 現場付款 | 找零、遺失、真假鈔 | 可以自己印製。 |
| 信用卡 | 先消費後繳帳單 | 帳單、額度、負債 | 刷卡時還要給現金或不用付錢。 |
| 儲值卡 | 先儲值後扣款 | 餘額不足、遺失 | 和信用卡一樣先買後付。 |
| 行動支付 | 依綁定來源扣款或付款 | 密碼、帳戶、手機保管 | 不需帳戶且沒有安全風險。 |
| 禮券 | 在可使用範圍折抵 | 使用期限、適用店家 | 任何地方都能用。 |

**守衛點**：不要只比較「方便不方便」；需同時比較付款責任與限制。

### 3.4 購物場所與取貨方式任務

設計任務卡，讓學生選擇合適購物方式：

| 需求 | 可能選擇 | 判斷理由 |
|:--|:--|:--|
| 下課後立刻買牛奶 | 超商或附近商店 | 距離近、取得快。 |
| 家裡要一次買大量日用品 | 大賣場 | 品項多、可大量採買，通常現場取貨。 |
| 想買外地書店才有的書 | 網路購物 | 可遠距下單，常宅配或超商取貨。 |
| 在電視節目看到家用品想訂購 | 電視購物 | 透過電話或網路下單後配送。 |

**守衛點**：現場採買、網路購物、電視購物的下單與取貨方式不同，不能一律配宅配或一律配現場取貨。

### 3.5 行動支付安全情境討論

提供情境：「手機遺失」「收到陌生付款連結」「店員請你掃碼付款」「同學問你的支付密碼」。請學生判斷可以做、不能做、需要找大人協助的行動。

**守衛點**：三年級學生不需掌握金融科技細節，但要建立帳號密碼保護、交易來源查證、遇疑問找可信任大人的基本觀念。

## §四 迷思分析

| # | 迷思描述 | 來源反推 | 正確觀念 | 守衛點 |
|:--:|:--|:--|:--|:--|
| M1 | 「以牙還牙」是早期交換物品的方式。 | 康軒 L3 誘答機制統計最高頻；迷思矩陣 M1。 | 貨幣出現前的交換方式是「以物易物」，不是「以牙還牙」。 | 語詞題要考成語意義辨析，避免學生只看字面有「換」。 |
| M2 | 使用信用卡時，現場還要交紙鈔。 | 康軒 L3 題型 C；KL3 共通迷思 C3。 | 信用卡是先消費，收到帳單後再付款；現場不用同時交現金。 | 題幹出現刷卡付款時，要能說出「後續仍要繳帳單」。 |
| M3 | 信用卡是免費錢，想買什麼都可以買。 | KL3 C3 與康軒 L4 誘答「使用信用卡可以想買什麼就買什麼」。 | 信用卡只是付款工具，仍需按帳單付款，並要量力消費。 | L3 工具題需銜接 L4 理性消費，避免把工具等同無限制資源。 |
| M4 | 儲值卡和信用卡都是卡，所以使用方式相同。 | 康軒 L3 出題方向「儲值卡使用方式」。 | 儲值卡先儲值再扣款；信用卡先消費後付款。 | 比較題要問「先後順序」，不是只問能不能付款。 |
| M5 | 貝殼是現代台灣常用貨幣，或在台灣歷史中比所有貨幣都普遍。 | 康軒 L3 迷思矩陣 M3。 | 貝殼是教材中代表早期交易媒介的例子，不是現代常用交易工具。 | 排序時放在以物易物之後、銅錢之前；現代工具辨識題不可選貝殼。 |
| M6 | 行動支付不需要帳戶，直接從虛空扣費。 | 康軒 L3 迷思矩陣 M4；112-113 趨勢。 | 行動支付通常連結帳戶、信用卡、金融卡或電子錢包。 | 問「錢從哪裡來」與「如何保護帳號密碼」。 |
| M7 | 行動支付完全沒有安全風險。 | 康軒 L3 跨年度頻率分析 112-113。 | 行動支付便利，但仍可能有手機遺失、密碼外洩、詐騙連結與交易錯誤等風險。 | 正解應包含查證來源、保護密碼、找大人協助。 |
| M8 | 銅錢是最古老的交易工具。 | 康軒 L3 迷思矩陣 M5；題型 A 排序題。 | 最早是以物易物，之後才逐步出現貝殼、銅錢、紙鈔等交易媒介。 | 排序題必放「直接交換」情境，避免學生從金屬貨幣開始。 |
| M9 | 可以在家自行印製紙鈔使用。 | 康軒 L3 迷思矩陣 M6。 | 紙鈔是法定貨幣，需由合法機構發行，不能自行印製。 | 題目可問「為何普通紙不能變成錢」。 |
| M10 | 禮券是古代交易工具。 | 康軒 L3 誘答機制統計。 | 禮券是現代特定範圍使用的交易工具，不是古代貨幣。 | 判斷現代/傳統時，不只看是否是紙本，而要看制度與使用情境。 |
| M11 | 所有購物方式都會宅配寄送。 | 康軒 L3 題型 D。 | 現場到大賣場採買通常現場取貨；網路或電視購物常透過宅配或超商取貨。 | 場所與取貨方式必須配對，不能一律套用宅配。 |
| M12 | 網路購物只要方便就好，不需要查證來源或保護個資。 | 康軒報告指出 111-112 加入宅經濟情境；KL3 補強「網路消費特性」。 | 網路購物便利但需確認店家、商品資訊、付款方式、取貨方式與個資安全。 | 宅經濟題要同時考便利與風險，不只考能不能在家購物。 |
| M13 | 有手機就一定能行動支付。 | 由行動支付迷思延伸。 | 行動支付需裝置、網路、支付工具設定、帳戶或卡片綁定，且店家需支援。 | 不把「手機」等同「付款能力」，需看支付條件。 |
| M14 | 付款工具越新就一定越好。 | 由交易工具演進題延伸。 | 不同付款工具有不同便利、限制與風險，應依情境選擇。 | 演進不是價值排名；紙鈔、卡片與行動支付都可能在不同情境適用。 |
