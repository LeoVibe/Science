### 1.1 課綱連結

|:--|:--|:--|
| 學習表現 | **1a-II-1** | 辨識家鄉地名與自然環境、人文活動、歷史沿革之間的關聯。 |

### 1.2 單課學習總目標

學生完成本課後，應能：

1. 說明地名不只是地址標示，也可能記錄地方的自然環境、人文活動與歷史記憶。
2. 分辨自然環境命名因素，例如地形、氣候、植物、動物或特殊景觀。
3. 分辨人文命名因素，例如人物、居民活動、產業、族群語言、信仰或歷史事件。
4. 以鶯歌、烏來、竹山、朴子、官田、關廟等考古題常見案例，推測地名可能反映的地方特色。
5. 理解鶯歌是與岩石形狀、地形意象有關，不是因當地有很多鸚鵡或鳥叫聲。
6. 理解竹山與竹子相關，不是「山竹」水果；朴子偏植物名稱，不屬居民活動命名。
7. 說明烏來等地名可能來自原住民族語或族群語言，不能只用漢字字面猜測。
8. 知道地名可能因歷史、行政、文化或地方發展而改變，並非一旦形成就永遠不變。
9. 能選擇合適方式探索地名：訪問長輩或耆老、到圖書館查資料、上網查詢、參訪文物館或地方文化館。
10. 能說明訪談與資料查證的基本守則：事先設計問題、取得同意、記錄來源，並用多種資料互相印證。
11. 能把本課和 L6《家鄉的故事》區隔：L5 偏地名由來與探索方法，L6 偏地方人物、特產、古蹟、故事與文化保存。

## §二 核心知識點地圖

### 2.1 本課主要概念拆解

| 核心知識點 | 正確概念 | 典型例子或情境 | 守衛點 |
|:--|:--|:--|:--|
| 地名的功能 | 地名可用來辨識地方，也可能保存地方特色、歷史記憶與居民活動。 | 從某地名推測早期自然景觀或居民生活。 | 不把地名只當成地址或行政名稱。 |
| 自然環境命名 | 地名可由地形、氣候、植物、動物、河川、山形等自然因素而來。 | 鶯歌與岩石形狀、竹山與竹子、恆春與氣候溫暖。 | 判斷時要回到地方特徵，不只看字面。 |
| 地形因素 | 地形、山形、岩石形狀、河流湖泊等常成為命名線索。 | 鶯歌因岩石形狀像鳥形而與地形意象相關。 | 鶯歌不是因飼養鸚鵡或當地鳥叫聲得名。 |
| 氣候因素 | 地名可能反映地方氣候感受或自然條件。 | 恆春意指氣候溫暖、如春。 | 不把「溫暖」誤解成「多雨」或居民期待。 |
| 植物因素 | 地方常見植物或植被特色可成為地名來源。 | 竹山與竹子相關，朴子屬植物線索。 | 竹山不是山竹水果；朴子不是居民活動。 |
| 動物或形狀意象 | 有些地名看似動物字詞，其實可能來自地形形狀或傳說意象。 | 鶯歌字面像鳥名，但考點在岩石形狀與地形。 | 不能只看字面有動物字就判為動物來源。 |
| 人物因素 | 重要人物、開墾者、地方賢達或歷史人物可能成為地名來源。 | 某地以人物姓氏或紀念人物命名。 | 人名命名屬人文因素，不屬自然環境。 |
| 居民活動因素 | 產業、信仰、耕作、交易、廟宇、官署等活動可能影響地名。 | 官田、關廟等可作為人文活動或信仰線索。 | 植物地名不能誤判成居民活動地名。 |
| 族群語言因素 | 地名可能來自原住民族語、客語、閩南語或不同族群語言。 | 烏來來自原住民族語「烏萊」，與溫泉相關。 | 不能用漢字字面猜成「女巫住所」。 |
| 地名會改變 | 地名可能因政權、行政區劃、書寫方式、地方發展或居民使用而改變。 | 舊稱、現稱、行政名稱可能不同。 | 不把現在地名視為自古不變。 |
| 地名與地方認同 | 了解地名由來有助於認識家鄉故事與地方特色。 | 學生探索自己居住地或學校附近地名。 | 不是背全台地名，而是學會從地名問問題。 |
| 探索方法 | 可用上網查詢、圖書館資料、詢問長輩、參訪文物館等方式探索。 | 考古題中甲乙丙丁四種方式皆可。 | 不把單一資料來源當作全部答案。 |
| 訪談準備 | 訪問耆老或長輩前，需先設計問題、約定時間、取得同意並記錄重點。 | 訪談地方長輩前先列問題。 | 不是帶紙筆直接去就算完成訪談。 |
| 資料查證 | 網路資料、口述資料與書面資料都需要比對來源與可信度。 | 上網後再查圖書館資料或地方文史資料。 | 網路資料不能直接複製引用不查證。 |
| L5/L6 邊界 | L5 聚焦地名由來與探索方法；L6 聚焦地方故事、特產、古蹟與文化保存。 | 鶯歌地名屬 L5；鶯歌陶瓷特產較偏 L6。 | 不把特產配對題全部歸入 L5。 |

### 2.2 守衛點總表

| 守衛點 | 來源訊號 | 診斷問法 | 出題與教學應避免 |
|:--|:--|:--|:--|
| SG1：自然與人文因素要分清 | 康軒 L5 題型 A、B；KL3 3.4 | 這個地名是來自地形、氣候、植物，還是居民活動、人物、語言？ | 只問「哪個地名屬自然」但選項缺少可判斷線索。 |
| SG2：地名判斷不可只看字面 | 康軒 L5 鶯歌、烏來誘答 | 只看「鶯」「烏」等字，會不會誤判？ | 把字面聯想當成正解。 |
| SG3：鶯歌守衛 | 康軒 L5 高頻誘答；KL3 H3 | 鶯歌是因鳥類得名，還是因岩石形狀、地形意象？ | 設計成「鸚鵡鳥類」正解。 |
| SG4：竹山守衛 | 康軒 L5 題型 D | 竹山和竹子有關，還是和山竹水果有關？ | 讓學生用「竹山 = 山竹」的顛倒讀法過關。 |
| SG5：烏來守衛 | 康軒 L5 誘答統計 | 烏來可否直接用漢字字面猜成女巫住所？ | 忽略原住民族語或族群語言因素。 |
| SG6：居民活動與植物不可混淆 | 康軒 L5 題型 B | 朴子為何不是起因於居民活動？ | 把所有熟悉地名都歸為人文活動。 |
| SG7：地名可能變遷 | 康軒 L5 跨年度趨勢 | 地名是否一旦形成就永遠不變？ | 把地名當成固定不變的標籤。 |
| SG8：探索方式可多元 | 康軒 L5 題型 C | 上網、圖書館、訪談、文物館是否都可作為探索方式？ | 把單一方式寫成唯一正解。 |
| SG9：訪談要事先準備 | 康軒 L5 誘答統計 | 訪問長輩前要不要設計問題、約時間、取得同意？ | 把「直接去問」設為理想流程。 |
| SG10：網路資料要查證 | 康軒 L5 110-113 趨勢 | 上網找到資料後能不能直接複製引用？ | 把網路搜尋等同資料正確。 |
| SG11：多重由來要保留彈性 | 康軒 L5 迷思 M6 | 一個地名是否可能有不同說法或歷史層次？ | 強迫所有地名只有單一、絕對來源。 |
| SG12：出題要測推理不是舊稱背誦 | KL3 Audit Gateway | 題目是否讓學生根據地方特徵推測命名原因？ | 只考「某地舊稱是什麼」的孤立記憶題。 |

## §三 探究活動與生活連結

### 3.1 地名由來分類卡

提供地名卡與線索卡，讓學生分成自然環境與人文活動兩大類，再細分為地形、氣候、植物、人物、居民活動、族群語言等。

| 分類 | 判斷問題 | 可能例子 |
|:--|:--|:--|
| 地形 | 是否和山形、岩石、河川、湖泊等自然形狀有關？ | 鶯歌的岩石形狀意象。 |
| 氣候 | 是否和溫暖、寒冷、多風等氣候感受有關？ | 恆春的溫暖意象。 |
| 植物 | 是否和當地常見植物或植被有關？ | 竹山、朴子。 |
| 居民活動 | 是否和耕作、交易、信仰、官署、產業有關？ | 官田、關廟等人文線索。 |
| 族群語言 | 是否來自原住民族語、客語、閩南語或其他語言？ | 烏來與原住民族語。 |

**守衛點**：分類不是看字面第一印象，而是要說出「地方特徵證據」。

### 3.2 學校附近地名小調查

學生選一個學校附近或住家附近的地名，記錄它的位置、名稱、可能由來與已查到的資料來源。

| 欄位 | 學生要填什麼 | 守衛問題 |
|:--|:--|:--|
| 地名 | 路名、里名、地區名或公共場所名 | 名稱是否正確？是否有不同寫法？ |
| 初步猜測 | 可能和自然或人文哪一類有關 | 這是猜測還是已查證？ |
| 查證資料 | 網站、書籍、地圖、訪談或文物館資料 | 資料來源是否可說明？ |
| 結論 | 目前最可信的由來 | 是否至少比對兩種資料？ |

**守衛點**：允許學生保留「尚未確定」，但不能把未查證猜測當成結論。

### 3.3 訪談耆老或長輩 SOP

以「訪問家中長輩或地方人士」練習地名探索。

1. 先選定要問的地名。
2. 事先列出 3-5 個問題，例如「這個地名以前也這樣叫嗎？」「您聽過哪些由來說法？」
3. 約定訪談時間並取得同意。
4. 訪談時記錄重點，不任意改寫受訪者意思。
5. 訪談後再用書籍、地圖或網路資料查證。

**守衛點**：訪談不是臨時閒聊；需要問題設計、禮貌與資料整理。

### 3.4 網路資料查證任務

給學生兩段不同來源的地名說明，讓學生比較哪一段有標明來源、是否有日期、是否能和地方文史資料互相印證。

| 查核面向 | 問題 |
|:--|:--|
| 來源 | 是政府、學校、地方文史館、百科，還是不明網站？ |
| 內容 | 是否只講傳說，還是也說明自然或人文證據？ |
| 日期 | 資料是否可能過時？ |
| 比對 | 是否能找到第二個資料來源支持？ |

**守衛點**：上網是探索方法之一，不是可信度保證。

### 3.5 地名變遷時間線

選用地方舊稱與現稱案例，讓學生排列「早期稱呼、行政調整、現在名稱」的時間線，討論地名為何會改變。

**可討論原因**：行政區劃改變、書寫方式改變、地方發展、文化保存、居民習慣或政策調整。  
**守衛點**：地名會保存歷史，也可能在歷史中變化。

### 3.6 從地名推測地方特色

依 KL3 Audit Gateway，地名類題型應改為「依此地特徵推測命名原因」。活動可給學生地方特徵描述，請學生判斷可能命名因素。

| 地方特徵 | 可能命名因素 |
|:--|:--|
| 附近有形狀特殊的岩石或山形 | 地形 |
| 早期以某種植物聞名 | 植物 |
| 名稱來自原住民族語音譯 | 族群語言 |
| 與廟宇、耕作、官署或市場活動有關 | 居民活動 |

**守衛點**：重點是推理理由，不是背地名清單。
