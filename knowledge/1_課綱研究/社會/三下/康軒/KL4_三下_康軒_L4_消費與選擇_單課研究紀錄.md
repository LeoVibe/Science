## §一 課綱連結與學習總目標

### 1.1 課綱連結

| 類型 | code | 本課對應 |
|:--|:--|:--|
| 學習表現 | **1a-II-1** | 辨識日常消費活動、商品資訊、廣告訊息與生活環境之間的關聯。 |
| 學習表現 | **2b-II-2** | 了解自己的需求、慾望與消費責任，並對消費選擇負責。 |
| 學習表現 | **3a-II-1** | 透過蒐集商品標示、價格、廣告與標章資料，進行比較與判斷。 |
| 學習表現 | **3d-II-1** | 遇到消費爭議時，選擇合適方式求助、申訴或尋求大人協助。 |

| 學習內容 | **Bd-II-1** | 個人需求與資源運用、消費判斷；本課聚焦理性選擇、環保消費與消費安全。 |
| 學習內容 | **Cb-II-1** | 地方公共服務與居民生活的連結；本課以消費者服務專線與正式申訴管道作延伸。 |

### 1.2 單課學習總目標

學生完成本課後，應能：

1. 分辨生活中的「需要」與「想要」，理解需要應優先於想要。
2. 說明理性消費不是只看價格，而是同時考量需求、預算、品質、標示、期限、售後與環境影響。
3. 辨識商品標示的重要資訊，例如內容物、保存期限、使用方式、產地、成分、價格或警語。
4. 理解廣告可能包含商品介紹、打折促銷、明星代言或誇大功能，不能把廣告當作唯一購買依據。
5. 分辨環保標章、節能標章與省水標章的用途，並能連結到降低環境負擔的消費行為。
6. 說明自備購物袋、減少過度包裝、選擇有認證的環保商品等行為，都是環保消費的一部分。
7. 知道統一發票或購買證明有助於兌獎、記帳、查核交易與處理退換貨或消費爭議。
8. 遇到消費爭議時，能保留證明、先理性溝通，必要時撥打消費者服務專線 **1950**，而不是誤用 1999、1922 或 1590。
9. 理解信用卡、折扣與品牌都不能取代理性判斷；付款工具、促銷訊息與知名度不是「想買就買」的理由。
10. 能把本課和 L3《消費與生活》區隔：L3 偏交易工具與購物方式，L4 偏消費判斷、廣告辨識、標章、發票與消費權益。

## §二 核心知識點地圖

### 2.1 本課主要概念拆解

| 核心知識點 | 正確概念 | 典型生活情境 | 守衛點 |
|:--|:--|:--|:--|
| 需要 vs 想要 | 需要是維持生活、健康或學習的必要項目；想要是希望擁有但未必必要的物品或服務。 | 鉛筆寫不出字需要買筆；看到新款玩具很想買但家裡已有類似玩具。 | 不把「我很想要」等同「我需要」；購物應先處理需要。 |
| 預算與資源有限 | 金錢、時間與家庭資源有限，消費時要量力而為。 | 零用錢只能買一樣東西，要在午餐、水壺、玩具間做選擇。 | 不把折扣、信用卡或家人付款當作資源無限。 |
| 理性消費判斷 | 購物前應看需求、價格、品質、標示、保存期限、售後服務與是否適合自己。 | 買牛奶前看保存期限；買書包前比較價格、容量、耐用度。 | 廣告、品牌、明星代言、折扣都不能取代實際比較。 |
| 商品標示 | 商品標示提供安全、品質、使用與保存資訊，是購物判斷的重要依據。 | 食品看成分與期限；玩具看適用年齡與安全標示。 | 知名品牌也要看標示，不能因品牌熟悉就省略查核。 |
| 比較消費 | 多看幾家、多比較規格與價格，有助於避免衝動消費。 | 同樣容量的水壺，確認材質、價格與保固後再買。 | 價格最高不一定品質最好，價格最低也不一定最適合。 |
| 廣告訊息辨識 | 廣告可能是商品介紹、打折促銷、明星代言或誇大功能，目的在吸引購買。 | 「跳樓大出清」屬打折促銷；名人推薦屬明星代言。 | 廣告不是保證真實或保證適合；要回到需求與證據。 |
| 打折促銷 | 打折是商家吸引購買的方式，不代表一定需要或一定划算。 | 「買一送一」可能造成買太多、吃不完或用不到。 | 有折扣不等於應該購買；仍需看需求、期限與預算。 |
| 誇大功能 | 廣告可能把效果說得過滿，學生需辨識不合理承諾。 | 「用了立刻變聰明」「穿了跑最快」等誇大說法。 | 看到絕對化、神奇化語句要提高警覺。 |
| 環保標章 | 環保標章表示商品較符合環境保護相關標準，可降低環境負擔。 | 選購有環保標章的衛生紙或清潔用品。 | 環保標章不是節能標章或省水標章，不能混用。 |
| 節能標章 | 節能標章常用於電器或能源使用相關商品，表示能源效率較佳。 | 家人買電風扇、冷氣或燈具時看節能標章。 | 節能重點在用電效率，不是所有環保商品都貼節能標章。 |
| 省水標章 | 省水標章常用於水龍頭、馬桶、蓮蓬頭等用水設備，表示較節省用水。 | 更換蓮蓬頭時看是否具省水標章。 | 省水重點在用水設備，不等於節能標章。 |
| 環保消費行為 | 環保消費包含自備購物袋、少用一次性用品、減少過度包裝、選擇合適數量。 | 去超商自備袋子；不因促銷買過量零食。 | 環保消費不是只買有標章商品，也包含少買、少浪費。 |
| 統一發票與購買證明 | 統一發票可兌獎，也可作為交易證明，協助記帳、退換貨與消費爭議處理。 | 商品壞掉要退換時，需要購買證明。 | 發票不是只有兌獎功能；不要買完就隨手丟掉。 |
| 消費爭議處理 | 遇到消費糾紛應保留證據、理性溝通，必要時請大人協助或撥打 1950。 | 買到瑕疵商品，先保留發票與商品，向店家詢問退換貨。 | 1950 是消費者服務專線；1999 是政府便民，1922 是疫情，1590 不是正確答案。 |
| L3 與 L4 邊界 | L3 重在交易工具和購物方式；L4 重在如何選擇、如何判斷與如何維護權益。 | 信用卡本身是 L3 工具；「有信用卡就想買什麼都買」屬 L4 理性消費迷思。 | 不把付款工具知識誤當成消費能力無上限。 |

### 2.2 守衛點總表

| 守衛點 | 來源訊號 | 診斷問法 | 出題與教學應避免 |
|:--|:--|:--|:--|
| SG1：需要優先於想要 | 康軒 L4 題型 E；KL3 C1 | 這個東西是生活必需，還是只是想擁有？如果錢不夠先買哪個？ | 把「想要」描述成必需品，或用道德口號取代理由判斷。 |
| SG2：價格不等於品質 | KL3 C2；購物注意事項高頻 | 最貴的商品一定最好嗎？最便宜的一定最划算嗎？ | 讓價格成為唯一判準，忽略規格、用途、品質與標示。 |
| SG3：廣告不是購買依據本身 | 康軒 L4 題型 B、誘答統計 | 電視廣告出現過，能不能當成購買的主要理由？ | 把「有廣告」「名人推薦」設為正確購物理由。 |
| SG4：廣告四分類要能情境辨識 | 康軒 L4 題型 D；KL3 4.2 | 「跳樓大出清」屬哪一種廣告訊息？ | 只背分類名稱，沒有對應情境句。 |
| SG5：折扣不等於需要 | 康軒 L4 誘答「有折扣一定要多買」 | 打折時是否一定要買更多？買了會不會用不到或浪費？ | 把促銷等同划算，未檢查需求、期限與數量。 |
| SG6：三種標章不可混淆 | 康軒 L4 題型 A；KL3 H1 | 環保、節能、省水分別適合用在哪類商品？ | 把環保標章、節能標章、省水標章視為同一種標章。 |
| SG7：環保消費包含少浪費 | 康軒 L4 出題方向；KL3 3.2 | 除了買有標章商品，還有哪些方式能降低環境負擔？ | 把環保消費縮小成「買比較貴的綠色商品」。 |
| SG8：1950 是消費者服務專線 | 康軒 L4 題型 C；KL3 C4 | 發生消費爭議可以撥哪支電話？1999、1922 分別是什麼？ | 混用 1950、1999、1922、1590。 |
| SG9：發票是交易證明 | 康軒 L4 出題方向；KL3 4.2 | 退換貨或申訴時，為什麼要保留發票？ | 只教發票可兌獎，忽略權益與記帳功能。 |
| SG10：品牌不能取代標示 | 康軒 L4 迷思 M7 | 知名品牌是否仍要看保存期限、成分與使用說明？ | 把品牌信任當作免查核理由。 |
| SG11：信用卡不是任意購買許可 | 康軒 L4 誘答；L3/L4 邊界 | 有信用卡是否代表可以想買什麼就買什麼？ | 把付款工具等同購買能力或消費自由無上限。 |
| SG12：消費爭議要理性處理 | 康軒 L4 迷思 M6 | 買到瑕疵品時，第一步應該做什麼？ | 把「找商家大吵大鬧」設計成合理解法。 |

## §三 探究活動與生活連結

### 3.1 需要/想要四格判斷

提供生活物品卡，例如早餐、鉛筆、玩具、運動鞋、書包、飲料、手機遊戲點數。學生依「是否生活必要」與「是否目前急需」分成四格，再討論如果預算有限應如何排序。

| 分類 | 判斷問題 | 可能例子 |
|:--|:--|:--|
| 需要且急需 | 沒有它會影響生活、健康或學習嗎？ | 午餐、壞掉後需替換的眼鏡。 |
| 需要但不急 | 目前還能使用，可先規劃嗎？ | 尚可使用但快壞的書包。 |
| 想要但可延後 | 不買也不影響生活嗎？ | 新款玩具、第二個相似文具盒。 |
| 不需要且容易浪費 | 買了可能放著不用或用不完嗎？ | 因買一送一而多買太多零食。 |

**守衛點**：活動重點不是禁止想要，而是讓學生說出選擇理由與排序依據。

### 3.2 廣告偵探任務

讓學生蒐集或閱讀模擬廣告句，判斷屬於商品介紹、打折促銷、明星代言或誇大功能，再補寫「購買前還要查什麼」。

| 廣告句 | 可能類型 | 購買前查核 |
|:--|:--|:--|
| 「跳樓大出清，今天不買會後悔。」 | 打折促銷 | 是否真的需要、是否過期、是否有更適合商品。 |
| 「知名球星推薦的運動鞋。」 | 明星代言 | 尺寸、用途、價格、耐用度。 |
| 「喝了立刻變聰明。」 | 誇大功能 | 是否有合理證據，是否只是誇張說法。 |
| 「容量 500 毫升，可保冷 6 小時。」 | 商品介紹 | 標示是否清楚，價格是否合理。 |

**守衛點**：不要把所有廣告都視為假訊息；正確目標是辨識目的、查證資訊、回到需求。

### 3.3 商品標示與比價實作

提供兩到三個同類商品包裝或模擬資料卡，請學生比較價格、容量、保存期限、標章、成分、適用對象與售後資訊。

| 比較項目 | 看什麼 | 守衛問題 |
|:--|:--|:--|
| 價格 | 單價、容量與數量 | 便宜是否因容量較少或快到期？ |
| 標示 | 成分、期限、產地、使用方式 | 標示不清是否適合購買？ |
| 品質 | 材質、保固、是否符合用途 | 貴的是否真的比較適合？ |
| 需求 | 是否現在需要 | 只是看到廣告或折扣嗎？ |

**守衛點**：比價不是只找最低價格，而是比較「是否適合需求」。

### 3.4 標章連連看與生活分類

使用環保標章、節能標章、省水標章圖卡與商品情境卡配對。

| 標章 | 常見連結 | 生活例子 |
|:--|:--|:--|
| 環保標章 | 商品較符合環境保護標準 | 衛生紙、清潔用品、文具。 |
| 節能標章 | 用電效率較佳 | 電風扇、冷氣、燈具。 |
| 省水標章 | 用水設備較節省用水 | 水龍頭、馬桶、蓮蓬頭。 |

**守衛點**：若學生只說「都很環保」，需追問「它節省的是電、水，還是整體環境負擔」。

### 3.5 消費爭議處理流程演練

提供情境：「買到故障玩具」「食品過期」「網購商品和照片差很多」。學生排列處理步驟。

1. 保留商品、包裝、發票或購買證明。
2. 向家人或老師說明狀況。
3. 與店家理性溝通退換貨或處理方式。
4. 仍無法解決時，尋求正式申訴管道或撥打 **1950**。

**守衛點**：消費爭議不是靠吵架解決；正式管道需要證據與清楚說明。

### 3.6 一週環保消費紀錄

學生記錄一週內自己或家人做過的環保消費行為，例如自備購物袋、少拿免洗餐具、選擇簡單包裝、避免買過量、選擇有合適標章商品。

**產出**：一張「我家的環保消費清單」，每項行為需寫出降低哪一種浪費或環境負擔。  
**守衛點**：不要求家庭額外消費；少買、重複使用、避免浪費也屬於環保消費。

## §四 迷思分析

| # | 迷思描述 | 來源反推 | 正確觀念 | 守衛點 |

| M2 | 有打折就要多買，錯過很可惜。 | 康軒 L4 迷思 M2；誘答統計「有折扣一定要多買」。 | 折扣只是促銷，仍要看是否需要、是否用得完、價格是否合理。 | SG5：折扣題必檢查需求、數量、期限與浪費風險。 |
| M3 | 廣告上的資訊都真實可信。 | 康軒 L4 迷思 M3；KL3 K7。 | 廣告有吸引購買的目的，可能誇大或只呈現有利資訊，需查證。 | SG3：不能把「廣告說」當作正確理由。 |
| M4 | 商品有在電視廣告出現過，所以是好的購買選擇。 | 康軒 L4 題型 B。 | 電視廣告不是購物注意事項；仍要看標示、價格、品質與需求。 | SG3：選項若出現「廣告出現過」，通常是誘答。 |
| M5 | 「跳樓大出清」是商品介紹或誇大功能。 | 康軒 L4 題型 D。 | 「跳樓大出清」主要是打折促銷訊息。 | SG4：廣告分類要用情境句判斷，不只背名稱。 |
| M6 | 使用信用卡購物，想買什麼就買什麼。 | 康軒 L4 迷思 M4；L3/L4 邊界守衛。 | 信用卡只是付款工具，仍需按帳單付款並量力消費。 | SG11：付款工具不等於資源無限。 |
| M7 | 節能標章、環保標章、省水標章都一樣。 | 康軒 L4 迷思 M5；KL3 H1。 | 三種標章用途不同：環保偏整體環境標準，節能偏用電效率，省水偏用水設備。 | SG6：連連看題要能配商品類型與用途。 |
| M8 | 環保消費就是買比較貴或看起來綠色的商品。 | KL3 W2 補強；康軒 L4 環保消費高頻。 | 環保消費包含減少浪費、自備購物袋、避免過度包裝與選擇合適標章商品。 | SG7：少買、少浪費也是環保消費。 |
| M9 | 消費糾紛可以直接找商家大吵大鬧。 | 康軒 L4 迷思 M6。 | 應保留證明、理性溝通，必要時請大人協助或走正式申訴管道。 | SG12：情境題要考處理流程，而非情緒反應。 |
| M10 | 消費者服務專線是 1999、1922 或 1590。 | 康軒 L4 題型 C；KL3 C4。 | 消費者服務專線是 **1950**；1999 是政府便民，1922 是疫情相關。 | SG8：電話題需安排相近號碼誘答並要求辨別用途。 |
| M11 | 購買知名品牌就不需要看商品標示。 | 康軒 L4 迷思 M7。 | 品牌不能取代標示，仍要確認期限、成分、規格、適用對象與使用方式。 | SG10：知名品牌題應設計標示查核情境。 |
| M12 | 越貴的商品品質一定越好。 | KL3 C2；購物注意事項高頻。 | 價格不等於品質，要比較需求、規格、標示、耐用度與售後。 | SG2：比價題不可只問價格高低。 |
| M13 | 統一發票只有兌獎用途，和消費權益無關。 | 康軒 L4 出題方向；KL3 4.2。 | 發票也是購買證明，可協助退換貨、記帳與消費爭議處理。 | SG9：發票題需連到交易證明與權益。 |
| M14 | 想買前只要問「錢夠不夠」，不用想用途與後果。 | KL3 Bd-II-1 消費判斷延伸。 | 理性消費需同時考量需求、預算、品質、標示、環境與是否造成浪費。 | SG1/SG2/SG7：消費決策題需多因素判斷。 |
