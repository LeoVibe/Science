## §一 課綱連結與學習總目標

### 1.1 課綱連結

| 類型 | code | 本課對應 |
|:--|:--|:--|
| 學習表現 | **1a-II-1** | 辨識居住地方的行政層級、居民活動與生活環境特性。 |
| 學習表現 | **2a-II-1** | 感受自己與家鄉、社區居民和多元文化的連結。 |
| 學習表現 | **2b-II-2** | 了解不同居民的生活背景，能以尊重態度看待新住民與外來文化。 |
| 學習表現 | **3a-II-1** | 透過地址、門牌、地圖、訪問與生活觀察，蒐集認識家鄉的資料。 |
| 學習表現 | **3d-II-1** | 選擇合適方式參與家鄉公共事務，如公聽會、協調會、意見反映。 |

| 學習內容 | **Ab-II-1** | 居住地方的人文與自然環境特色。 |
| 學習內容 | **Cb-II-1** | 地方上的公共事務與居民參與。 |
| 學習內容 | **Cc-II-1** | 地方組織、村里辦公處、里鄰制度與其功能。 |

### 1.2 單課學習總目標

學生完成本課後，應能：

1. 依「鄰 → 村里 → 鄉鎮市區 → 縣市」說明自己居住地方的行政層級，並知道「鄰」是由相近住戶組成的基層行政單位。
2. 依生活情境判斷應尋求哪一類行政機關或公共服務，而不是把所有問題都推給公所、警察或里長。
3. 區分里長與鄰長的產生方式及職責：里長由居民選舉產生，鄰長通常由村里長任命指派並協助辦理該鄰事務。
4. 理解家鄉公共事務需要居民共同參與，能辨識公聽會、協調會、里民大會、意見箱、網站留言等參與或反映管道。
5. 認識新住民移居常見原因與多元文化交流的價值，能避免把「旅遊、購物」誤認為移居主因，也不把外來文化視為威脅。

## §二 核心知識點地圖

### 2.1 本課主要概念拆解

| 核心知識點 | 正確概念 | 典型生活情境 | 守衛點 |
|:--|:--|:--|:--|
| 行政單位層級 | 鄰由相近住戶組成；鄰上有村里，再上為鄉鎮市區、縣市。 | 讀懂自己的地址、門牌或戶口名簿。 | 問「最小行政單位」時答案是**鄰**，不是里。 |
| 居住地址與家鄉定位 | 地址可呈現縣市、鄉鎮市區、村里、鄰、路街巷弄號等空間層次。 | 查詢學校或住家所在行政區。 | 不要求學生公開完整住址；教學用可改成學校地址或虛擬地址。 |
| 行政機關職能 | 戶政處理戶籍、結婚登記；衛生所處理健康防疫；警察維護治安；消防處理火災與救護；公所辦理地方行政。 | 結婚登記、登革熱防治、火災、失物、地方建設。 | 不可把「公所」當萬能機關；題幹要有明確事件。 |
| 環境與清潔分工 | 清運垃圾、環境清潔通常屬清潔隊或環保相關單位；衛生所偏健康、防疫、保健。 | 社區垃圾堆積、環境消毒、防疫宣導。 | 「衛生」二字容易誘使學生選衛生所，需用分工破解。 |
| 里長與鄰長 | 里長由居民選舉產生；鄰長通常由村里長任命，協助傳達、聯繫、辦理鄰內事務。 | 里民大會通知、鄰內資料傳達、協助里長。 | 「基層職務都要選舉」是高頻錯誤。 |
| 公共事務參與 | 居民可參與協調會、公聽會、里民大會，也可透過意見箱、網站、投書、民意代表等管道反映。 | 社區公園整修、交通安全、環境改善。 | 公共事務不是只靠里長、專家、政府或志工。 |
| 家鄉活動類型 | 公聽會討論公共議題；跳蚤市場促進交流與再利用；節慶活動凝聚地方認同；義賣或志工服務回應社區需要。 | 學校或社區辦活動、居民參與討論。 | 不把所有家鄉活動都視為「娛樂」或「賺錢」。 |
| 志工服務 | 志工可提供環保、關懷、巡守、活動協助等服務；小學生參與須符合年齡與安全。 | 探訪長者、整理環境、協助活動。 | 不讓學生誤以為任何志工任務都適合兒童。 |
| 新住民與多元文化 | 新住民常因求學、工作、結婚等原因移居台灣，帶來飲食、語言、節慶與生活經驗交流。 | 班上或社區有不同國家背景居民。 | 「旅遊、購物」不是移居主因；多元文化不是本土文化的敵人。 |
| 常見公共服務電話 | 110 警察、119 消防救護、1999 地方政府便民服務、1950 消費者服務。若涉及家暴或兒少保護，應查證教材採用的專線設定。 | 走失、火災、消費糾紛、市政反映。 | 電話題必須設情境，不可只背號碼；110、119、1950、1999 易混。 |

### 2.2 知識點之間的學習路徑

1. **先定位**：我住在哪裡？從地址與行政層級建立空間歸屬。
2. **再分工**：家鄉有哪些行政機關與地方組織？不同問題應找不同單位。
3. **再參與**：居民不是旁觀者，可用合適方式反映意見與參與公共事務。
4. **再擴大**：家鄉不是單一文化共同體，而是由不同背景居民共同生活、互相影響。

## §三 探究活動與生活連結

### 3.1 地址層級拆解

以學校地址或虛擬地址為例，讓學生標出縣市、鄉鎮市區、村里、鄰、路街巷弄號，再反推每個層級的功能。此活動對應行政層級題，重點不是背順序，而是知道「鄰」與「里」的包含關係。

**守衛點**：避免要求學生公開完整個人住址；可用學校、圖書館或虛擬家庭地址。

### 3.2 「我該找誰？」情境卡

設計生活事件卡，例如：

| 事件 | 較合適的單位或管道 | 判斷理由 |
|:--|:--|:--|
| 家人要辦理結婚登記 | 戶政事務所 | 涉及戶籍與身分登記。 |
| 社區有登革熱孳生源疑慮 | 衛生所 / 衛生局與相關防疫單位 | 涉及健康、防疫與病媒防治。 |
| 公園垃圾長期未清 | 清潔隊 / 公所相關單位 / 1999 | 涉及環境清潔與市政反映。 |
| 發生火災或緊急救護 | 119 | 消防與救護。 |
| 路口交通危險，希望改善號誌 | 里辦公處、民意代表、1999 或交通相關單位 | 屬公共事務，需要反映與協調。 |

**守衛點**：題目要讓學生根據「事件性質」選單位，而不是只靠單位名稱直覺。

### 3.3 公共事務參與模擬

以「社區公園是否增設照明」「學校附近路口是否需要交通志工」「社區要不要辦跳蚤市場」作為議題，讓學生分組扮演居民、里長、鄰長、學生、店家、志工，練習提出理由、聆聽不同意見、形成可行建議。

**守衛點**：公共參與不是最大聲者勝，也不是把責任丟給單一權威；要能說明證據、需求與可能影響。

### 3.4 新住民與多元文化觀察

從社區商店、飲食、語言、節慶、家庭故事或學校活動觀察多元文化如何進入日常生活。若安排訪談，需先取得同意、尊重隱私，不把新住民當作「被展示的文化樣本」。

**守衛點**：學生要能說出「尊重與交流」的具體行為，例如願意了解、避免嘲笑口音、尊重不同飲食與節慶，而不是只背「要尊重」。

## §四 迷思分析

| # | 迷思描述 | 來源反推 | 正確觀念 | 守衛點 |
|:--:|:--|:--|:--|:--|
| M1 | 「里」是最小的行政單位。 | 康軒 L1 行政層級選擇題高頻。 | 鄰才是由相近住戶組成的基層行政單位，里由若干鄰組成。 | 題幹若問「由相連或相近住戶組成」，答案鎖定鄰。 |
| M2 | 鄰長和里長一樣都由居民選舉產生。 | 考古題反覆考「鄰長由村里長任命指派」。 | 里長由居民選舉，鄰長通常由里長任命並協助辦理鄰內事務。 | 必須同時考「選舉 vs 任命」，不可只問職稱。 |
| M3 | 區公所或公所可以處理所有地方生活問題。 | 結婚登記題常以區公所作誘答。 | 不同機關有不同職能；戶籍、衛生、警政、消防、市政反映各有分工。 | 事件要具體，讓學生依職能而非權威大小判斷。 |
| M4 | 衛生所負責垃圾清掃、清運或所有環境問題。 | 「衛生」與「環境衛生」混淆，為高頻誘答。 | 衛生所偏健康、防疫與保健；垃圾清運通常屬清潔隊或環保相關單位。 | 出題時可用「登革熱防治」與「垃圾清運」對照。 |
| M5 | 公共服務電話可以混用，只要是求助都能打同一支。 | 110、119、1999、1950 類題易混。 | 110 警察、119 消防救護、1999 市政便民、1950 消費者服務，各有適用情境。 | 電話題應搭配清楚生活情境，避免純背號碼。 |
| M6 | 家鄉公共事務只需要里長、政府、專家或志工參加。 | 協調會、公聽會題常設「在家等待」或「少數人負責」誘答。 | 居民也是家鄉公共事務的參與者，可表達意見、蒐集資料、參與會議。 | 把「積極參與」具體化為參加會議、提出意見、整理資料。 |
| M7 | 小學生太小，對家鄉問題沒有影響力。 | KL3 跨版本迷思 C5「公民無力感」。 | 兒童可以用合適方式參與，如觀察、訪談、提案、提醒大人、參與安全志工活動。 | 不要求學生承擔成人責任，但要肯定有限且合宜的行動。 |
| M8 | 新住民移居台灣主要是為了旅遊或購物。 | 康軒 L1 新住民題常以購物作錯誤選項。 | 常見移居原因包含求學、工作、結婚等長期生活因素。 | 題目可用「選出錯誤原因」檢核學生是否理解移居與觀光不同。 |
| M9 | 外來文化會衝擊本土文化，因此應避免接觸。 | 多元文化態度題的高頻誘答。 | 多元文化交流可豐富家鄉生活；應以尊重、理解與包容態度互動。 | 不把「尊重」寫成空泛口號，要搭配具體行為。 |
| M10 | 家鄉活動都是休閒娛樂，和公共事務或社區互助無關。 | 家鄉活動、公聽會、跳蚤市場、義賣題混合出現。 | 家鄉活動有多種目的：討論問題、凝聚情感、資源再利用、關懷服務。 | 需辨識活動目的，而非只看活動名稱。 |
| M11 | 所有志工工作都適合小學生參與。 | 志工服務內容題常考服務對象與任務。 | 小學生可參與環保、關懷、活動協助等安全且合宜的服務；巡守、救災等需成人或專業人員。 | 出題需區分「想幫忙」與「能安全合宜地幫忙」。 |
