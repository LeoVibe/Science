## 🧠 第一章：高年級學童認知發展總論 — 學術基礎與交叉驗證

### 1.1 皮亞傑 (Piaget) 認知發展理論定錨

國小高年級學童（10-12 歲）處於**「具體運思期晚期 → 形式運思期初期」**的關鍵過渡帶。此過渡並非瞬間跳躍，而是一段連續且具個體差異的漸進歷程。

| 認知特徵 | G5（10-11 歲）具體運思晚期 | G6（11-12 歲）形式運思初期 | 跨年級命題差異化策略 |
|:---|:---|:---|:---|
| **抽象思維** | 能處理具體情境下的邏輯推演，但仍高度依賴實物或圖示鷹架 | 開始能處理純符號的抽象概念（如未知數 $x$、假設命題） | G5 每道抽象題須搭配具體情境鷹架；G6 可逐步減少鷹架比例 |
| **假設演繹推理** | 初步萌芽，需要引導 | 能自行設定「如果...那麼...」的假設並驗證 | G6 可設計實驗假設推理題；G5 以觀察推論為主 |
| **後設認知** | 知道自己不懂，但難以精準定位問題 | 能「思考自己的思考過程」，自我監控與調節學習策略 | G6 可加入「找出解題步驟的錯誤」反思型題目 |
| **去中心化** | 仍傾向以自身經驗為中心理解世界 | 開始能站在他人立場思考（同理心與多元觀點） | G6 社會科可加入歷史同理心與價值思辨題 |

### 1.2 台灣在地實證交叉驗證

以下研究經交叉比對，確認皮亞傑理論在台灣高年級學童群體中的適用性：

| 研究來源 | 主要發現 | 對 Eidos 的設計啟示 |
|:---|:---|:---|
| 碩士論文《國小高年級閱讀理解後設認知量表之編製》（國圖） | **六年級後設認知分數顯著高於五年級**，符合理論預測 | G6 國語科可增加反思型與自我監控型題目比例 |
| 碩士論文《重述故事結合故事結構教學對高年級閱讀後設認知的影響》 | 特定教學策略可有效提升此年齡層的後設認知能力 | 題目解析可融入後設認知引導，示範「如何思考」 |
| 國內追蹤研究（G3 至 G9 後設認知發展調查） | 後設認知能力確實隨年齡呈**梯度增長**，年齡較大者能力較佳 | G5→G6 的題庫難度應呈現可觀測的梯度提升 |

### 1.3 對皮亞傑理論的批判性修正 — Eidos 必須納入考量

| 修正觀點 | 來源 | 對題庫設計的影響 |
|:---|:---|:---|
| **發展是連續漸進，非階段跳躍** | 新皮亞傑學派 (Neo-Piagetian) | 約 30-50% 的高年級生在特定領域仍需具體鷹架 → 每道抽象題應搭配暖身題 |
| **認知發展具領域特定性** | Case (1992), Demetriou | 同一學童可能國語閱讀推論佳但數學代數弱 → 各科須獨立校準難度 |
| **社會文化脈絡影響學習** | Vygotsky 近側發展區 (ZPD) | 台灣升學壓力背景下，題目情境須緊貼台灣學童日常生活經驗 |
| **鷹架教學 (Scaffolding) 的必要性** | Bruner | 能力較弱的學生須透過情境線索（圖片、表格）進行推論，而非死背 |

## 📊 第二章：108 課綱第三學習階段對標 — 跨科共同框架

### 2.1 核心素養三面九項

108 課綱以「核心素養」為導向，分三大面向、九大項目。高年級的命題設計必須覆蓋以下面向：

| 面向 | 核心素養項目 | 高年級命題體現 |
|:---|:---|:---|
| **自主行動** | 身心素質與自我精進 | 後設認知反思題（國語/數學） |
| | 系統思考與解決問題 | 多步驟情境題（數學/自然） |
| | 規劃執行與創新應變 | 實驗設計題（自然） |
| **溝通互動** | 符號運用與溝通表達 | 圖表判讀題（數學/社會）、語境溝通題（英語） |
| | 科技資訊與媒體素養 | 媒體識讀題（社會）、資訊擷取題（國語） |
| | 藝術涵養與美感素養 | 修辭賞析題（國語） |
| **社會參與** | 道德實踐與公民意識 | 公民決策情境題（社會） |
| | 人際關係與團隊合作 | 協作情境題（社會/英語） |
| | 多元文化與國際理解 | 跨文化題（英語/社會） |

### 2.2 素養導向評量的跨科共同設計原則

根據教育部、NAER 與臺灣教育評論月刊 (ATER) 的研究，高年級素養導向評量必須遵循：

| 傳統評量 | 素養導向評量 | Eidos 全科設計對策 |
|:---|:---|:---|
| 考記憶與背誦 | 考知識的**遷移與運用** | 所有科目以生活情境包裝題目 |
| 題幹簡短直接 | **長文本、跨文本、圖表整合** | 前端 UI 須支援長題幹排版與圖表嵌入 |
| 單一學科知識 | **跨領域整合** | 可設計跨科情境題（如：數學計算 + 社會議題） |
| 單一標準答案 | 強調**分析歷程**與多元解法 | 誘答須包含「歷程錯誤但直覺合理」的選項 |
| 紙筆測驗為主 | 多元評量（實作、口述、檔案） | 短期以選擇題為主，未來可擴展至非選擇題 |

## 🎯 第三章：五大科目學習標的與精準測驗規劃 — 以學術研究為據

### 📐 3.1 數學科 (Mathematics)

#### 108 課綱第三學習階段學習內容代碼（來源：NAER 數學領域課程手冊定稿版）

| 代碼 | 主題 | G5 核心內容 | G6 核心內容（深化） |
|:---:|:---|:---|:---|
| **n-III** | 數與量 | 分數加減（異分母）；小數乘除；因數與倍數 | 分數四則運算（含分數乘除法）；比與比值；概數與估算 |
| **r-III** | 關係 | 數字規律探索；簡單等式推理 | 等量公理與未知數（代數啟蒙）；**正比關係**；**速率** |
| **s-III** | 空間與形狀 | 三角形與四邊形性質；體積初探 | 圓周率與圓面積；扇形面積；**柱體表面積與體積** |
| **d-III** | 資料與不確定性 | 長條圖、折線圖製作與報讀 | **圓形圖**的製作與報讀；百分率的統計應用 |

#### 迷思概念實證地圖 — 台灣碩博士論文

**〔G6 核心〕速率概念**（六下公認最難單元）：

| 迷思次領域 | 學生表現 | 迷思根源 | 文獻來源 |
|:---|:---|:---|:---|
| 速率二維比較 | 時間與距離皆不同時的比較表現顯著低落 | 對速率定義不理解 | 臺南大學碩士論文 |
| 速率單位換算 | 公里/時 ↔ 公尺/分 的化聚頻繁出錯 | 單位化聚觀念不清 | 同上 |
| 平均速率 | 將不同速率直接相加取平均 | 誤解平均速率意義（應為總距離÷總時間） | 國小數學工作坊研究 |
| 速率應用問題 | 從長篇文字中擷取數值並建立算式的能力不足 | 閱讀理解 + 數學建模雙重認知負荷 | 教育大學教學實驗 |

**〔G5→G6 銜接〕分數概念**：

| 迷思次領域 | 文獻來源 |
|:---|:---|
| 等值分數概念與測量意義理解不足 | 北京師範大學合作研究（含台灣五六年級樣本） |
| 圖形表徵 ↔ 符號表徵轉換的高頻出錯 | 清華大學碩士論文 |
| 分數乘除法的抽象性導致低成就學童迷思 | 臺灣師範大學碩士論文（多篇） |

#### 高年級數學認知配比（來源：`KL2_數學科共同發展總綱.md`，本處深化 G6 說明）

```
G5 配比：2-4-4（事實提取 20% / 邏輯推論 40% / 高階思辨 40%）
G6 配比：1-4-5（事實提取 10% / 邏輯推論 40% / 高階思辨 50%）
       → G6 的「高階思辨」比重應高於 G5，以銜接國中代數啟蒙
```

#### Eidos 數學科 G6 精準測驗決策

| 測驗維度 | 設計策略 | 學術依據 |
|:---|:---|:---|
| 速率情境解構 | 多步驟行程問題，測驗文字→算式的轉化能力 | 臺南大學速率迷思論文 |
| 分數誘答設計 | 刻意對調基準量/比較量作為誘答 | NTHU 分數表徵轉換研究 |
| 平均速率攔截 | 「直接加總取平均」為強力誘答選項 | 數學工作坊平均速率迷思研究 |
| 代數啟蒙 | 含未知數情境題，但保留具體數字鷹架 | 皮亞傑形式運思過渡原理 |
| 跨單元整合 | 結合速率 + 圓面積的複合情境 | 108 課綱「系統思考與解決問題」素養 |

### 📖 3.2 國語科 (Chinese Language Arts)

#### PIRLS 閱讀理解四層次框架（來源：IEA PIRLS 2021、台灣 PIRLS 研究團隊）

| 層次 | 名稱 | 說明 | G5 題型比重 | G6 題型比重 |
|:---:|:---|:---|:---:|:---:|
| 1 | **直接提取** | 從文中直接找到明確資訊 | 20% | 10% |
| 2 | **直接推論** | 連結文中線索做出推論 | 30% | 30% |
| 3 | **詮釋整合** | 整合全文資訊理解主旨與手法 | 30% | 35% |
| 4 | **評估批判** | 對觀點、意圖進行批判性思考 | 20% | 25% |

**台灣 PIRLS 表現實證**：
> - 台灣學童在「說明文」閱讀表現優於「故事體」
> - **高層次思考能力（層次 3、4）仍有顯著提升空間**（PIRLS 2021 台灣報告）
> - 教育部已宣示將閱讀教學從「基本策略」轉化為「高層次思考策略」
> - 碩士論文證實 PIRLS 四層次提問教學方案能有效提升學童的詮釋理解歷程

#### 高年級國語認知配比（來源：`KL2_國語科共同發展總綱.md`，本處深化 G6 說明）

```
G5 配比：2-3-5（記憶提取 20% / 邏輯推論 30% / 場景與高階思辨 50%）
G6 配比：1-3-6（記憶提取 10% / 邏輯推論 30% / 場景與高階思辨 60%）
       → G6 大幅提高批判賞析與跨文本分析的比重，為國中會考長文閱讀打底
```

#### Eidos 國語科 G6 精準測驗決策

| 測驗維度 | 設計策略 | 學術依據 |
|:---|:---|:---|
| 長文本推論 | 提供 300-500 字文章，跨段落資訊統整 | PIRLS 層次 2-3 |
| 觀點批判 | 兩篇觀點不同短文的作者意圖比較 | PIRLS 層次 4 |
| 修辭與過渡句 | 測驗「然而、因此、儘管如此」等轉折詞精準運用 | 108 課綱學習表現 5-III-7 |

| 說明文題材加重 | 增加科普文、議論文的出題比重 | 台灣 PIRLS 報告：說明文表現優於故事體 |

### 🌍 3.4 社會科 (Social Studies)

#### 素養導向社會科評量的三大挑戰（來源：ATER 研究論文）

1. **長文本閱讀門檻**：素養導向題幹含圖表、地圖、史料文本，可能對閱讀弱勢學生造成「非學科因素」的答題障礙
2. **命題資源不足**：台灣教育現場「素養導向社會科題庫」嚴重匱乏
3. **文化資本差異**：學生的生活經驗與家庭社經背景顯著影響情境題表現

#### G5→G6 社會科知識視野擴展圖

| 維度 | G5 知識範疇 | G6 深化範疇 |
|:---|:---|:---|
| **歷史** | 台灣開發史（原住民→荷西→鄭氏→清領→日治） | 台灣民主化歷程、**國際關係與全球化** |
| **地理** | 台灣本島各區域特色、地形與產業 | **世界地理概覽**、氣候與環境變遷 |
| **公民** | 學校自治、社區參與 | **國家制度與政府運作**、人權議題、媒體識讀 |

**G6 社會科核心迷思概念**：

| 學科分支 | 常見迷思類型 | 來源 |
|:---|:---|:---|
| 歷史 | 時代先後順序混淆（荷西 vs 鄭氏）；歷史事件視為孤立而非因果鏈 | ATER 研究論文 |
| 地理 | 地圖比例尺、等高線判讀困難；區域特色理解流於刻板印象 | 台北市教育局社會領域輔導團 |

## 🔀 第四章：跨科整合視角 — 高年級獨有的命題機會

### 4.1 跨科情境題設計矩陣

六年級學童已具備足夠的跨領域知識基礎，可設計以下類型的整合情境題：

| 主題情境 | 融合科目 | 測驗能力 | 範例概述 |
|:---|:---|:---|:---|
| 手機上網資費方案比較 | 數學 (比與比值) + 社會 (消費者權益) | 數據分析 + 決策判斷 | 給定 A/B/C 三種資費方案，計算最划算的選擇 |
| 校園節水計畫 | 自然 (水循環) + 數學 (統計圖表) + 社會 (環保公民) | 數據蒐集 + 科學原理 + 公民行動 | 記錄用水量並製作折線圖，提出節水建議 |
| 國際文化美食節 | 英語 (菜單閱讀) + 社會 (多元文化) + 數學 (價格計算) | 跨文化理解 + 實用計算 | 閱讀英語菜單，計算預算內的最佳選擇 |
| 天氣異常新聞報導 | 國語 (新聞文本閱讀) + 自然 (氣候變遷) + 社會 (全球化) | 長文閱讀 + 科學推論 + 議題思辨 | 閱讀一段氣象新聞，判斷原因並討論影響 |

### 4.2 高年級共通的命題紅線 (Cross-Subject Red Lines)

以下為整合各科 `00` 總綱後的跨科通用禁令：

| 紅線 | 說明 | 適用科目 |
|:---|:---|:---|
| **嚴禁純機械式記憶題** | 不考「背公式」「背年代」「背單字」 | 全科 |
| **嚴禁城鄉偏見情境** | 情境設定須為「普世經驗」（超市、學校、公園、自然環境） | 全科 |
| **嚴禁連續高壓出題** | 即使高階思辨比重達 50-60%，也須穿插信心錨點 (Confidence Anchors) | 全科 |
| **嚴禁冷僻素材** | 語文字彙限課綱範圍、英語限 1200 基礎單字表 | 國語/英語 |
| **強制情境標籤** | 長情境題幹須加上 `【在XX時】` 場景前綴以降低閱讀認知負荷 | 全科 |
| **強制解答均勻分配** | AI 產題時須隨機化答案索引，避免偏集中於特定選項 | 全科 |

### 5.1 已知侷限與風險評估

| 項目 | 風險 | 說明 | 補強計畫 |

### 5.2 方法論自省

1. **本框架為二手文獻綜述**，尚未進行一手實證田野調查。所有結論須在 R3 素材庫建置時以真實考古題收錄進行驗證。
2. **引用之碩博論文多為 2015-2025 年**，樣本規模 100-300 人，屬小型研究。更高信度應以 TASA 全國大樣本資料庫為補強。
3. **108 課綱自 2019 年起實施**，約 7 年後部分內容可能已有微調，應交叉比對最新公告。
4. **各科目前的 `00` 總綱仍有用語風格差異**（如數學科使用「Brain-Friendly」一詞，本總綱建議後續版本統一為學術中性語彙）。
