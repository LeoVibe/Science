```ts
it('應為無 id 的題目自動補上 fallback id', async () => {
  mockFetchManifestAndFile(/* meta+questions，題目不含 id 欄位 */);
  const r = await loadQuestions(3, '國語', 2, '翰林');
  expect(r.questions.length).toBeGreaterThan(0);
  expect(r.questions.every(q => typeof q.id === 'string' && q.id.length > 0)).toBe(true);
});
```

- [ ] Step 5: Run 該測試 — 預期 PASS（loader 已有 fallback）。暫時移除 `questionLoader.ts:262`/`230 分支` 的 id fallback 跑一次確認該測試變 FAIL（證明守得住），再還原。
