## 四、上版階段規劃（建議時程可壓在 1～3 日內完成）

### 階段 A：Release Candidate（RC）凍結

- [ ] `main`（或約定分支）與題庫 commit **凍結**，只接受 **阻擋型 bugfix**  
- [ ] 執行第三節題庫硬動作  
- [ ] `npm run test` + `npm run build` 全通過並記錄（可複製到 `docs/reports/`）

### 階段 B：預備環境（Exam15 / Preview）

- [ ] Cloudflare Pages **Preview** 或 **Exam15** 建置  
- [ ] 確認 **環境變數**：`VITE_API_URL`、Base Path 與 Worker **一致**  
- [ ] 依 [`上版前整體驗證與檢查清單.md`](./上版前整體驗證與檢查清單.md) **§五、§七** 驗證後台登入與 `/api/settings`  
- [ ] **§三** 瀏覽器抽樣：至少每個年級 1 科、G6 有題組合、深連結重整一次

### 階段 C：正式上線（Production）

- [ ] 將 **已驗證之同一 commit** 部署至 **Production** branch／網域  
- [ ] 上線後 **煙霧測試**：首頁、任選 1 條測驗路徑、關於頁、後台登入（若對外開放）  
- [ ] 監控 Worker 錯誤率與回報 API 是否 5xx

### 階段 D：上線後 48 小時

- [ ] 檢視後台 **題目回報／全站意見** 是否有異常堆積  
- [ ] 若有資料錯誤，登記 `docs/DATA_ERRORS.md`（依專案慣例）  
- [ ] 排程：Lint 技術債、Playwright 擴充（選配）

## 五、風險登記（與因應）

| 風險 | 影響 | 因應 |

| 本機／Exam15 **後台登入失敗** | 無法審核／看回報 | 先查 Network API 基底；對齊 `api.ts` 與 `VITE_API_URL` |
