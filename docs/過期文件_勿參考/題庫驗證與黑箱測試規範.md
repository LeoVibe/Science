# 🔬 題庫盲審驗證與品質校對規範 (Blind Evaluation & Quality Calibration Protocol)

**last_updated：** 2026-03-21 13:25  
**updated_by：** Antigravity-Agent  
**版本：** v2.0（配合 CQI v2 重構）  
**適用範圍：** 所有 eidosProject 題庫 JSON 檔案之品質校對與模擬驗證。

---

## 1. 測試方法命名：盲審 (Blind Evaluation)

### 為什麼不叫「黑箱測試」？

| 術語 | 軟體工程定義 | 適不適合我們的場景 |
| :--- | :--- | :--- |
| **黑箱測試 (Black-Box Testing)** | 不知道系統內部實作，只測試輸入→輸出。 | ⚠️ 部分符合。我們確實屏蔽了答案，但我們同時也在**評估內容品質**，這超出了傳統黑箱的範疇。 |
| **盲審 (Blind Review)** | 學術界的同儕審查機制：審稿人不知道作者身份，純粹依據內容品質判斷。 | ✅ **高度符合**。我們的驗證模型在不知道正確答案的情況下，根據題目品質進行獨立判斷。 |
| **雙盲測試 (Double-Blind)** | 受試者與施測者雙方都不知道分組。 | ⚠️ 若出題模型與驗證模型為不同 Agent，則為雙盲。若同一模型，則為單盲。 |

> **結論**：本專案的測試方法正式命名為**「盲審驗證 (Blind Evaluation)」**。若出題與驗證分屬不同模型，可稱為「雙盲驗證」。

---

## 2. 核心流程：盲審三步驟

### 步驟一：盲目讀取 (Blind Read)
- 提取 `scenario`, `question`, `options`。
- **嚴禁**讀取 `answer_index`, `explanation`, `commonMisconception`。

### 步驟二：驗證模型獨立推論 (LLM Inference)
- 輸出：預測答案 (predicted_index)、推論過程 (reasoning)、內容建議 (suggestions)。

### 步驟三：交叉比對 (Validation)
- 將「predicted_index」與「answer_index」比對。
- 一致 = 題目邏輯自洽；不一致 = 需人工複查。

## 3. JSON 欄位定義（v2 擴充）

| 欄位名稱 | 類型 | 說明 | 範例 |
| :--- | :--- | :--- | :--- |
| `cqi_score` | Number | CQI v2 品質分 (0.0-10.0)，由 `evaluate_question_quality.js` 自動計算。 | `7.5` |
| `verification` | String | 驗證日期與結果簡述。 | `"2026-03-21 盲審完成"` |
| `authoring_model` | String | **出題模型**：產出本題原始內容的 AI 模型。 | `"Gemini-2.5-Pro"` |
| `verifying_model` | String | **驗證模型**：執行盲審的 AI 模型。 | `"Antigravity-Agent"` |

### 欄位命名設計理由
- `authoring_model` 而非 `generator`：強調「著作」而非「生成」，暗示模型對內容負責。
- `verifying_model` 而非 `reviewer`：強調「驗證」帶有客觀流程意涵，而非主觀評論。
- 兩個欄位分離設計，支援「先出題、後驗證」的跨階段工作流。

---

## 4. ⚠️ 模型同質性提示規範

若 `authoring_model` 與 `verifying_model` 基於相同邏輯架構，驗證報告**必須**標注：
> **「⚠️ 單盲提示：出題與驗證採用相同邏輯框架，存在共識偏差風險。建議輔以人工覆核或換用不同模型進行雙盲驗證。」**

## 5. CQI v2 品質評分權重（原生定義）

依據 `evaluate_question_quality.js`，`cqi_score` 採用以下七+維度計分（滿分 10.0）：

| # | 維度 | 配分 | 佔比 | 自動化 |
| :--- | :--- | :--- | :--- | :--- |
| A | 選項對稱性 | 2.0 | 20% | ✅ 全自動 |
| B | 情境深度 (字數+標籤) | 2.0 | 20% | ✅ 全自動 |
| C | 認知層次 | 1.5 | 15% | ✅ 半自動 |
| D | 結構完整度 | 1.0 | 10% | ✅ 全自動 |
| E | 易讀性 (句長+選項) | 1.0 | 10% | ✅ 全自動 |
| F | 課綱對齊 (Phase 1 簡易) | 1.0 | 10% | ⚠️ 半自動 |
| G | 認知成熟度匹配 | 0.5 | 5% | ✅ 全自動 |
| H | 誘答鑑別度 (Phase 3) | 1.0 | 10% | ⚠️ 需 LLM |
| I | 文化公平性 | -(扣分) | — | ✅ 全自動 |
| J | 研究支撐度 | -(天花板) | — | ✅ 已實作 |
