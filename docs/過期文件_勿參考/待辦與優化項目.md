# 待辦與優化項目

建立時間：2026-02-26 15:53  
最後更新：2026-02-26 21:30

此文件用於集中管理「未來建議發展項目」，作為後續派工與版本規劃的候選清單。

## P0（高優先）

1. **Cloudflare Wrangler v4 升級與相容驗證**
   - 背景：`backend/api` 目前可運作，但 CLI 已提示 wrangler 版本過舊。
   - 目標：完成 `wrangler@4` 升級、調整可能的設定差異，並補齊升級驗證步驟。
   - 驗收建議：`backend/api` 可 `dev` / `deploy --dry-run` / 正式部署，且 `/api/settings`、`/api/admin/*` 回應行為一致。

2. **後端 API 正式完成來源遷移（移除委派入口）**
   - 背景：目前 `backend/api/src/index.ts` 以委派方式連到舊路徑實作，屬於過渡方案。
   - 目標：將 API 主程式完整搬到 `backend/api/src/`，再移除對舊路徑的依賴。
   - 驗收建議：功能測試與 E2E 回歸通過，且程式碼無跨目錄委派。

3. **部署與維運文件統一**
   - 背景：目錄已重整為 `backend/api`，需確保所有操作文件一致。
   - 目標：盤點 CI/CD、runbook、教學筆記是否仍使用舊路徑，全部改為新路徑。
   - 驗收建議：以 `rg "scripts/workers/api"` 全域掃描，僅允許歷史紀錄或遷移說明存在。

## P1（中優先）

1. **管理後台路由切分與懶載入強化**
   - 目標：針對 admin 大型頁面落實 code splitting，降低初次載入體積。
   - 效益：改善首頁 FCP/TTI，減少一般使用者下載非必要管理模組。

2. **題庫資料快取策略優化**
   - 目標：針對 `question/platform` 的讀取建立更明確的 CDN/快取控制策略。
   - 效益：降低題庫延遲與後端負載，提升尖峰時段穩定性。

3. **錯誤監控與告警補強**
   - 目標：補齊前端 ErrorBoundary 與後端 Worker 錯誤追蹤指標（含關鍵路由）。
   - 效益：問題定位更快，減少線上故障排查時間。

## P2（低優先）

1. **UI 微動效與互動細節提升**
   - 目標：在不影響可用性的前提下，補強轉場與操作回饋。
   - 效益：提升整體質感與操作流暢度。

2. **長期技術債巡檢節奏化**
   - 目標：建立每月固定巡檢項目（依賴套件、Lint 規範、測試覆蓋率趨勢）。
   - 效益：避免小問題累積成大型重構成本。

- 完工後將成果同步寫回 `jobs/*-Report.md` 與 `docs/task_history.md`。
