## 五個常見陷阱（JOB-258 歸納，務必對照）
1. **假綠燈測試**：改題庫載入邏輯後，跑 `npx vitest run` 確認真綠（非略過）。
2. **統計過時**：題庫增刪後必跑 `generate_library_stats.js` + 對帳腳本。
3. **回饋回歸**：動到 `questionLoader.ts` 後，確認題目仍有 id（守門測試會擋）。
4. **隱形課**：上架旗標 `is_publishable` 誤標 → 跑 `audit_hidden_lessons.mjs`。
5. **上架數定義**：about 顯示上架數採「包級達標全算」，loader 採「逐題 is_publishable」，兩者可能不符（待 PM 裁定，見 JOB-258 缺口）。
