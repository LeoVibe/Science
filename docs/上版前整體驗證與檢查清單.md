## §五、後台登入、儲存與參數問題

| 現象 | 排查 |
|------|------|
| 後台錯誤 | `VITE_API_URL`、Worker 是否啟動、請求是否回 HTML 404 |
| 本機儲存失敗 | `wrangler dev` 埠是否與 `api.ts` 一致（常為 8787） |
| Pages 與本機不同 | `*.pages.dev` 使用 `origin` 作 API 基底時，Worker 路由須對齊 |
