# 📊 Eidos 題庫與研究進度總彙整 (2026-03-01)

---

## 🧭 上線標準 (Go-Live Readiness) 定義

我們採用「三位一體」評鑑法：
1. **品質深度 (Quality)**：必須達到 **L4 (深度思考)** 或 **L5 (專家認證)**。
2. **題量穩定 (Quantity)**：每單元平均題數需達 20 題以上（或每出版社總題數達一定規模）。
3. **科研支撐 (Research)**：必須具備對應年級學期的 `發展綱要.md`，包含「實證驗證區」。

3.  **上線標記**：建議在前端 UI 针对 **🟢 可上線** 的科目加上特別標誌（如「✨ 優質推薦」），引導使用者優先體驗 L4 內容。
