# 🛠️ 後台管理系統架構設計

**最後修訂：** 2026-03-22（新增分析中心「使用者分析」）
**存放路徑：** `docs/後台管理架構設計.md`
**對應程式碼：** `apps/v3_eidos/src/pages/AdminDashboard.tsx`

---

## 1. 設計精神

後台管理系統採用 **「三大群組 + 子頁路由」** 二級架構，取代早期的扁平分頁。

**核心原則：**
- 頂層最多 3 個 Tab → 手機一行塞得下
- 每個群組內部用膠囊按鈕切換子頁 → 未來新增功能只需追加子頁，不會撐爆頂層
- 路由採 URL 路徑式 → `/admin/{group}/{sub}`，語義清晰、可書籤

---

## 2. 功能群組總覽

```
/admin
├── /library          📚 題庫中心（所有跟題庫資料相關的操作）
│   ├── /manage         上架管理（開關年級/學期/科目/出版社）
│   └── /quality        品質重評（即時重跑品質評分引擎）
│
├── /analytics        📈 分析中心（所有跟數據觀察相關的頁面）
│   ├── /usage            使用統計（裝置 ID 分群、活躍天數）
│   ├── /user_analysis    使用者分析（高活躍裝置：日／時段、IP、年級科目、錯題連結）
│   ├── /feedback         題目回饋（統計與熱點題）
│   └── /logs             操作日誌（活動時間軸）
│
└── /system           ⚙️ 系統管理（基礎設定與權限控制）
    ├── /config         全局參數（網站狀態、預設值、進階設定）
    └── /users          帳號管理（🔐 Owner 限定）
```

## 4. 路由設計

**進入點：** `App.tsx` 中的 `/admin/:tab/*` 通配路由
**解析邏輯：** `AdminDashboard.tsx` 使用 `useLocation()` 從 `pathname` 提取 `group` + `sub`

```
URL                          → 對應畫面
/admin                       → 預設：題庫中心 / 上架管理
/admin/library               → 題庫中心 / 上架管理
/admin/library/quality       → 題庫中心 / 品質重評
/admin/analytics/usage         → 分析中心 / 使用統計
/admin/analytics/user_analysis → 分析中心 / 使用者分析
/admin/analytics/feedback      → 分析中心 / 題目回饋
/admin/analytics/logs          → 分析中心 / 操作日誌
/admin/system/config         → 系統管理 / 全局參數
/admin/system/users          → 系統管理 / 帳號管理（Owner 限定）
```

## 6. 擴展預留

未來需要新增後台功能時，僅需：

1. 建立新的 `Admin*.tsx` 元件
2. 在 `AdminDashboard.tsx` 的 `TAB_GROUPS` 陣列中追加一筆 `subTab`
3. 不需要修改路由（通配路由已涵蓋）

## 7. 權限控制

| 角色 | 可見範圍 |
|------|----------|
| `admin` | 所有群組，但「帳號管理」子頁隱藏 |
| `owner` | 所有群組，全部子頁可見 |

判斷邏輯（2026-02-26 更新）：

1. 路由層先由 `RequireAdminAuth` 以 `admin_token` 呼叫後端 `GET /api/admin/verify` 驗證。
2. 驗證成功後才允許載入 `AdminDashboard`，並將回傳 session 寫入 `sessionStorage('admin_session')` 供 UI 顯示角色。
3. 角色顯示規則仍由 `TAB_GROUPS.ownerOnly` 控制（`owner` 可見帳號管理，`admin/editor` 不可見）。
4. 所有後台設定寫入（`AdminConfigPanel`、`AdminLibraryManager`）皆透過 `PUT /api/admin/config` + Bearer token，不再只靠 localStorage。
