## 一、驗收前置

### 1.1 啟動雛形

```bash
cd prototypes/ui-v2
npm install   # 已由 JOB-203 執行完畢
npm run dev   # 預設 port 5183
```

瀏覽器打開 <http://localhost:5183>，預設進入主選單。

### 1.2 檢視清單

請逐一走訪：

- [ ] `/`（主選單）—— 切換 6 科目，觀察 pill / 漸層 / 分課卡 / 挑戰按鈕配色
- [ ] `/quiz`（答題）—— 選答案 + 確認，試 A/B/C/D 快捷鍵、答對 / 答錯回饋

- [ ] `/report`（學習報告）—— 切換 3 出版社（康/南/翰），看統計 / 錯題分頁
- [ ] 右上 🌙/☀️ 切換 Light / Dark
- [ ] 用瀏覽器 DevTools 切 375px / 768px / 1024px 檢視 RWD
