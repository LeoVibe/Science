## 二、待使用者決策的關鍵問題

### 2.1 主題方向（必選其一）

使用者需在 §3 勾選以下三選項之一：

#### 選項 A：完全替換（Full Replacement）

- 範圍：所有 token 換成 Claymorphism、原 warm amber 全部退役
- 影響面：15 個檔案（134 次使用點）全部改寫
- 工期估計：3 週（Token migration 1 週 + 視覺 QA 1 週 + L3 驗證 1 週）
- 風險：使用者熟悉感重置、若反應不佳無法快速回退
- 適合情境：產品仍在早期／目前 UAU 低／明確想與過往視覺切割

#### 選項 B：融合（Hybrid）

- 範圍：保留 warm amber 科目色語意層，底色改 Learning Blue、按鈕改 Clay、字型升級
- 影響面：約 60% 檔案改（核心 semantic token + 字型 + 陰影），科目色 token 留用
- 工期估計：2 週（Token migration 1 週 + QA 1 週）
- 風險：兩種設計語言在同頁共存，需明確分配 (e.g. 藍為框架、琥珀為科目標識)
- 適合情境：珍惜既有科目色系統／想試水溫再決定是否全換

#### 選項 C：僅新功能使用（Scoped）

- 範圍：Claymorphism 僅用於「下一階段新功能」（暫定範例：家長儀表板、親子任務、成就系統）
- 影響面：不動現有 15 個檔案，新建檔案才使用新 token
- 工期估計：不列入本 JOB，隨新功能同步交付
- 風險：新舊並存時間長、使用者在站內跨頁面會感到視覺斷層
- 適合情境：不希望打擾既有使用者／把新視覺當作新功能的「旗艦識別」

### 2.2 科目色處理（A/B 情境適用）

若選 A 或 B，科目色是否保留？

- 選項 α：**保留現行 6 科目色** — 只換核心 semantic，科目識別不變
- 選項 β：**重新設計科目色以搭配 Learning Blue** — 讓科目色與新主色色相距離合適，避免衝突
- 選項 γ：**取消科目色**，改用 icon + 標籤 — 大幅簡化，但科目辨識度下降

### 2.3 出版社色處理

`PUBLISHER_THEME_COLORS`（康軒/南一/翰林）是否同步調整？

- 選項 x：保留現值 — 學習報告頁面識別不變
- 選項 y：重新設計配色以搭配 Learning Blue — 與科目色同步調整

### 2.4 Dark Mode 政策

- 選項 1：本輪僅做 Light Mode，Dark 延後 Phase 3 處理
- 選項 2：本輪同步設計 Claymorphism Dark（陰影層需重新配色，工期 +3 天）
