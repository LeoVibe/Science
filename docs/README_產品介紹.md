Eidos 是一個專為國小學生設計的高互動性題庫演練系統，提供 108 課綱與多個出版社授課內容所延伸的複習題目（康軒／翰林／南一）。

---

## 為什麼這裡的題目值得信賴？

坊間多數練習卷只是「把課本換成選擇題」。Eidos 的題目經由一套**從學術研究到落地出題的四層流水線**產出，並在每道題目上標示其已完成的品管等級（QL1–QL4）。以下用最白話的方式，帶您了解我們是怎麼做到的。

---

## Eidos 的四層研究架構

我們製作每一道題目的過程，就像蓋一棟房子：先打地基（研究孩子怎麼學）、再畫藍圖（規劃各科怎麼考）、接著備料（蒐集課文與考古題）、最後才砌磚（實際出題並品管）。

```
 第一層  國小學齡總體研究        ← 地基：孩子的大腦準備好了嗎？
     ↓
 第二層  各科共同發展總綱        ← 藍圖：這個科目該怎麼考？
     ↓
 第三層  各年級原始研究素材庫     ← 備料：這學期教了什麼？哪裡容易錯？
     ↓
 第四層  題庫落地出題            ← 砌磚：題目生產、品管、上架
```

### 第一層：了解孩子的學習能力（地基）

在出任何一道題之前，我們先回答一個根本問題：**這個年紀的孩子，能理解多複雜的問題？**

- 一、二年級的孩子，大腦還在「具體思考」階段，我們的題目以**記憶和基礎理解**為主，絕不會出現需要抽象批判的題型，避免造成不必要的挫折。
- 三、四年級開始能做簡單的邏輯推理，我們逐步加入**情境應用題**。
- 五、六年級進入「抽象思考」的準備期，題目開始要求**價值判斷和觀點評估**。

這套認知發展的配比原則，確保每個年級的孩子都在「剛好有挑戰、又不會太難」的甜蜜點上練習。

### 第二層：幫每個科目量身打造出題規則（藍圖）

國語和數學的出題邏輯完全不同——國語要考閱讀理解和修辭辨識，數學要防止學生用刪去法猜答案。所以我們為每一個科目都撰寫了一份「共同發展總綱」，規定：

- 這個科目的**出題核心原則**是什麼？
- **誘答選項**（錯誤選項）該怎麼設計，才能精準找出孩子真正不懂的地方？
- 不同年級的**認知層次配比**應該是多少？

目前已涵蓋：國語、數學、自然、社會、英語、生活，共六大科。

### 第三層：深入每一課、每一版本的教學內容（備料）

這是整個流程中**工作量最大、最紮實**的環節。我們會針對每個年級、每個學期、每個科目，進行以下四大研究：

1. **全版本課文目錄**：完整記錄康軒、翰林、南一三大出版社「每一課」的課名和學習重點，一課都不遺漏。
2. **學術文獻研究**：引用台灣碩博士論文、PIRLS 國際閱讀評量報告等專業研究，找出「孩子在這個主題上最容易犯的錯」。
3. **逐課教材分析**：拆解每一課的生字、修辭、閱讀策略重點，確保我們真正理解課本在教什麼。
4. **真實考古題分析**：從全國中小學題庫網、各縣市學力檢測等來源擷取真實的段考題目，分析選項的「干擾機制」——為什麼學生會選錯？錯在哪個環節？

完成這四大研究後，我們再將這些素材「濃縮」成一份給 AI 出題系統使用的「命題矩陣」，告訴 AI：這一課應該考什麼、怎麼考、陷阱設在哪裡。

### 第四層：題目生產、品管與上架（砌磚）

有了前三層的堅實基礎，我們才開始正式出題。目前已做到的品質把關包括：

1. **格式檢驗**：確保每道題的結構完整（題幹、選項、正確答案、解析一個都不少）。
2. **內容品質評分**：自動檢測題幹是否清楚、選項是否合理、答案是否唯一正確。
3. **平衡度檢查**：確保正確答案平均分布在 A/B/C/D，不會讓聰明的孩子用「規律」猜答案。
4. **AI 盲測**：將題目交給完全未見過答案的 AI 模型作答，確保題幹清晰、選項不模糊。

## 題目品質等級（QL）

每道題目都有一個品質等級，標示其研究深度與驗證程度：

| 等級 | 名稱 | 說明 |
|:--|:--|:--|
| QL1 | 課綱基礎 | 僅依課綱與關鍵字產出，學習目標不夠精準 |
| QL2 | 課文歸納 | 已完成 KL4 單課研究；題目能具體歸納課程內容與精髓 |
| QL3 | 考古參考 | 額外完成 KL4 考古題與討論；誘答設計有實證基礎 |
| QL4 | 深思與盲測 | 用不同 Agent 進行盲測且通過；題幹與選項經實測精修 |
| QL5 | 專家認證 | 教師審閱與使用者回饋驗證（未來期待） |

完整定義請見 [`question/README_驗證與盲測準則.md`](../question/README_驗證與盲測準則.md)。

## 目前的題庫主力與限制

**目前以國語、社會、自然為主力出題科目**。三科在三、四年級下學期已完成 KL4 研究素材建置與大多數盲測，是題庫品質最穩定的區塊；五、六年級部分科目仍在 KL4 研究與盲測進行中，請以各科目標示的 QL 等級為準。

**英語**：各校選書差異較大（康軒、翰林、南一進度不一），目前尚未作為主力出題項目。已有部分三年級題目，後續視研究資源擴展。

**數學**：選擇題只能評量部分數學能力；計算過程、圖形判讀、算式推導等能力難以用單純四選一呈現。後續計畫針對「適合選擇題出題的題型」進行針對性優化，目前已有的數學題庫以概念理解類為主。
