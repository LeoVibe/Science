## 📖 名詞定義 (Terminology)

### 研究深度 (R1-R4)
這是題庫**產出前**必須經歷的四個研究層次，確保知識正確與認知負荷合理。
| 層次 | 隱喻 | 範疇 | 核心問題與交付物定位 |
|:---:|:---|:---|:---|
| **R1🧠** | 地基 | **全國小總體研究** | 孩子大腦準備好了嗎？(認知配比/素養框架) |
| **R2🗺️** | 藍圖 | **分科總體研究** | 這科 G1~G6 該怎麼考？(各科目 00 總綱) |
| **R3📚** | 規劃 | **分年級個別研究** | 課綱教什麼？容易錯哪？(原始研究素材庫) |
| **R4🔧** | 材料 | **分學期細節材料** | 各版本課文/考古題分析 (發展綱要/命題矩陣) |

### 題庫成熟度 (L1-L5)
這是題庫落地在 `question/platform/` 資料夾的品質宣告。
| 燈號 | 成熟度 | 說明 |
|:---:|:---|:---|
| 🔵 | **L4/L5 (高品質)** | 經 AI 品質管線稽核或專家驗證，含層次 3-4 深度誘答與防呆。 |
| 🟢 | **L3 (高階)** | 具備完整詳解與迷思概念分析，但認知層次分佈較基礎。 |
| 🟡 | **L2 (中階)** | 僅包含基本題目與答案，缺乏深度詳解。 |
| ⚪ | **L1 (基礎)** | 結構化初稿階段，尚未經品質修正，可能包含偏差。 |
| 🔴 | **(缺件)** | 尚未產出對應版本的 JSON 題庫。 |

### 與本文件「表格題數」的關係（請避免誤會）

- 本文件主表（例如 G3 上學期國語「康+翰+南」題數）是 **分出版社** 的敘述與派工脈絡；**不**保證等於 `stats` 中單一 `G3_S1_國語` 的 `count`（匯總規則不同）。
- **`totalIndexed` / `stats.count`**：適合「全站儀表板／索引」；**`publisherStats`**：適合「題庫總覽 UI 依版本展開」。
