# eidos 未來發展藍圖與功能願望清單 (Future Roadmap & Wishlist)
*最後更新：2026-02-27 21:25*

本文件紀錄 eidos 專案中長期待開發的功能概念、研究方向與使用者願望。

## 🌟 核心機制進化
1. **智慧抽題 (Smart Shuffle) v2.0**
   - **狀態**：規劃中 (JOB-037)
   - **詳情**：不再只是純隨機。導入「加權抽題」，自動根據忘記曲線調整出現頻率。避開連續答對 3 次以上的題目，直到其餘題目已被覆蓋。

2. **跨裝置同步 (Cloud Sync)**
   - 使用使用者 ID 進行多裝置學習進度同步。

## 👨‍👩‍👧 家長與教育研究
1. **內容探討 (Research Deep Dive) 專區**
   - **狀態**：已派工 (JOB-038)
   - **目標**：展示開發團隊在題目設計上的「深研」。
   - **主題**：題目品質層級 (L1-L5)、HCI/UX 在小學教育介面的應用、錯題分析模型。

2. **家長週報 (Parent Insight Report)**
   - 每週透過電子郵件或站內訊息，提供孩子學科能力雷達圖分析。

## 🎨 UI/UX 深度優化
1. **闖關式學習地圖**
   - 取代目前的分類列表，小三學生可在地圖上解鎖單元，提升遊戲化體驗。

2. **角色成長系統 (Pet/Avatar)**
   - 隨著複習點數 (100point) 的累積，虛擬寵物可進化。

## 💡 使用者願望清單 (Wishlist)
- [ ] 支援更多科目的「影片解析」。
- [ ] 考前模擬考模式（計時、總結與 PR 值預估）。
- [ ] 語音導讀題目（適合低年級或聽覺學習型使用者）。
