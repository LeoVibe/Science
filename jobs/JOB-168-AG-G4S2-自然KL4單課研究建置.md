# JOB-168-AG-G4S2-自然KL4單課研究建置

**`job_type`**: `research`
**`executor`**: Claude Code（使用者授權例外 — 深度研究需 PM 直接操作）

---

## 📌 任務背景

G4S2 自然三版本已有 KL3 發展綱要（`四下_自然_發展綱要.md`，含跨版本矩陣與迷思庫），但**缺乏 KL4 單課研究檔**。

依研究架構總綱，KL4 為「材料層」，採「一課雙檔」制：
1. 單課研究紀錄：課文摘要、結構剖析、核心概念、守衛點
2. 考古題與討論：真實考古題、誘答機制解析

**沒有 KL4 → 出題品質上限受限**（CQI-P P-J 研究支撐度：無 KL4 → 最高 QL3）。
JOB-169 補題盲測依賴本 JOB 的 KL4 產出。

---

## 📖 執行步驟

### Phase 1：確認各版本課程對照

查閱 108 課綱四下自然各版本實際單元：
- 康軒、翰林、南一各有 4 個單元
- 確認現有 JSON meta.title 是否正確（目前康軒/翰林顯示相同標題，需驗證）
- 建立正確的跨版本課程對照表

### Phase 2：建立目錄結構

```
knowledge/課綱研究/自然/四下/
├── 康軒/
│   ├── KL4_四下_康軒_L1_{課名}_單課研究紀錄.md
│   ├── KL4_四下_康軒_L1_{課名}_考古題與討論.md
│   └── ... (L2-L4)
├── 翰林/
│   └── ... (L1-L4 雙檔)
└── 南一/
    └── ... (L1-L4 雙檔)
```

### Phase 3：KL4 單課研究紀錄

每檔包含：
1. 課文/單元實體摘要（核心概念、學習重點）
2. 實驗與探究活動結構（操作變因、控制變因）
3. 核心知識點地圖
4. 認知地雷與守衛點（學生容易混淆之處）

### Phase 4：KL4 考古題與討論

每檔包含：
1. 真實考古題建檔（從白名單來源蒐集）
2. 學生誘答機制解析（為什麼會選錯）
3. 迷思概念深度討論

### Phase 5：品質稽核

- CK-01：包含三大版本對照
- CK-02：引用外部教育資源（≥ 3 來源）
- CK-03：建立微觀地雷矩陣
- CK-04：不含出題 Prompt 或 AI 指令
