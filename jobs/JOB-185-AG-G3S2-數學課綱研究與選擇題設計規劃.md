# JOB-185-AG-G3S2 數學課綱研究與選擇題設計規劃

**`job_type`**: `research`  
**`executor`**: Claude Code（使用者授權例外）

## 📌 任務背景
G3S2 數學題庫已完成出題與盲測，但 154 題視覺圖形題已封存（TYPE-C）。
使用者決策：「圖形題先不上架，因為目前技術問題還無法克服。」
需要研究小三下數學課綱，釐清哪些概念適合以選擇題複習、如何設計，
以及哪些單元因圖形操作性質應暫時排除。

## 🎯 任務目標
逐單元分析 G3S2 數學課綱，產出選擇題設計指引文件，指導後續出題方向。

## 🚧 任務邊界

本次任務只做：
- 研究 G3S2 數學各單元的知識點與認知需求
- 分類：適合選擇題 vs. 圖形操作型（暫封存）
- 設計出題框架與範例題
- 產出指引文件

本次任務不做：
- 產出題庫 JSON
- 修改現有題庫
- 修改規範文件

## 📖 執行步驟
1. 讀取 G3S2 數學發展綱要與素材庫
2. 逐單元分析：知識點、認知層次、是否需圖形操作
3. 分類：計算型 / 情境型 / 概念型 / 錯誤辨識型 / 圖形操作型
4. 為每個適合出題的類型設計 2-3 個範例題
5. 列出圖形封存清單（單元、課次對應、封存原因）
6. 產出指引文件
