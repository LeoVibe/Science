# JOB-030: 後台「題目回饋洞察」功能開發

## 任務摘要
在 Admin 後台新增「題目回饋洞察 (Feedback Insights)」頁面，讓管理者能查看孩童對於題目的反饋標籤，系統應自動統計被標記次數最多的題目，協助內容優化。

## 需求細節
1.  **數據概覽 (Overview)**：
    - 顯示總回饋數。
    - 顯示各標籤（看不懂、內容有錯等）的分佈比例。
2.  **熱點題目 (Hotspots)**：
    - 列出被孩子們反應最多次的題目清單。
    - 點擊可查看具體的回饋內容（如有文字備註）。
3.  **過濾功能**：
    - 可依年級、科目或標籤類型過濾。
4.  **操作介面**：
    - 接續現有 Admin Dashboard 的 Tabs 結構。

## 技術規格
- **API**: `GET /api/feedback` (需具備 Admin 權限驗證)。
- **資料庫**: 對 `feedback` 資料表進行統計查詢。
- **前端**: 使用 Shadcn UI 表格與圖表展示。

## 階段目標
1.  [ ] **設計驗收**：產出 UI Mockup 並獲准。
2.  [ ] **API 實作**：在 Worker API 實作統計與列表端點。
3.  [ ] **前端開發**：實作 Admin 端的 Insights 頁面。
4.  [ ] **同步更新**：更新規格書。
