## 五、各閘門實際 prompt

### 階段0 — 考點清單抽取（claude）
```
讀取 KL4_三下_翰林_L{N}_*_考古題與討論.md。
抽出本課「考古考點清單」，每考點輸出 kaodian_id / 描述（一句話）/ 來源（考古題型或段落）。
只抽考古素材裡真有的，不得自行擴充。輸出 JSON 陣列。
```

### 階段3 — 對應 judge（claude sonnet）
```
給定 L{N} 考點清單與一題（含 scenario/options/answer_index/explanation）。
判斷此題是否真正對應清單中某個 kaodian_id。
- 對應：題目考核的能力/概念與某考點一致 → {match:true, kaodian_id}
- 不對應：偏離所有考點或自由發揮 → {match:false, reason}
保守判定：模稜兩可一律 match:false。
```

### 階段4 — 雙盲盲測（claude sonnet）
```
【盲讀】只給題幹與 4 選項（不給 answer_index、不給 explanation）。
1. 作答：選出唯一正解索引。
2. 單一正解：是否只有一個選項成立？多解/無解 → single_answer:false。
3. 課別歸屬：是否屬「三下社會 翰林 L{N}」範圍？非本課 → belongs:false。
輸出 {answer_index, single_answer, belongs, reason}。系統比對 Match。
```
