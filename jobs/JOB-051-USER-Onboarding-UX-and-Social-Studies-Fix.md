# JOB-051-USER-Onboarding-UX-and-Social-Studies-Fix

## 1. 任務概要
優化 V3 版本的首登引導流程與視覺指引，並修復社會科題庫存取權限問題，提升系統穩定性與使用者體驗。

## 2. 實作變更紀錄 (Implementation Results)

### A. 社會科 (Social Studies) 存取修復 🏛️
- **邏輯重構**：將 `isLibraryEnabled` 判定由「白名單」改為「Fail-safe」模式。
- **成果**：系統現在預設開啟所有科目，僅在明確禁用時阻斷。成功解決社會科無法點選測驗的問題。

### B. 首登流程與導覽指引優化 🛡️👆
- **流程修復**：修正 `handleProfileSave` 狀態切換，確保點選「開始練習」後立即關閉歡迎頁，不再重複顯示設定視窗。
- **導覽視覺升級**：
    - **位置翻轉**：手指游標 (👆) 置於上方直接指向盾牌 icon，說明文字移至下方。
    - **指向優化**：手指更靠近目標物，並在氣泡上方加入裝飾性突起，引導感更強。

### C. 智慧學期與年級同步 📅🎒
- **學期自動判定**：根據月份自動預設學期（2-8月為下學期，9-1月為上學期）。
- **年級連動**：首登頁面年級按鈕與後台 `libraryConfig` 同步，動態顯示開放狀態，取代硬編碼。

### D. UI 組件精煉 🎚️
- **設定圖標**：採用極簡琥珀色 Sliders (Mixer Toggles) 設計，確保在高解析度下清晰且專業。

## 3. 驗證結論
- **本機編譯**：`npm run build` 通過。
- **首登測試**：無痕模式下首登流程、智慧預設與導覽指引運作正常。
- **社會科測試**：已可正常進入測驗頁面並載入題目。
