# JOB-040-USER-Value-Proposition-Manual

## 📌 任務背景
雖然我們的系統在技術與學術上非常嚴謹，但對於家長與一般使用者而言，這些複雜的「皮亞傑理論」、「4-4-2 動態配比」與「大腦友善原則」可能過於艱澀。為了建立品牌信任感並傳達題目背後深沉的教育關懷，我們需要一封「文情並茂」的說明書。這不僅是技術說明，更是一份對三年級孩子成長規律的深刻致敬。

## 📖 任務詳情
1. **文案撰寫**：將學術理論（Piaget、認知配比、大腦友善原則）轉化為感性且易懂的語言，強調對 G3 孩子心理發展的細膩觀察。
2. **核心價值定義**：說明為什麼「長題幹」與「合理迷思」是愛的表現，而非單純的難度增加。
3. **UX 呈現建議**：思考這份文案最適合放在網站的哪個位置（如：登入後的導覽、關於我們、或題目開始前的「給大人的話」）。
4. **建立信任體系**：讓使用者對系統產出的題組產生專業與溫暖並重的雙重認同。
