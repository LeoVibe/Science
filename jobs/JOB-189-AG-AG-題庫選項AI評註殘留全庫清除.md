# JOB-189-AG-題庫選項AI評註殘留全庫清除

**`job_type`**：`engineering`
**`executor`**：Claude Code（使用者授權例外）
**`priority`**：P1（上版前必須處理）
**`depends_on`**：JOB-188（發現問題來源）

---

## 📌 任務背景

JOB-188 §A 抽樣驗證發現，29 個開放組合中有 13 個組合（44.8%）的題目選項文字含出題 Agent 遺留的評註字串，如「這點在分析單元核心時非常關鍵」、「呼應三下社會課重點」等。這些字串使用者可見，嚴重影響題目品質與可信度。

---

## 🎯 任務目標

全庫掃描 `question/platform/` 下所有題庫 JSON 的 `options` 欄位，移除 AI 出題評註殘留字串，並儲存修改。

---

## 🚧 任務邊界

**只做**：
- 讀取並修改 `question/platform/` 下的題庫 JSON 的 `options` 欄位
- 移除已定義的 AI 評註殘留模式
- 輸出 dry-run 報告與實際修改報告

**不做**：
- 修改 `question`、`explanation`、`meta` 等其他欄位
- 修改任何規範文件
- 修改選項的語意核心（只移除尾綴/嵌入的評註）

---

## 📋 清除模式清單

以下字串模式一旦出現在 `options[i]` 中，依規則處理：

| 類型 | 模式 | 處理方式 |
|:--|:--|:--|
| 尾綴-1 | `，這點在分析單元核心時非常關鍵[^$]*` | 截斷至逗號前 |
| 尾綴-2 | `，這點在實務上很重要。[^$]*` | 截斷至逗號前 |
| 尾綴-3 | `，呈現出課綱所要求之探索精神[^$]*` | 截斷至逗號前 |
| 尾綴-4 | `，內容完整確診且具備情境深度[^$]*` | 截斷至逗號前 |
| 尾綴-5 | `，這也是[^$]*` | 截斷至逗號前（需確認語意） |
| 嵌入 | `，並且需要經過深思熟慮的考量。?` | 移除嵌入片段 |
| 重複括號 | `（呼應[^\n]*）（呼應[^\n]*）[^$]*` | 保留首個完整選項文字，移除括號及後續 |
| 重複括號 | `（屬於課堂常見[^\n]*）（屬於[^\n]*）[^$]*` | 同上 |
| 重複括號 | `（協助檢驗[^\n]*）（協助[^\n]*）[^$]*` | 同上 |
| 重複括號 | `（可對照[^\n]*）（可對照[^\n]*）[^$]*` | 同上 |
| 前綴垃圾 | `^如果我們仔細觀察的話會發現[A-D]\.` | 移除前綴，保留真正選項文字 |
