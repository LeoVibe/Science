## 📎 附錄 A：Pilot 驗證結果（四下翰林 L10 孫悟空，5 題，2026-06-14）

### Pilot 三大發現（決定方法）
1. **codex 會編假來源（KP-01 風險）**：初版未加防護時，codex 自編題並掛「內安國小 108 第二次段考」等來源——但 grep L2 真實考卷 **0 命中**，全是虛構。直接衝量會產出假考古題。
2. **雙重驗證可擋住**：prompt 加「(a) 回報讀取行 (b) 每題來源可回查 (c) 沒真題就誠實標改編、禁掛假學校」後，重跑 5 題：來源全標「依課文改編」、**零假來源**、讀取行 `sed` 比對**逐行屬實**。
3. **國語多數課無對應真題**：L2 國語考題不綁特定課文（孫悟空課關鍵詞在 L2 命中 0）。故國語 KL4 考古題與討論多走 **A 方案：依課文改編題型示例**，誠實標「非真實考卷」，不假裝考古題。

## 📎 附錄 C：驗證機制（每課產出後自動跑，不合格退回重跑）

| 檢查項 | 方法 | 退回條件 |
|:--|:--|:--|
| 讀取證明屬實 | `sed -n 'Np'` 比對 codex 引用行 vs 實際檔 | 對不上 |
| 無虛構來源 | grep 題目區無「國小/段考/學年」假來源 | 有 |
| 來源可回查 | 若標 L2 真題，grep L2 確認存在 | 查無 |
| 扣課文 | 題幹含課文專屬詞 | 命中過低 |
| 誘答分析實質 | 每題分析 ≥30 字 | 空話 |
| 誠實標註 | 含「依課文改編/非真實考卷」或真實來源 | 無 |
| 無空殼 | 無 bootstrap/待補 | 有 |

**人工抽樣**：每學期抽 2-3 課讀內容，確認題目扣課文、誘答有料、非灌水。

**省 token 流程**：驗證腳本先就位 → pilot 1 課 → 腳本+人工驗 → prompt 調穩 → 批量（每課即驗，只重跑不合格課）。
