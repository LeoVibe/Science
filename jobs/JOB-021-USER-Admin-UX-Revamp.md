# JOB-021：後台題庫管理版面精簡 + 前台更版資訊重整（升級正式版 1.0）

## 任務背景

目前後台「題庫管理」同列資訊過多（出版社、QG、CQI、題數、審查按鈕），造成可讀性偏差。  
前台「更版資訊」描述也偏雜，缺少「使用者有感」重點與清楚的版本節點敘事。  
本次需同時完成：

1. 後台列表資訊降噪（移除 CQI 字樣、微調版面、審查按鈕獨立）。
2. 前台更版資訊重寫（聚焦有感功能）。
3. 重新規劃 0.7 之後版次，並明確宣告本次為正式版 `v1.0`。

## 任務詳情

1. 後台題庫管理 UI 精簡（`AdminLibraryManager`）
   - 將 `CQI 6.94` 改為僅顯示數值（例如 `6.94`；無資料仍顯示 `—`）。
   - 調整每列資訊密度與間距，避免科目區塊過擠（字級/間距/對齊微調即可，不做大改版）。
   - 「審查」改為獨立按鈕區塊，不與前方出版社資訊主 block 疊在同一層（避免覆蓋與誤觸）。
   - 手機版與桌機版都需維持可用（至少在常見寬度無重疊、文字可讀）。

2. 前台更版資訊重整（`AboutView` / 必要時 `AboutModal`）
   - 將「更版資訊」改為「使用者有感」版本摘要，不保留情緒化或內部測試描述。
   - 從既有內容挑選有意義項目重寫（建議聚焦：題庫穩定性、續答、錯題、後台治理、資料清除與安全性）。
   - 建立 0.7 之後的清楚版次節點（建議包含 `0.8`、`0.9`、`1.0`），並標註本次為 `v1.0 正式版`。
   - 歷史版連結（`/history/v0.1/`、`/history/v0.5/`）保留，但文案需避免誤導。

3. 文件同步
   - 將版本定位（正式版 `v1.0`）同步到適當文件（至少 `docs/網站功能規格書.md` 與相關版本敘述區塊）。
   - 若有新增「更版資訊規則」，同步到對應文件，避免後續再次雜亂。
