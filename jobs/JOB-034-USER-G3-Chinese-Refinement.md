# JOB-034-USER-G3-Chinese-Refinement 三年級國語題庫精煉與品質擴充

## 任務背景
目前三年級國語部分單元存有「湊字數」現象，干擾項（Distractors）語意無意義或出現不當口語（如「很爽」）。本任務旨在透過精煉模型提示詞，重新生成精簡、專業且具備 QL4+ 層次的題庫，並顯著提升題量以覆蓋更多教學細節。

## 任務詳情
1. **去贅字與廢話修剪**：
   - 嚴禁使用通用型廢話（如「很好玩」、「雖然累但開心」）。
   - 選項必須基於課文深度邏輯陷阱、近義詞辨析或語境推論。
2. **題量大幅擴充**：
   - **強制要求**：每單元（課）必須提供 **20 題以上**。
   - 題型需涵蓋：字音字形 (QL1)、詞義辨析 (QL2)、情境應用 (QL3)、文意推論/修辭賞析 (QL4)。
3. **長度對齊 (Length Balancing)**：
   - 四個選項字數必須接近（誤差 < 20%），消除漏題特徵。
4. **格式標準化**：
   - 產出符合 `question/README_題庫格式規範.md` 之 A' 格式。
