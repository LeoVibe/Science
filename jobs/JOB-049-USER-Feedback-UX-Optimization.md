# JOB-049：測驗頁面問題回報文案優化 (Feedback UX Refinement)

## 任務背景
使用者反應目前的「問題回報」用詞過於生硬且正式，希望能改用更簡短、親切且直觀的方式，讓孩子或家長在發現題目異常時，能更自然地與系統進行交流。

## 任務詳情
1. **文案正名**：
   - 將按鈕標題由「問題回報」改為「這題有誤？」。
   - 使用問句形式能有效降低使用者的心理門檻，並引發確認動機。
2. **互動語氣調整**：
   - 優化 Popover 內的引導文字，減少機械感。
   - 標題改為「這題哪裡怪怪的呢？」。
   - 副標題改為「告訴我們，我們會馬上修復它！」。
3. **保持相容性**：
   - 僅修改介面文案，不變動現有的 API 提交邏輯與 Tag 結構。

## 關鍵參考檔案
