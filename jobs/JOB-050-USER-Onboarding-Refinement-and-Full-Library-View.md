# JOB-050-USER-Onboarding-Refinement-and-Full-Library-View

## 📌 任務背景
為了優化新使用者的初次進站體驗，我們決定捨棄零散的彈窗通知，改為一個結構完整的「引導式開屏設定」。同時，使用者反映原本的「題庫總覽」表僅能看見當前設定的單一年級資料，無法全盤掌握站內題庫開發進度，因此需要將其改位「全站視角」總表。

## 📖 任務詳情

### 1. 移除舊版 Onboarding 邏輯
- 刪除 `OnboardingModal.tsx` 並移除 `Index.tsx` 中相關的狀態控制。

### 2. 實作 WelcomeSetup 引導頁面
- **第一屏 (Welcome)**：增加感性問詢「你是第一次使用本站嗎？」，點擊後進入設定。
- **第二屏 (Setup)**：
  - **強制年級設定**：確保新使用者必須選擇年級（3-5 年級），否則無法開始。
  - **出版社設定**：預設為展開狀態，不需隱藏。文字改為：「※ 若不清楚教科書版本，可先略過，之後隨時可以從主畫面右上角「🎒」修改。」
- **理念注入**：在設定頁底部呈現「4-4-2 的黃金心法」，移除「AI 扮演學科專家」區塊。
- **操作提示**：在確認按鈕下方增加「盾牌圖示 🛡️」提示，告知使用者未來可在主畫面左上角修改年級設定。

### 3. 優化全站「題庫總覽」
- **打破年級限制**：將 `AboutView.tsx` 中的題庫表改為遍歷所有有效年級。
- **自動動態連動**：表格需對接 API 的 `libraryConfig`，自動隱藏被禁用的科目，並對應 `libraryData` 顯示最新題數。

### 4. 系統文案一致性修正
- 將導覽標籤 `🏫紀錄` 統一修正為 `🏫本站`。
- 還原 `AboutView` 中的原始感性大標：「陪孩子一起複習」、「回家 15 分鐘，把今天學過的重點帶走」。

## ✅ 驗證基準 (DoD)
- [ ] 無痕模式下進入首頁，應正確跳出 `WelcomeSetup` 引導頁。
- [ ] 進入後設定頁底部應包含「關於本站」理念說明。
- [ ] 「題庫總覽」分頁應能看見跨年段（如 G3、G4、G5）的統計表。
- [ ] 右上方按鈕自「紀錄」更名為「本站」。
- [ ] 產出完補之派工單與完工報告。
