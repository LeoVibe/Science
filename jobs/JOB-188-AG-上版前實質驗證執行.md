## §A：題庫抽樣驗證

### A.1 驗證對象

目前有開放給使用者的題庫組合（共 10 科目 × 約 3 版本 ≈ 29 組合）：

| 年級學期 | 科目 | 版本 |
|:--|:--|:--|
| G3 S2 | 國語(CHI) | 翰林 / 康軒 / 南一 |
| G3 S2 | 英語(ENG) | 翰林 / 康軒 / 南一 |
| G3 S2 | 數學(MATH) | 翰林 / 康軒 / 南一 |
| G3 S2 | 自然(SCI) | 翰林 / 康軒 / 南一 |
| G3 S2 | 社會(SOC) | 翰林 / 康軒 / 南一 |
| G4 S2 | 國語(CHI) | 翰林 / 康軒 / 南一 |
| G4 S2 | 自然(SCI) | 翰林 / 康軒 / 南一 |
| G4 S2 | 社會(SOC) | 翰林 / 康軒 / 南一 |
| G5 S2 | 國語(CHI) | 翰林 / 康軒 |
| G6 S2 | 國語(CHI) | 翰林 / 康軒 / 南一 |

**總計**：約 29 組合 × 3 題 = 約 87 題

### A.2 每題驗證的 4 個維度

| 維度 | 通過條件 |
|:--|:--|
| **格式合規** | 有 `meta` + `questions` 根節點；`meta` 含 grade/semester/subject/publisher |
| **欄位完整** | `question`、`options`（恰好 4 項）、`answer_index`（0-3 整數）、`explanation` 均存在且非空白 |
| **答案可信** | `answer_index` 對應的 options 文字，在語意上合理為正確答案（Claude Code 閱讀題目後判斷；明顯錯誤要標記） |
| **文字品質** | 題幹/選項無截斷、無明顯錯字、不含「PLACEHOLDER」「待補」「[TODO]」等占位字樣；題幹長度 > 10 字 |

### A.3 抽樣方式

對每個組合，從所有該組合的題庫 JSON 檔案中，取第 1 題、中間題、最後 1 題（跨不同課程），若題數 < 3 則全取。

### A.4 輸出格式

產出 `docs/reports/JOB-188-題庫抽樣驗證報告.md`：

```markdown
| 組合 | 版本 | 題ID | 格式 | 欄位 | 答案 | 文字 | 問題說明 |
|:--|:--|:--|:--:|:--:|:--:|:--:|:--|
| G3 S2 國語 | 翰林 | L1-Q1 | ✅ | ✅ | ✅ | ✅ | — |
| G3 S2 國語 | 翰林 | L6-Q15 | ✅ | ✅ | ⚠️ | ✅ | 答案index=2但選項C語意較弱，建議複查 |
```

圖例：✅ 通過 / ⚠️ 疑慮（需人工確認）/ ❌ 失敗（有明確問題）

最後附彙整統計（各維度通過率）與 ⚠️/❌ 項目清單。

### B.3 每條路徑的驗證步驟

1. 導航至路徑 → 選課頁面正常載入（無白畫面/崩潰）
2. 點選第一個可選課程 → 進入答題模式
3. 完整回答 10 題（每題點選一個選項 + 確認答案）
4. 每題解析頁正常顯示（有文字說明，非空白）
5. 答完後「查看結果」頁正常顯示
6. 全流程無「畫面暫時發生錯誤」或 JS 崩潰

記錄格式（每條路徑）：
```

選課頁載入：✅/❌
進入答題：✅/❌

結果頁正常：✅/❌
無 JS 錯誤：✅/❌
備注：[若有問題]
```
