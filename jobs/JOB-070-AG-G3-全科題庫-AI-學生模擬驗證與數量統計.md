# JOB-070-AG-G3-全科題庫-AI-學生模擬驗證與數量統計

## 📌 任務背景
為了確保 G3 題庫（包含國、數、英、自、社）的內容正確性、描述合理性以及選項與答案的一致性。我們需要從三年級學生的視角出發，模擬作答流程，以發現潛在的題目瑕疵。同時，需更新全站進度表中的題目數量統計。

## 📖 任務詳情
1. **遍歷 G3 檔案結構**：掃描 `question/platform/G3` 下的所有科目與出版社目錄。
2. **統計題目數量**：針對每個科目、學期、出版社的 JSON 檔案進行題目總數加總。
3. **AI 學生模擬作答**：
    - 逐題讀取 `title` (題目描述)。
    - **不讀取 `options` (選項)**。
    - AI 根據題目自行推理出答案。
    - 比對 AI 答案與 JSON 中的 `answer` 以及 `options` 是否邏輯自洽且正確。
4. **內容合理性核查**：檢查題目描述是否符合小三學生的認知程度，文字是否流暢合理。
5. **更新進度表**：將統計出的數量與驗證結果回填至 `docs/進度彙整_全站研發與題庫產出.md`。
