# 📚 Eidos 題庫數據理型 (Schema Contract)

**最後修訂時間：** 2026-02-21
**存放路徑：** `shared/forms/schema_contract.md`
**目的：** 定義 Eidos 題庫靜態 JSON 檔案 (Assets) 的標準格式，確保前後端讀取的一致性與未來擴充性。

---

## 1. 核心 JSON 結構 (Core Structure)
每個章節（Lesson）的題庫會獨立編譯為一個靜態的 JSON 檔案，以達最大快取效益。檔案必須嚴格遵守以下 JSON Schema：

### 1.1 頂層屬性 (Root Attributes)
- `meta` (Object): 記錄該題庫的來源、分類與驗證資訊。
- `questions` (Array): 存放該章節下所有的題目陣列。

### 1.2 `meta` 區塊定義
| 欄位名稱 | 型別 | 說明 | 範例值 | 必填 |
| :--- | :--- | :--- | :--- | :--- |
| `grade` | String | 適用年級 | `"grade_3"`, `"grade_4"` | ✅ |
| `semester` | String | 適用學期 | `"semester_1"`, `"semester_2"` | ✅ |
| `subject` | String | 適用科目 | `"自然"`, `"社會"`, `"國語"` | ✅ |
| `publisher` | String | 出版社版本 | `"kang_hsuan"` (康軒), `"nan_i"` (南一), `"han_lin"` (翰林) | ✅ |
| `lesson` | String | 章節代碼 | `"Sci1"`, `"Soc2"` | ✅ |
| `order` | Number | 章節順序 | `1`, `2` | ✅ |
| `title` | String | 章節名稱 | `"多采多姿的植物"` | ✅ |
| `verified` | Boolean | 是否經過 Antigravity/驗證機制的正確性確認 | `true` | ✅ |
| `verification_source` | String | 資料來源或驗證方式說明 | `"現有題庫轉換"`, `"Gemini AI 生成"` | ❌ |

### 1.3 `questions` 陣列元素定義 (Question Object)
| 欄位名稱 | 型別 | 說明 | 範例值 | 必填 |
| :--- | :--- | :--- | :--- | :--- |
| `id` | String | 題目唯一碼 (目前為題號字串) | `"1"`, `"2"` | ✅ |
| `type` | String | 題型識別碼 | `"multiple_choice"`, `"true_false"` | ✅ |
| `question` | String | 題目內文 | `"請問植物的器官包含哪些？"` | ✅ |
| `options` | Array[String] | 選擇題的選項陣列（一般為 4 個選項）| `["根", "莖", "以上皆是", "都不是"]` | 若為選擇題則✅ |
| `answer` | String | 正確解答的完全比對字串（需對應 options 之一） | `"以上皆是"` | ✅ |
| `explanation` | String | 答題詳解與教學目標重點 | `"植物的器官包含根、莖、葉等..."` | ✅ |
| `authoring_date` | String | 出題日期 (YYYY-MM-DD) | `"2026-03-14"` | ❌ |
| `authoring_model` | String | 出題模型名稱 | `"Gemini-2.5-Pro"` | ❌ |
| `blind_evaluation` | Boolean | 是否經過盲審驗證 | `true` | ❌ |
| `verifying_date` | String | 驗證日期 (YYYY-MM-DD) | `"2026-03-21"` | ❌ |
| `verifying_model` | String | 驗證模型名稱 | `"Gemini-2.5-Flash"` | ❌ |

## 2. 擴充建議 (V2/V3 Future Proofing)

> **last_updated**: 2026-03-22 01:30
> **updated_by**: Antigravity
為了支援未來的動態出題與學習履歷追蹤，建議在未來的 Parser 轉換中，加入以下選填欄位：
1. `difficulty`: (Number) 記錄題目難度 (1-5)，便於適性化推薦。
2. `tags`: (Array[String]) 認知重點標籤 (如 `["記憶", "理解", "植物器官"]`)。
3. `media`: (Object) 支援題幹附帶圖片或音檔的 URL (如 `{"image": "/assets/sci_001.jpg"}`)。
