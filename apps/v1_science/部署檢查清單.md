## 需要手动检查的步骤

### 1. 检查 GitHub Pages 设置

访问：https://github.com/LeoVibe/NexusLab/settings/pages

确保以下设置：
- **Source**: 选择 `GitHub Actions`（不是 Branch）
- 如果看到 "Your site is live at..." 说明已启用

### 2. 检查 GitHub Actions 运行状态

访问：https://github.com/LeoVibe/NexusLab/actions

查看最新的工作流运行：
- ✅ 绿色勾号 = 成功
- ❌ 红色叉号 = 失败（点击查看错误信息）
- 🟡 黄色圆圈 = 运行中

### 3. 检查构建输出

如果 Actions 成功，检查：
- 构建是否完成
- 是否有任何警告或错误
- 部署步骤是否成功

### 4. 验证网站

访问：https://leovibe.github.io/NexusLab/Science/

应该看到：
- 页面正常加载（不是 404）
- "國小自然科 題庫練習" 标题
- 功能按钮可以点击

## 常见问题排查

### 问题 1: 页面显示 404

**可能原因**：
- GitHub Pages 未启用
- Source 设置错误（应该选择 GitHub Actions，不是 Branch）

**解决方法**：
1. 访问 Settings → Pages
2. 选择 Source 为 `GitHub Actions`
3. 保存设置

### 问题 2: 页面空白或资源加载失败

**可能原因**：
- Base 路径配置错误
- 资源文件路径不正确

**解决方法**：
1. 检查浏览器控制台（F12）的错误信息
2. 确认 `vite.config.js` 中的 base 路径是 `/NexusLab/Science/`
3. 重新构建并推送

### 问题 3: GitHub Actions 失败

**可能原因**：
- 依赖安装失败
- 构建错误
- 权限问题

**解决方法**：
1. 查看 Actions 日志
2. 检查错误信息
3. 确保 `package.json` 和 `package-lock.json` 已提交

## 手动触发部署

如果需要手动触发部署：

1. 访问：https://github.com/LeoVibe/NexusLab/actions
2. 点击左侧的 "Deploy to GitHub Pages" 工作流
3. 点击 "Run workflow" 按钮
4. 选择 `main` 分支
5. 点击 "Run workflow"

## 验证部署成功

部署成功后，通常需要等待 1-2 分钟，然后：

1. 访问：https://leovibe.github.io/NexusLab/Science/
2. 清除浏览器缓存（Cmd+Shift+R 或 Ctrl+Shift+R）
3. 检查页面是否正常显示
