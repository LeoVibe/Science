# 修复 404 错误的步骤

## 问题：访问 https://leovibe.github.io/NexusLab/Science/ 显示 404

## 快速修复步骤

### 步骤 1：检查 GitHub Pages 设置（最重要！）

1. 访问：https://github.com/LeoVibe/NexusLab/settings/pages
2. 在 "Source" 部分：
   - **必须选择**：`GitHub Actions`（不是 Branch 或 docs）
   - 如果看到其他选项（如 "Deploy from a branch"），请改为 "GitHub Actions"
3. 点击 "Save" 保存

### 步骤 2：检查 GitHub Actions 是否运行

1. 访问：https://github.com/LeoVibe/NexusLab/actions
2. 查看是否有 "Deploy to GitHub Pages" 工作流
3. 如果工作流存在：
   - 点击查看最新的运行记录
   - 检查是否有 ✅ 绿色勾号（成功）或 ❌ 红色叉号（失败）
4. 如果工作流不存在或失败：
   - 手动触发：点击 "Deploy to GitHub Pages" → "Run workflow" → 选择 `main` 分支 → "Run workflow"

### 步骤 3：等待部署完成

- GitHub Actions 通常需要 1-3 分钟完成构建和部署
- 部署完成后，等待 1-2 分钟让 GitHub Pages 更新

### 步骤 4：验证网站

1. 访问：https://leovibe.github.io/NexusLab/Science/
2. 清除浏览器缓存：按 `Cmd+Shift+R` (Mac) 或 `Ctrl+Shift+R` (Windows)
3. 如果仍然 404，检查浏览器控制台（F12）的错误信息

## 如果仍然无法工作

### 检查清单：

- [ ] GitHub Pages Source 设置为 "GitHub Actions"
- [ ] GitHub Actions 工作流成功运行（绿色勾号）
- [ ] 等待了足够的时间（3-5 分钟）
- [ ] 清除了浏览器缓存
- [ ] 检查了浏览器控制台的错误信息

### 手动触发部署：

如果 GitHub Actions 没有自动运行，可以手动触发：

1. 访问：https://github.com/LeoVibe/NexusLab/actions
2. 点击左侧的 "Deploy to GitHub Pages"
3. 点击右侧的 "Run workflow" 按钮
4. 确保选择 `main` 分支
5. 点击绿色的 "Run workflow" 按钮
