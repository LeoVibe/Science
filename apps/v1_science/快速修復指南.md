# 快速修复 404 错误 - 3 个步骤

## ⚠️ 重要：必须先完成步骤 1，否则会一直 404

### 步骤 1：设置 GitHub Pages Source（必须！）

1. **访问**：https://github.com/LeoVibe/NexusLab/settings/pages

2. **找到 "Source" 部分**，选择：
   ```
   ✅ GitHub Actions  ← 选择这个！
   ❌ Deploy from a branch
   ❌ None
   ```

3. **点击 "Save"** 保存

**这是最关键的一步！如果这里设置不对，会一直显示 404。**

---

### 步骤 2：检查 GitHub Actions 是否运行

1. **访问**：https://github.com/LeoVibe/NexusLab/actions

2. **查看工作流状态**：
   - 🟡 **黄色圆圈** = 正在运行，等待完成
   - ✅ **绿色勾号** = 成功（等待 1-2 分钟让 Pages 更新）
   - ❌ **红色叉号** = 失败，点击查看错误信息

3. **如果没有看到工作流运行**：
   - 点击左侧 "Deploy to GitHub Pages"
   - 点击右侧 "Run workflow" 按钮
   - 选择 `main` 分支
   - 点击 "Run workflow"

---

### 步骤 3：验证网站

1. **等待 2-3 分钟**（让 GitHub Actions 完成部署）

2. **访问**：https://leovibe.github.io/NexusLab/Science/

3. **清除浏览器缓存**：
   - Mac: `Cmd + Shift + R`
   - Windows: `Ctrl + Shift + R`

---

## 如果还是 404

### 检查清单：

- [ ] **步骤 1 完成了吗？** GitHub Pages Source 设置为 "GitHub Actions"？
- [ ] **GitHub Actions 成功了吗？** 看到绿色勾号了吗？
- [ ] **等待足够时间了吗？** 至少 3-5 分钟
- [ ] **清除缓存了吗？** 按了 Cmd+Shift+R 吗？

### 如果都完成了还是 404：

1. **打开浏览器开发者工具**（按 F12）
2. **查看 Console 标签页**的错误信息
3. **告诉我具体的错误信息**，我可以进一步帮助
