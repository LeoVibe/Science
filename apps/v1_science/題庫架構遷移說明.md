## 使用方式

### 開發環境
```bash
npm run dev
```

開發伺服器會自動載入 `questions/platform/` 下的所有 JSON 檔案。

### 新增題目
1. 在 `questions/platform/G3/自然/S1/康軒/` 下創建新的 JSON 檔案
2. 遵循新架構格式（參考 `題庫架構說明.md`）
3. 重新啟動開發伺服器，題目會自動載入

### 轉換更多題目
如果需要將更多題目轉換為新格式，可以修改 `convert-questions.js` 並執行：
```bash
node convert-questions.js
```

## 注意事項

1. **舊檔案保留**：`src/data/questions.js` 已保留作為備份，但不再被使用
2. **路徑配置**：載入器使用 Vite 的 `import.meta.glob`，路徑相對於專案根目錄
3. **格式轉換**：新格式使用 `answer` (文字)，組件需要 `correctAnswer` (索引)，載入器會自動轉換
4. **分類映射**：新格式的 `meta.title` 會自動映射到舊的分類名稱
