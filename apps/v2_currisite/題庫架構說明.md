# 題庫架構使用說明

本專案已更新為使用新的題庫架構，題庫檔案存放在 `public/questions/platform/` 目錄下。

> **產出題庫與協作**：完整規格、**目前題庫覆蓋狀況**（哪些有/沒有、缺漏原因）、以及交檔前檢查清單，請見 **[平台題庫規格與協作說明](docs/平台題庫規格與協作說明.md)**。詳細欄位定義見 [平台題庫規格書](docs/平台題庫規格.md)。

## 📁 目錄結構

```
public/questions/platform/
├── G1/                    # 一年級
│   ├── 國語/
│   ├── 數學/
│   ├── 英語/
│   └── 生活/
├── G2/                    # 二年級
│   └── ...
├── G3/                    # 三年級
│   ├── 國語/
│   ├── 數學/
│   ├── 英文/
│   ├── 自然/
│   └── 社會/
└── ...
```

每個科目的完整路徑格式為：
```
public/questions/platform/G{年級}/{科目}/S{學期}/{出版社}/*.json
```

例如：
```
public/questions/platform/G4/自然/S1/康軒/L1_範例課程.json
```

## 📋 JSON 檔案格式

每個 JSON 檔案必須包含 `meta` 和 `questions` 兩個部分：

```json
{
  "meta": {
    "grade": "grade_4",
    "semester": "semester_1",
    "subject": "自然",
    "publisher": "kang_hsuan",
    "lesson": "L1",
    "order": 1,
    "title": "課程標題",
    "verified": true,
    "verification_source": "驗證來源"
  },
  "questions": [
    {
      "id": "1",
      "type": "multiple_choice",
      "question": "題目內容",
      "options": ["選項A", "選項B", "選項C", "選項D"],
      "answer": "選項B",
      "explanation": "解析說明"
    }
  ]
}
```

### Meta 欄位說明

- `grade`: 年級，格式為 `grade_1` ~ `grade_6`
- `semester`: 學期，`semester_1` 或 `semester_2`
- `subject`: 科目名稱（中文），如 `自然`、`數學`、`國語` 等
- `publisher`: 出版社代碼
  - `kang_hsuan` - 康軒
  - `han_lin` - 翰林
  - `nan_yi` - 南一
- `lesson`: 課次編號，如 `L1`、`M1`、`Sci1` 等
- `order`: 課次順序（數字）
- `title`: 課程標題
- `verified`: 是否已驗證（選填）
- `verification_source`: 驗證來源（選填）

### 題型說明

#### 1. 選擇題 (multiple_choice)
```json
{
  "id": "1",
  "type": "multiple_choice",
  "question": "題目內容",
  "options": ["選項A", "選項B", "選項C", "選項D"],
  "answer": "選項B",  // 可以是選項內容或索引（0-3）
  "explanation": "解析說明"
}
```

#### 2. 是非題 (true_false)
```json
{
  "id": "2",
  "type": "true_false",
  "question": "題目內容",
  "answer": "True",  // 或 "False"
  "explanation": "解析說明"
}
```

#### 3. 填充題 (fill_in_the_blank)
```json
{
  "id": "3",
  "type": "fill_in_the_blank",
  "question": "題目內容，空格處用______表示",
  "answer": "正確答案",
  "explanation": "解析說明"
}
```

## 🔧 生成 Manifest 檔案

為了讓系統能夠正確載入題庫，每個出版社目錄下需要有一個 `manifest.json` 檔案，列出該目錄下所有的 JSON 檔案。

### 自動生成

執行以下命令自動生成所有 manifest.json：

```bash
npm run generate-manifests
```

或直接執行：

```bash
node scripts/generate-manifests.js
```

### 手動創建

如果需要手動創建，manifest.json 格式如下：

```json
{
  "version": "1.0.0",
  "generated": "2026-02-17T16:58:49.360Z",
  "files": [
    "L1_範例課程.json",
    "L2_另一個課程.json"
  ]
}
```

## 📝 使用步驟

1. **放置題庫檔案**
   - 將 JSON 題庫檔案按照目錄結構放置在 `public/questions/platform/` 下

2. **生成 Manifest**
   ```bash
   npm run generate-manifests
   ```

3. **啟動開發伺服器**
   ```bash
   npm run dev
   ```

4. **測試載入**
   - 在網站中選擇對應的年級、科目、學期、出版社
   - 系統會自動從 `public/questions/platform/` 載入題庫

## ⚠️ 注意事項

1. **檔案編碼**：所有 JSON 檔案必須使用 UTF-8 編碼（無 BOM）
2. **檔案命名**：遵循 `{課次ID}_{課程標題}.json` 格式
3. **目錄名稱**：使用中文科目名稱（如 `自然`、`數學`），不是英文
4. **出版社名稱**：目錄中使用中文（`康軒`、`翰林`、`南一`），但 JSON meta 中使用代碼（`kang_hsuan`、`han_lin`、`nan_yi`）
5. **Manifest 更新**：每次新增或刪除題庫檔案後，記得重新生成 manifest.json

## 🔄 遷移舊題庫

如果您有舊格式的題庫（`src/data/library/` 下的 JS 檔案），可以使用轉換腳本：

```bash
node scripts/convert-all-antigravity.js
```

這會將舊格式的題庫轉換為新格式的 JSON 檔案。
