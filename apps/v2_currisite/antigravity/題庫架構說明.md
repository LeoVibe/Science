# 國小題庫系統：檔案與目錄結構設計指南 v2.0

此文件定義了題庫 JSON 檔案的存放架構與格式規範，請依此規範產出對應的題庫。

---

## 📁 1. 總體目錄架構

專案根目錄下的 `questions/` 資料夾分為兩大區域：

```
questions/
├── source/              # 原始題庫區（依年級、科目、學期、出版社分類）
│   ├── G1/
│   ├── G2/
│   ├── G3/
│   ├── G4/
│   ├── G5/
│   └── G6/
└── platform/            # 平台使用題庫區（經過驗證、格式化後供系統讀取）
    ├── G1/
    ├── G2/
    ├── G3/
    ├── G4/
    ├── G5/
    └── G6/
```

### 區域說明：
*   **`source/`**: 存放原始題庫內容，按照課程結構組織，用於內容開發與維護
*   **`platform/`**: 存放經過驗證、格式統一後的題庫，供平台系統直接讀取使用

## 📂 2. 原始題庫區 (`source/`) 目錄結構

### 路徑格式：
```
questions/source/{年級}/{科目}/{學期}/{出版社}/{檔案名稱}.json
```

### 層級定義：

#### 2.1 年級 (Grade)
*   `G1` ~ `G6` (代表國小一至六年級)

#### 2.2 科目 (Subject)
*   **低年級 (G1-G2)**: `國語`, `數學`, `生活`, `英語`
*   **中年級 (G3-G4)**: `國語`, `數學`, `英文`, `自然`, `社會`
*   **高年級 (G5-G6)**: `國語`, `數學`, `英文`, `自然`, `社會`

#### 2.3 學期 (Semester)
*   `S1`: 第一學期 (上學期)
*   `S2`: 第二學期 (下學期)

#### 2.4 出版社 (Publisher)
*   `康軒` (Kang Hsuan)
*   `翰林` (Hanlin)
*   `南一` (Nan-I)

#### 2.5 檔案命名規則
格式：`{課次ID}_{課程標題}.json`

| 科目 | 課次ID格式 | 範例 |
|------|-----------|------|
| 國語 | L1, L2, ... L12 | `L1_心的悄悄話.json` |
| 數學 | M1, M2, ... M10 | `M1_10以內的數.json` |
| 英文 | U1, U2, ... U4 | `U1_Hello.json` |
| 自然 | Sci1, Sci2, ... | `Sci1_認識植物.json` |
| 社會 | Soc1, Soc2, ... | `Soc1_我們的家鄉.json` |
| 生活 | Life1, Life2, ... | `Life1_快樂上學去.json` |

### 完整路徑範例：
```
questions/source/G3/國語/S1/康軒/L1_心的悄悄話.json
questions/source/G3/國語/S2/康軒/L1_許願.json
questions/source/G3/數學/S1/翰林/M1_10000以內的數.json
questions/source/G4/英文/S1/南一/U1_What_Time_Is_It.json
questions/source/G5/自然/S1/康軒/Sci1_太陽.json
```

## 📋 3. JSON 格式規範

每個 JSON 檔案必須包含 `meta` (元數據) 與 `questions` (題目陣列) 兩部分：

### 3.1 Meta 元數據結構
```json
{
    "meta": {
        "grade": "grade_3",           // 年級：grade_1 ~ grade_6
        "semester": "semester_1",     // 學期：semester_1 或 semester_2
        "subject": "國語",            // 科目名稱（中文）
        "publisher": "kang_hsuan",    // 出版社：kang_hsuan, han_lin, nan_yi
        "lesson": "L1",               // 課次編號
        "order": 1,                   // 課次順序（數字）
        "title": "心的悄悄話",        // 課程標題
        "verified": true,             // 是否已驗證（選填）
        "verification_source": ""     // 驗證來源（選填）
    },
    "questions": [ ... ]
}
```

### 3.2 Questions 題目陣列結構

每個題目物件包含以下欄位：

#### 共通欄位：
*   `id`: 題目編號（字串，如 "1", "2", "3"）
*   `type`: 題型類別
*   `question`: 題目內容
*   `answer`: 正確答案
*   `explanation`: 詳細解析

#### 題型類別 (type)：

**1. 選擇題 (multiple_choice)**
```json
{
    "id": "1",
    "type": "multiple_choice",
    "question": "題目內容...",
    "options": ["選項A", "選項B", "選項C", "選項D"],
    "answer": "選項B",
    "explanation": "詳細解析..."
}
```

**2. 是非題 (true_false)**
```json
{
    "id": "2",
    "type": "true_false",
    "question": "題目內容...",
    "answer": "True",  // 或 "False"
    "explanation": "詳細解析..."
}
```

**3. 填充題 (fill_in_the_blank)**
```json
{
    "id": "3",
    "type": "fill_in_the_blank",
    "question": "題目內容，空格處用______表示",
    "answer": "正確答案",
    "explanation": "詳細解析..."
}
```

### 3.3 完整範例
```json
{
    "meta": {
        "grade": "grade_3",
        "semester": "semester_1",
        "subject": "國語",
        "publisher": "kang_hsuan",
        "lesson": "L1",
        "order": 1,
        "title": "心的悄悄話",
        "verified": true,
        "verification_source": "康軒官網教材內容"
    },
    "questions": [
        {
            "id": "1",
            "type": "multiple_choice",
            "question": "本課「心的悄悄話」主要想傳達什麼訊息？",
            "options": [
                "要大聲說話",
                "學習傾聽內心的聲音",
                "不要跟別人說話",
                "要保守秘密"
            ],
            "answer": "學習傾聽內心的聲音",
            "explanation": "本課透過詩歌形式，引導學生學習靜下心來聆聽自己內心的想法與感受。"
        },
        {
            "id": "2",
            "type": "true_false",
            "question": "文中提到，心的聲音有時候比外在的聲音更重要。",
            "answer": "True",
            "explanation": "課文強調內在省思的價值，鼓勵學生重視自己的感受與想法。"
        },
        {
            "id": "3",
            "type": "fill_in_the_blank",
            "question": "當我們靜下心來，就能聽見心裡的______。",
            "answer": "聲音、想法、話語",
            "explanation": "本課的核心概念是學習與自己的內心對話。"
        }
    ]
}
```

## 🔄 4. 平台題庫區 (`platform/`) 說明

平台題庫區的檔案是從 `source/` 區域經過以下處理後產生：

1. **內容驗證**：確認題目內容正確性
2. **格式統一**：確保所有欄位符合規範
3. **品質檢查**：檢查解析完整性、選項合理性等

平台區的目錄結構與 source 區相同，但僅包含已驗證通過的題庫。

## 📊 5. 命名與編碼規範

### 5.1 命名慣例
*   **目錄名稱**: 使用中文或約定縮寫（G1, S1, 康軒）
*   **檔案名稱**: 使用底線分隔，保持與 curriculum.yaml 一致
*   **特殊字元處理**: 
    *   空格用底線 `_` 取代
    *   標點符號保留（如 `‧`、`?`、`!`）
    *   英文單字首字母大寫

### 5.2 編碼規範
*   所有檔案一律使用 **UTF-8 無 BOM** 格式
*   JSON 檔案使用 **2 空格縮排**
*   確保中文字元正確顯示

## 🔍 6. 品質控管

### 6.1 題目設計原則
*   每課至少 5 題，涵蓋不同題型
*   選擇題選項數量為 4 個
*   解析需清楚說明答案理由
*   題目難度符合該年級程度

### 6.2 驗證流程
1. 對照官方教材確認課程內容
2. 檢查題目與課程主旨的關聯性
3. 驗證答案正確性
4. 確認解析的教育價值

### 6.3 更新記錄
每次更新題庫時，應在 `題庫統計表.md` 中記錄：
*   更新日期
*   更新內容
*   驗證來源
*   負責人員

## 📝 7. 使用說明

### 7.1 新增題庫
1. 在 `source/` 對應路徑下建立 JSON 檔案
2. 依照格式規範填寫內容
3. 完成後進行驗證
4. 驗證通過後複製到 `platform/` 對應路徑

### 7.2 修改題庫
1. 修改 `source/` 區的原始檔案
2. 重新驗證修改內容
3. 同步更新 `platform/` 區的檔案
4. 更新統計表記錄

### 7.3 刪除題庫
1. 從 `source/` 和 `platform/` 同時移除
2. 更新統計表記錄
3. 檢查是否影響其他相關檔案

---

## 📌 8. 注意事項

1. **不要直接修改 `platform/` 區的檔案**，所有修改應從 `source/` 開始
2. **保持兩區同步**，避免版本不一致
3. **定期備份**重要的題庫檔案
4. **遵循命名規範**，確保系統能正確讀取
5. **記錄驗證來源**，方便日後追溯與更新
