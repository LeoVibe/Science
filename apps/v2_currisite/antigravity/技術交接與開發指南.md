## 🏗️ 1. 題庫系統架構

本系統採用 **雙層目錄架構** 以確保源碼管理與平台部署的靈活性：

### 1.1 原始題庫區 (`questions/source/`)
- **用途**: 存放原始生成的題庫 JSON 檔案。
- **結構**: `G{年級}/{科目}/{學期}/{出版社}/*.json`
- **特點**: 
  - 這是「單一真理來源」(Source of Truth)。
  - 所有新增、修改都在此進行。
  - 此目錄不包含 `manifest.json`。

### 1.2 平台發布區 (`questions/platform/`)
- **用途**: 供前端網站 (`Science-Standalone`) 直接讀取使用的結構。
- **結構**: `G{年級}/{科目}/{學期}/{出版社}/*.json`
- **特點**:
  - 此目錄內容由 `source` 同步而來。
  - **必須包含 `manifest.json`**：每個終端目錄下都有一個 manifest 檔案，列出該目錄下的題庫列表，供前端動態載入。

---

## 🔄 2. 同步與生成流程

當您在 `questions/source` 新增或修改了題庫後，請執行以下步驟將其發布：

### 步驟 A: 同步檔案
將 `source` 的變更同步到 `platform`：
```bash
# 在專案根目錄執行
cp -r questions/source/* questions/platform/
```

### 步驟 B: 生成 Manifest
執行 Python 腳本為每個目錄生成 `manifest.json`：

```python
# 執行 generate_manifests.py (需確保腳本存在)
python3 scripts/generate_manifests.py
```
> **注意**: Antigravity 已在對話中建立了此腳本，若本地無存檔，請參考下方的腳本內容。

### 步驟 C: 部署到網站
將準備好的 `questions/platform` 複製到網站專案的 `public` 目錄：

```bash
# 假設網站專案路徑為 ../Science-Standalone
cp -r questions/platform/* ../Science-Standalone/public/questions/platform/
```

## 📋 3. 檔案格式規範 (JSON)

每個題庫檔案必須嚴格遵守以下 JSON 結構：

```json
{
    "meta": {
        "grade": "grade_5",          // 年級: grade_1 ~ grade_6
        "semester": "semester_1",    // 學期: semester_1, semester_2
        "subject": "英文",           // 科目中文名稱
        "publisher": "kang_hsuan",   // 出版社代碼: kang_hsuan, han_lin, nan_yi
        "lesson": "U1",             // 課次編號
        "order": 1,                 // 排序
        "title": "Unit 1 Title",    // 標題
        "verified": true,           // 是否驗證
        "verification_source": "官網" // 驗證來源
    },
    "questions": [
        {
            "id": "1",
            "type": "multiple_choice", // 題型: multiple_choice, true_false, fill_in_the_blank
            "question": "題目內容",
            "options": ["A", "B", "C", "D"], // 選擇題必須有此欄位
            "answer": "正確答案",
            "explanation": "詳解"
        }
    ]
}
```

## 💻 4. 前端整合指南 (給 Cursor)

前端開發者 (Cursor) 在 `Science-Standalone` 專案中應遵循以下邏輯來讀取題庫：

1.  **使用者選擇**：年級 (G1-G6) -> 科目 -> 學期 (S1/S2) -> 出版社。
2.  **構建路徑**：`public/questions/platform/G{年級}/{科目}/S{學期}/{出版社}/manifest.json`。
3.  **讀取 Manifest**：
    - `fetch` 該路徑的 `manifest.json`。
    - 獲取 `files` 陣列（檔案列表）。
4.  **載入題庫**：
    - 根據 `files` 列表，依序 `fetch` 同目錄下的 JSON 檔案。
    - 解析 JSON 並顯示題目。

---

## ⚠️ 5. 注意事項與常見錯誤

1.  **路徑大小寫**：`S1` (大寫 S) vs `semester_1` (meta 欄位)。目錄使用簡寫 `S1`/`S2`，這是為了縮短 URL，請務必保持一致。
2.  **編碼**：所有 JSON 必須是 **UTF-8** (無 BOM)。
3.  **Manifest 更新**：每次新增檔案後**必須**重新生成 manifest，否則前端會讀不到新檔案。
4.  **數學題庫格式**：目前部分舊的數學題庫 (G3) 雖已修正 meta，但建議在顯示時做防呆處理 (檢查 `semester` 欄位是否存在)。

## 🛠️ 附錄：generate_manifests.py 腳本

```python
import os
import json
from datetime import datetime, timezone
from pathlib import Path

ROOT_DIR = Path("questions/platform")

def generate_manifest(directory):
    json_files = [
        f.name for f in directory.glob("*.json") 
        if f.is_file() and f.name != "manifest.json"
    ]
    json_files.sort()
    
    if not json_files: return

    manifest_data = {
        "version": "1.0.0",
        "generated": datetime.now(timezone.utc).isoformat().replace("+00:00", "Z"),
        "files": json_files
    }
    
    with open(directory / "manifest.json", 'w', encoding='utf-8') as f:
        json.dump(manifest_data, f, indent=2, ensure_ascii=False)
    print(f"✅ Generated manifest for {directory}")

for directory in ROOT_DIR.rglob("*"):
    if directory.is_dir():
        generate_manifest(directory)
```
