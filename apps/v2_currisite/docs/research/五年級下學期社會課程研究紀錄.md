## 一、康軒版 (Kang Hsuan) - 108 課綱 (五下)

### 課程目錄
| 單元 | 課次 | 課程名稱 | 關鍵內容研究備註 |
|:---:|:---:|:---|:---|
| 第一單元 | L1 | 移民的開墾如何改變生活空間？ | 清領時期漢人移墾、聚落形成（頂下郊拼）、信仰中心發展。 |
| | L2 | 開港通商如何影響經濟與文化？ | 外銷作物（茶糖樟腦）帶來的財富分佈變化與馬偕等人的文化傳播。 |
| | L3 | 開港後清帝國的統治措施有什麼變化？ | 牡丹社事件、沈葆楨/劉銘傳的現代化建設（鐵路、電報）。 |
| 第二單元 | L1 | 日本帝國如何統治臺灣？ | 總督府體制、警察政治、保甲制度與基礎建設（嘉南大圳、電力）。 |
| | L2 | 殖民統治下臺灣人如何爭取權利？ | 武裝抗爭轉為後期的政治運動（文化協會、議會設置請願）。 |
| 第三單元 | L1 | 日治時期的建設帶來什麼影響？ | 城市規劃、西式教育引進、衛生觀念與守時習慣的養成。 |
| | L2 | 日治時期的社會文化有什麼改變與影響？ | 向洋化轉向、現代文學與美術起點、女性地位的初步變革（放足）。 |
| 第四單元 | L1 | 如何在生產活動中落實環境永續？ | 循環經濟概念、有機農業推廣、產業轉型與綠能生產。 |
| | L2 | 如何在消費中落實環境永續？ | 綠色消費、減塑生活、低碳足跡產品的選擇。 |
| | L3 | 為什麼理財也要重視環境永續？ | 綠色金融、ESG 投資觀念與社會責任感建設。 |

## 二、翰林版 (Han Lin) - 108 課綱 (五下)

### 課程目錄
| 單元 | 課次 | 課程名稱 | 關鍵內容研究備註 |
|:---:|:---:|:---|:---|
| 第一單元 | L1 | 日本政府如何殖民統治臺灣？ | 第一任總督至後期的統治方針轉變，資源搜刮與同化政策。 |
| | L2 | 日治時期的建設帶來哪些改變 | 交通連貫、電力開發（日月潭水電）、農業品種改良（蓬萊米）。 |
| | L3 | 日治時期對臺灣社會有什麼影響 | 新舊交替、守法觀念建立、新式學制的社會階級流通性。 |
| 第二單元 | L1 | 臺灣為什麼有多元的米食文化？ | 從原住民小米到漢人稻米，再到多元文化下的米食創新。 |
| | L2 | 臺灣的音樂如何展現多元文化？ | 原本古調、客家山歌、早期流行歌（桃花泣血記）到民歌運動。 |
| 第三單元 | L1 | 中華民國政府為何在臺灣實施戒嚴？ | 戰後初期、二二八事件、長期戒嚴對社會發展的壓抑與影響。 |
| | L2 | 臺灣為什麼能走向民主社會？ | 民間解嚴訴求、政黨解禁、總統直選、媒體多元化等公民力量。 |
| 第四單元 | L1 | 如何發現在地與世界文化特色 | 透過節慶、地標、飲食觀察文化脈絡。 |
| | L2 | 各族群生活方式如何形成文化 | 不同自然環境影響下的建築、禮儀與社會規範。 |
| | L3 | 世界宗教如何在臺灣傳播發展 | 台灣多元信仰的並存與共融：寺廟、教堂與伊斯蘭文化等。 |

## 三、南一版 (Nan Yi) - 108 課綱 (五下)

### 課程目錄
| 單元 | 課次 | 課程名稱 | 關鍵內容研究備註 |
|:---:|:---:|:---|:---|
| 第一單元 | L1 | 移民與自然環境的交會 | 漢人適應台灣地形的土地利用（如海邊防風林、山區梯田）。 |
| | L2 | 漢人移墾社會的形成 | 血緣聚落到地緣組織的演化，宗廟與社會秩序。 |
| | L3 | 清帝國時期的臺灣社會 | 晚清現代化進程：軍事設施與民政機關的改革。 |
| 第二單元 | L1 | 開港通商 | 產業發展重點的轉移與國際商行（洋行）的社會影響。 |
| | L2 | 臺灣地位的改變 | 乙未戰爭背景、總督府行政體系與日治初期的統治手段。 |
| 第三單元 | L1 | 當島嶼遇見電 | 台灣電力發展史，從火力到水力發電（門牌潭、日月潭工程）。 |
| | L2 | 電源不絕污染要絕 | 清潔能源發展趨勢：風力、太陽能，以及對環境負擔的反思。 |
| 第四單元 | L1 | 日常的經濟活動 | 生產者與消費者的關係，分工合作與供給需求概念。 |
| | L2 | 理財大小事 | 儲蓄與投資的區別，正確金錢觀與防詐意識建設。 |
| | L3 | 環保經濟 | 基於 LNT 原則與永續生產的未來經濟新藍圖。 |
