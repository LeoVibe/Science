## 一、康軒版 (Kang Hsuan) - 108 課綱 (四下)

### 課程目錄
| 課次 | 課程名稱 | 關鍵內容研究備註 |
|:---:|:---|:---|
| L1 | 一束鮮花 | 蝴蝶效應：一個小改變（鮮花）如何修復凌亂的環境與人心。 |
| L2 | 心動不如行動 | 實踐智慧：探討窮和尚與富和尚去南洋的故事。 |
| L3 | 選拔動物之星 | 媒體與自我認知：透過反諷寓言反思大眾審美。 |
| L4 | 米食飄香 | 傳統工藝：節慶米食（粽子、湯圓）的食文化與節奏。 |
| L5 | 讀書報告-藍色小洋裝 | 成長與珍惜：理解資源與感激，反思物質滿足。 |
| L6 | 我愛鹿港 | 古城美學：觀察鹿港老街的龍山寺、九曲巷。 |
| L7 | 未來的模樣 | 願景思考：人類對未來科技（AI、環保）的建設性想像。 |
| L8 | 動物老師的智慧 | 仿生學與適應：生物界中的獨特行為對人的啟發。 |
| L9 | 向太空出發 | 科學疆界：太空梭、火星探測等人類對宇宙的探索。 |
| L10 | 小青蛙想看海 | 勇氣與毅力：打破框架、實現夢想的旅程。 |
| L11 | 窗前的月光 | 文字與藝術：張曉風散文，探討自然光影的美感。 |
| L12 | 如來佛的手掌心 | 古典文學：探討《西遊記》中關於狂妄與謙卑的哲思。 |

## 二、翰林版 (Han Lin) - 108 課綱 (四下)

### 課程目錄
| 課次 | 課程名稱 | 關鍵內容研究備註 |
|:---:|:---|:---|
| L1 | 稻間鴨 | 自然保育：探討有機農業中鴨稻共生的永續價值。 |
| L2 | 綠色魔法學校 | 環保建築：成大「孫運璿綠建築」的節能減碳設計。 |
| L3 | 石虎兄妹 | 保護指標物種：石虎保育計畫與環境意識。 |
| L4 | 阿里棒棒 | 產業創新：飛魚卵（阿里棒棒）轉型為創意漁產的故事。 |
| L5 | 快樂兒童日 | 全球視野：各國兒童節的習俗與兒童權利的精神。 |
| L6 | 阿公的秘密 | 代際溝通：理解長輩的過往故事與家族情感傳承。 |
| L7 | 棒球英雄夢 | 王建民或其他選手的忍痛復健與運動家精神。 |
| L8 | 夢幻全壘打 | 運動美學：棒球場上的精彩瞬間與團隊合作。 |
| L9 | 單車遊日月潭 | 低碳觀光：透過單車視角體驗全球最美自行車道。 |
| L10 | 孫悟空三借芭蕉扇 | 改寫《西遊記》，關於耐心、計策與溝通。 |
| L11 | 最後一片葉子 | 歐亨利短篇小說：希望的力量與捨己為人的大愛。 |
| L12 | 閱讀課 | 解構性閱讀：如何從書本延伸到現實生活的體會。 |

## 三、南一版 (Nan Yi) - 108 課綱 (四下)

### 課程目錄
| 課次 | 課程名稱 | 關鍵內容研究備註 |
|:---:|:---|:---|
| L1 | 火旁龍慶元宵 | 苗栗客家元宵習俗：龍神文化的力與美。 |
| L2 | 看戲 | 戲劇文化：傳統廟口野台戲（布袋戲或歌仔戲）回憶。 |
| L3 | 舞吧!小飛魚 | 雅美族（達悟族）文化：飛魚季與海洋尊重的圖騰。 |
| L4 | 蝶之生 | 科普紀錄：蝴蝶從卵、幼蟲、蛹到成蟲的化蝶奇蹟。 |
| L5 | 活出生命奇蹟 | 意志力：如謝坤山或其他人物克服軀體限制的史實。 |
| L6 | 走過就知道 | 行動研究：透過實踐來驗證知識的真切感。 |
| L7 | 不一樣的母親花 | 文化象徵：了解金針花與康乃馨不同的孝情意涵。 |
| L8 | 屋頂上的野貓 | 動物與城市：微觀城市中的流浪動物生命。 |
| L9 | 用一公斤愛嘉明湖 | LNT (Leave No Trace) 精義：登山者背土回山的護山行動。 |
| L10 | 想像與發明 | 思考策略：好奇心如何驅動科學發明。 |
| L11 | 小事物大驚奇 | 顯微視角：生活中微小事物的宏大結構（如雪花）。 |
| L12 | 九蛙傳奇 | 日月潭水情指標：九蛙疊像的起源與環境意義。 |
