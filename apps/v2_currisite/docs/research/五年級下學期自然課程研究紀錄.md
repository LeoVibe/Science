## 一、康軒版 (Kang Hsuan) - 108 課綱 (五下)

### 課程目錄
| 單元 | 課次 | 課程名稱 | 關鍵內容研究備註 |
|:---:|:---:|:---|:---|
| 第一單元 | L1 | 力有哪些種類 | 接觸力（推力、拉力、摩擦力）與非接觸力（磁力、重力、電力）。 |
| | L2 | 如何知道力的大小 | 彈簧伸長量與受力的關係、虎克定律；運動快慢的測量。 |
| | L3 | 如何保持力的平衡 | 物體受力達成平衡的條件；拔河實驗與力的作用線。 |
| 第二單元 | L1 | 地層裡有什麼 | 沉積岩、岩石與礦物的特性；化石的形成與年代意義。 |
| | L2 | 大地如何變動 | 板塊活動、地震成因、褶皺與斷層的地理力量。 |
| | L3 | 大地變動有什麼影響 | 地形改變（高山抬升）、地震防災訓練與預警。 |
| 第三單元 | L1 | 植物如何獲取養分 | 光合作用探討、根部吸收水分與養分運輸途徑。 |
| | L2 | 植物有哪些繁殖方式 | 花的結構、授粉與種子萌發；營養器官繁殖。 |
| | L3 | 植物有哪些妙招 | 被迫環境（缺水、貧瘠）下的特殊適應與自保機制。 |
| 第四單元 | L1 | 溫度改變對物質的體積有何影響 | 固體、液體、氣體的熱脹冷縮與生活案例。 |
| | L2 | 熱是如何傳播 | 傳導、對流、輻射三種熱傳播途徑的差異。 |
| | L3 | 如何保溫與散熱 | 保溫瓶原理、建築散熱設計與隔熱材料。 |

## 二、翰林版 (Han Lin) - 108 課綱 (五下)

### 課程目錄
| 單元 | 課次 | 課程名稱 | 關鍵內容研究備註 |
|:---:|:---:|:---|:---|
| 第一單元 | L1 | 星空神話 | 透過星星認識古文明神話與星座文化意涵。 |
| | L2 | 一起觀星星 | 星座盤操作、方位角與仰角觀測實踐。 |
| | L3 | 夜裡辨認方位 | 利用北極星或北斗七星進行定向引領。 |
| 第二單元 | L1 | 氧氣與燃燒 | 氧氣助燃實驗、氧氣製備與線香檢測。 |
| | L2 | 二氧化碳 | 滅火原理、二氧化碳生成實驗與澄清石灰水檢驗。 |
| | L3 | 燃燒與滅火 | 燃燒三要素（可燃物、助燃物、燃點）與相對應滅火法。 |
| 第三單元 | L1 | 生鏽知多少 | 影響生鏽因素（氧、水、酸鹼），鐵鏽的物理性質觀察。 |
| | L2 | 生活中的食物保存 | 防止微生物滋生、密封、低溫、乾燥、鹽醃/糖漬等防腐建設。 |
| 第四單元 | L1 | 校園動物偵查員 | 觀察動物運動方式（爬、跑、飛、游）與構造。 |
| | L2 | 動物的生存之道 | 避敵（保護色、擬態）、覓食行為與群居/獨居性。 |
| | L3 | 動物的生命延續 | 卵生、胎生、育幼行為與變態發育（完全/不完全變態）。 |
| | L4 | 動物與人類生活 | 導盲犬、役用動物、及對生物多樣性的倫理關懷。 |

## 三、南一版 (Nan Yi) - 108 課綱 (五下)

### 課程目錄
| 單元 | 課次 | 課程名稱 | 關鍵內容研究備註 |
|:---:|:---:|:---|:---|
| 第一單元 | L1 | 認識星空 | 星星的亮度（視星等）與顏色差異（表面溫度）。 |
| | L2 | 觀測星空 | 星星的高度角及方位判定，認識夏季/冬季大三角。 |
| | L3 | 星星的移動 | 天體周日運動、地球自轉造成的星空旋轉幻象。 |
| 第二單元 | L1 | 空氣與燃燒的關係 | 生活中的氧化現象（如暖暖包）；燃燒條件的破壞。 |
| | L2 | 氧氣和二氧化碳的特性 | 微觀分子角度理解常見氣體的應用（如乾冰、氧氣瓶）。 |
| | L3 | 空氣與生鏽的關係 | 防鏽漆、鍍膜等預防性工程建設的必要性。 |
| 第三單元 | L1 | 動物的身體構造和運動 | 鳥類的龍骨與輕量骸骨、昆蟲的外骨骼構造分析。 |
| | L2 | 動物求生存的方式 | 恆溫與變溫動物、洄游、遷徙與冬眠行為。 |
| | L3 | 動物延續生命的方式 | 體內受精與體外受精、卵生與胎生的優缺點比較。 |
| 第四單元 | L1 | 認識聲音三要素 | 響度（振幅）、音調（頻率）、音色（波形）。 |
| | L2 | 製作簡易樂器 | 利用空氣柱或弦線長短進行調音，體驗發聲原理。 |
| | L3 | 噪音與防治 | 分貝概念、吸音/隔音工程與公民公共環境意識。 |
