## 一、康軒版 (Kang Hsuan) - 108 課綱 (113/114 下)

### 課程目錄
| 單元 | 單元名稱 | 學習重點 |
|:---:|:---|:---|
| U1 | 體積 | 長方體與正方體的體積公式、1立方公尺。 |
| U2 | 分數的計算 | 分數的乘法、整數乘以分數、分數乘以分數。 |
| U3 | 容積 | 容積與容量的關係、計算不規則物體的體積。 |
| U4 | 小數的乘法 | 整數乘以小數、小數乘以小數。 |
| U5 | 億以上的數 | 認識億、兆等大數，大數的加減計算。 |
| U6 | 整數、小數除以整數 | 小數除以整數（商為小數）、整數除以整數（商為小數）。 |
| U7 | 表面積 | 長方體與正方體的表面積計算。 |
| U8 | 比率與百分率 | 認識比率、百分率（%）及其應用。 |
| U9 | 時間的乘除 | 時間單位的乘法與除法計算。 |
| U10 | 生活中的大單位與折線圖 | 公噸、公頃、平方公里；折線圖的報讀與製作。 |

## 二、翰林版 (Han Lin) - 108 課綱 (113/114 下)

### 課程目錄
| 單元 | 單元名稱 | 學習重點 |
|:---:|:---|:---|
| U1 | 數的十進位結構 | 多位小數、億以上的大數位值。 |
| U2 | 分數的計算 | 分數與整數的乘法、分數與分數的乘法。 |
| U3 | 長方體與正方體的體積 | 體積公式、1立方公尺、複合形體體積。 |
| U4 | 小數 | 小數的加減與應用。 |
| U5 | 生活中的大單位 | 認識公噸、公頃、平方公里等。 |
| U6 | 時間的乘除 | 時間的加減乘除應用問題。 |
| U7 | 容積 | 容器的內部空間計算、水的體積與容積。 |
| U8 | 比率與百分率 | 比率的概念、百分率與小數、分數的轉換。 |
| U9 | 表面積 | 展開圖、計算正方體與長方體的表面積。 |
| U10 | 線對稱圖形 | 認識對稱軸、對稱點、對稱邊與對稱角。 |

## 三、南一版 (Nan Yi) - 108 課綱 (113/114 下)

### 課程目錄
| 單元 | 單元名稱 | 學習重點 |
|:---:|:---|:---|
| U1 | 分數的計算 | 分數乘以整數、分數乘以分數、被乘數與積的關係。 |
| U2 | 數的十進位結構 | 認識大數與多位小數。 |
| U3 | 平面圖形與對稱 | 線對稱圖形的概念。 |
| U4 | 正方體和長方體 | 體積計算公式與應用。 |
| U5 | 整數、小數除以整數 | 小數除法的直式計算與應用。 |
| U6 | 小數的乘法 | 小數乘以小數的進位與補位。 |
| U7 | 表面積 | 認識表面積並學習計算。 |
| U8 | 比率與百分率 | 折扣、漲幅等實務應用。 |
| U9 | 容積與容量 | 計算液體體積與容器容量。 |
| U10 | 怎樣列式 | 使用未知數（x或y）列出加減乘除式子。 |

## 四、研究結論與建議
1. **單元高度重疊**：三版在「分數計算」、「小數運算」、「體積/容積/表面積」、「比率百分率」上幾乎一致。差異僅在單元排序。
2. **產出建議**：題目應側重於情境應用（例如：容量換算、折扣計算、體積堆疊等），以符合 108 課綱素養導向。
