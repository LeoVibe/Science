## 一、康軒版 (Kang Hsuan) - 108 課綱 (五上)

### 課程目錄
| 單元 | 課次 | 課程名稱 | 關鍵內容研究備註 |
|:---:|:---:|:---|:---|
| 第一單元 | L1 | 我們生活的臺灣 | 台灣的地理位置、經緯度、鄰近國家與海洋特色。 |
| | L2 | 當我們生活在一起 | 人口分佈、族群組成（閩、客、原、新住民）與互動。 |
| | L3 | 法律影響我們的生活 | 法律的基本功能、權利與義務的關係，憲法的重要性。 |
| 第二單元 | L1 | 河川對生活空間的影響 | 台灣河川特性（短小流急）、水資源開發與水利建設（埤圳、水庫）。 |
| | L2 | 氣候對生活空間的影響 | 氣溫、降雨量受地形與季風影響，氣候災害與調適。 |
| 第三單元 | L1 | 山海環境與居民的生活 | 不同地形（平原、盆地、高山）居民的傳統生活模式。 |
| | L2 | 探訪史前人類與原住民族 | 長濱文化、卑南文化、十三行文化；原住民十六族分布與文化特質。 |
| 第四單元 | L1 | 臺灣與世界的連結 | 早期航海圖、地圖中看見的台灣，地理大發現背景。 |
| | L2 | 臺灣的位置與大航海時代 | 荷蘭、西班牙在台的經營、貿易（鹿皮、糖）與傳教。 |
| | L3 | 大航海時代對臺灣的改變 | 荷西殖民對台灣生產、文字、宗教與國際貿易地位的開啟。 |

## 二、翰林版 (Han Lin) - 108 課綱 (五上)

### 課程目錄
| 單元 | 課次 | 課程名稱 | 關鍵內容研究備註 |
|:---:|:---:|:---|:---|
| 第一單元 | L1 | 從地圖探索位置與發展有何關聯？ | 台灣經緯度位置的優勢、領海與領空、南海島嶼。 |
| | L2 | 史前人們如何善用資源維持生活？ | 舊石器、新石器、青銅/鐵器時代的演進與遺跡。 |
| | L3 | 原住民族的文化與環境有何關聯？ | 海洋文化（達悟）、高山文化（泰雅、布農），社會制度與歲時祭儀。 |
| 第二單元 | L1 | 臺灣為什麼在大航海時代崛起 | 地理位置的戰略核心，漢人、日本浪人、西方海權的交會。 |
| | L2 | 大航海時代在臺灣留下哪些影響 | 城堡建築（熱蘭遮城、聖多明哥城）、外來農作物與語言借詞。 |
| 第三單元 | L1 | 早期移民如何在臺灣建立家園？ | 鄭氏時期的軍墾、清初的移墾社會、宗族與信仰。 |
| | L2 | 開港通商為什麼改變了臺灣的發展 | 茶、糖、樟腦外銷，淡水/板橋/大稻埕的興起，西洋建築引進。 |
| 第四單元 | L1 | 人們如何適應不同地形創造所需？ | 水利建設（曹公圳、八堡圳）、聚落發展與地名的關係。 |
| | L2 | 沿海的利用為什麼呈現多元發展？ | 漁業、鹽業（井仔腳）、養殖業與生態保護。 |
| | L3 | 土地開發與環境保護該如何抉擇？ | 水資源短缺、地層下陷問題，永續發展的建設性思考。 |

## 三、南一版 (Nan Yi) - 108 課綱 (五上)

### 課程目錄
| 單元 | 課次 | 課程名稱 | 關鍵內容研究備註 |
|:---:|:---:|:---|:---|
| 第一單元 | L1 | 鳥瞰台灣 | 台灣的地形特色（五大地形）、島嶼起源（板塊碰撞）。 |
| | L2 | 海中誕生的家園 | 火山與珊瑚礁島嶼、生物多樣性與地理隔離的關係。 |
| | L3 | 當人類來到臺灣島 | 史前文化發展歷程，環境變遷對史前生活的影響。 |
| 第二單元 | L1 | 島嶼上的子民 | 原住民與大自然的共生哲學，傳統領域的分配與維護。 |
| | L2 | 島上居民的生活 | 性別平權議題、新住民對台灣文化的豐富與融合。 |
| 第三單元 | L1 | 豐饒之地 | 農業社會的形成、埤圳水利系統的社會連結（共好精神）。 |
| | L2 | 山中的故事 | 山區物產、林業發展、山地部落的轉型與觀光。 |
| 第四單元 | L1 | 潟湖上的海上貿易 | 安平、鹿港的商貿起源，潟湖環境對港口發展的利弊。 |
| | L2 | 大航海時期來臺的人們 | 顏思齊、鄭芝龍的海盜/商貿武裝，荷、西、鄭的角力。 |
| | L3 | 大航海時期對臺的影響 | 全球化早期的台灣角色，外來文化對本土社會的層積作用。 |
