## 一、康軒版 (Kang Hsuan) - 108 課綱 (四上)

| L5 | 假如給我三天光明 | 海倫凱勒傳記，透過缺失感悟對感官價值的珍惜。 |
| L6 | 攀登生命的高峰 | 探險家或偉人克服天險實現目標的精神。 |
| L7 | 美味的一堂課 | 生活美學：從烹飪或飲食中學習文化與感官體驗。 |
| L8 | 建築界的長頸鹿 | 台北101或其他現代建築的結構設計與科技高度。 |
| L9 | 請到我的家鄉來 | 國際視野：邀請外國朋友介紹各國特色與文化。 |
| L10 | 奇幻旋律 | 音樂感受：探討聲音如何激發想像力與情緒。 |
| L11 | 兔子先生等等我 | 想像文學：引導學生進入超現實的童話空間。 |
| L12 | 老鞋匠和小精靈 | 格林童話：關於勤勞、報恩與善的連鎖反應。 |

## 二、翰林版 (Han Lin) - 108 課綱 (四上)

### 課程目錄
| 課次 | 課程名稱 | 關鍵內容研究備註 |
|:---:|:---|:---|
| L1 | 美麗島 | 台灣地理美學：從詩歌角度讚頌蘭嶼或全台景觀。 |
| L2 | 請到我的家鄉來 | 跨文化溝通：不同國家的風情、飲食與禮儀介紹。 |
| L3 | 鏡頭下的家鄉 | 齊柏林《看見台灣》視角，環境保護與國土監測。 |
| L4 | 飛行夢 | 航空史與夢想：萊特兄弟或各種飛行試驗的啟發。 |
| L5 | 月光下 | 文學想像：中秋、月色下的感官記憶。 |
| L6 | 又遠又近的月亮 | 科學與文學：探討月球奧祕與人類的太空聯繫。 |
| L7 | 松鼠先生的麵包 | 團隊合作與溝通：分享與共同解決問題。 |
| L8 | 平凡的大俠 | 性格教育：隱藏在平凡生活中的俠義精神。 |
| L9 | 王子折箭 | 成語寓言：團結力量大的具體實踐。 |
| L10 | 海中的熱帶雨林 | 海洋科普：珊瑚礁生態系統的脆弱與重要性。 |
| L11 | 美食島 | 台灣在地飲食文化：夜市小吃與文化認同感。 |
| L12 | 寧靜的音樂會 | 感官轉移：在安靜中感受萬物的律動。 |

## 三、南一版 (Nan Yi) - 108 課綱 (四上)

### 課程目錄
| 課次 | 課程名稱 | 關鍵內容研究備註 |
|:---:|:---|:---|

| L2 | 奶奶的排骨粥 | 親情記憶：食物背後的愛與傳統工序。 |

| L12 | 戴斗笠的地藏 | 善念傳承：日本寓言中的布施與溫情。 |
