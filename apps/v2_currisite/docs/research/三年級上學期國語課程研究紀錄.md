| L6 | 小女生 | 性別平等與自我認同（或成長故事）。 |

## 二、翰林版 (Han Lin) - 108 課綱 (三上)

### 課程目錄
| 課次 | 課程名稱 | 關鍵內容研究備註 |
|:---:|:---|:---|
| L1 | 時間是什麼 | 探討抽象的時間概念。 |
| L2 | 明天再寫 | 拖延心理與時間管理。 |
| L3 | 提早五分鐘 | 建立生活好習慣的建設性建議。 |

| L5 | 便利貼的妙用 | 生活小物的發明故事與創意。 |
| L6 | 小鉛筆大學問 | 重點工具背後的製造與知識。 |
| L7 | 風的味道 | 感官體驗與季節變化。 |
| L8 | 寄居蟹找新家 | 環境保護與生態觀察（換殼危機）。 |
| L9 | 阿朗壹古道 | 自然地景保護與步行體驗。 |
| L10 | 秋千上的婚禮 | 魯凱族文化（或其他族群）傳統習俗。 |
| L11 | 一路平安 | 交通安全與守護的心意。 |
| L12 | 不一樣的團圓 | 跨文化或特殊家庭的節慶體驗。 |
