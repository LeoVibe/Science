# 五年級上學期數學課程研究紀錄 (G5S1 Mathematics Curriculum Research)

**版本**: v1.0.0  
**最後更新時間**: 2026-02-18 23:30  
**研究對象**: 康軒、翰林、南一 三大出版社 108 課綱課程目錄與內容概要。

---

## 一、康軒版 (Kang Hsuan) - 108 課綱 (五上)

### 課程目錄
| 單元 | 單元名稱 | 學習重點 |
|:---:|:---|:---|
| U1 | 多位小數與加減 | 認識多位小數、位值表、小數的大小比較與加減法。 |
| U2 | 因數與公因數 | 認識因數、判別因數、公因數與最大公因數。 |
| U3 | 倍數與公倍數 | 認識倍數、判別 2, 5, 10 的倍數、公倍數與最小公倍數。 |
| U4 | 擴分、約分和通分 | 等值分數的概念、擴分、約分、通分的計算方法。 |
| U5 | 多邊形與扇形 | 多邊形的性質、三角形邊長關係、內角和、扇形與圓心角。 |
| U6 | 異分母分數的加減 | 異分母分數的加法與減法、應用問題。 |
| U7 | 線對稱圖形 | 認識線對稱圖形、對稱軸、對稱點、對稱邊、對稱角。 |
| U8 | 整數四則運算 | 含有括號的計算、乘除混合運算、分配律。 |
| U9 | 面積 | 平行四邊形、三角形、梯形的面積公式與計算。 |
| U10 | 柱體、錐體和球 | 認識角柱、圓柱、角錐、圓錐、球的構成要素與性質。 |

## 二、翰林版 (Han Lin) - 108 課綱 (五上)

### 課程目錄
| 單元 | 單元名稱 | 學習重點 |
|:---:|:---|:---|
| U1 | 折線圖 | 認識折線圖、繪製折線圖、報讀與分析資料。 |
| U2 | 倍數與因數 | 認識倍數、因數、倍數與因數的關係、判別法。 |
| U3 | 平面圖形 | 三角形邊長關係、內角和、四邊形性質、多邊形。 |
| U4 | 公倍數與公因數 | 公倍數、最小公倍數、公因數、最大公因數的應用。 |
| U5 | 立體形體 | 面的垂直與平行、認識柱體（角柱/圓柱）與錐體（角錐/圓錐）、球。 |
| U6 | 四則運算 | 兩步驟與三步驟的計算、交換律、結合律、分配律。 |
| U7 | 擴、約分與加減 | 擴分、約分、通分、異分母分數的大小比較與加減。 |
| U8 | 面積 | 平行四邊形、三角形、梯形的面積計算。 |
| U9 | 乘以幾分之一 | 分數乘以分數（單位分數）、整數乘以分數。 |
| U10 | 扇形 | 認識扇形、圓心角、幾分之幾圓。 |

## 三、南一版 (Nan Yi) - 108 課綱 (五上)

### 課程目錄
| 單元 | 單元名稱 | 學習重點 |
|:---:|:---|:---|
| U1 | 數的十進位結構 | 認識一億以上的數、多位小數、大數的加減。 |
| U2 | 因數和倍數 | 整除、因數、公因數、最大公因數、倍數、公倍數、最小公倍數。 |
| U3 | 多邊形 | 多邊形性質、正多邊形、三角形邊長關係、內角和。 |
| U4 | 擴分、約分和通分 | 擴分、約分、通分的意義與操作。 |
| U5 | 線對稱圖形 | 認識線對稱圖形、對稱要素、繪製線對稱圖形。 |
| U6 | 平行四邊形、三角形和梯形面積 | 各種平面圖形的面積公式推導與複合圖形計算。 |
| U7 | 時間的計算與應用 | 時間的乘法與除法（複名數）、時間應用問題。 |
| U8 | 正方體和長方體的表面積 | 認識表面積、展開圖、計算正方體與長方體的表面積。 |

## 四、研究結論與建議
1.  **核心概念一致**：三大版本在五上皆涵蓋「因數倍數」、「多邊形/面積」、「分數運算（異分母/擴約分）」、「立體形體/表面積」等核心議題。
2.  **編排差異**：
    *   **南一版** 將「表面積」與「時間計算」放入五上，較為提前。
    *   **翰林版** 將「折線圖」置於首單元，並有獨立的「乘以幾分之一」單元。
    *   **康軒版** 對於「多位小數」與「整數四則」有完整的單元規劃。
3.  **題庫設計方向**：建議強化「幾何圖形的性質推導」與「分數/因倍數的應用情境」，培養邏輯推理與解決問題的能力。
