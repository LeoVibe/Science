## � 協作手冊 (Workflow Guide for AI)

1.  **檔案命名規範**: 嚴格遵守 `agent/CONTRACT.md`。檔名必須為 `{課次ID}_{標題}.json`，標題須與本總表一致。
2.  **目錄修正**: 若發現網站顯示名稱與本表不符，優先修改平台路徑 JSON 的 `meta.title`。
3.  **引述方式**: 在討論中請使用：「依據『國小課程總表』五年級 S1 國語欄位...」。
4.  **研究流程**: 
    - 取得新來源 → 讀取內容 → 在 `docs/research/` 建立詳細研究筆記 → 更新本總表「狀態」與「課程目錄」→ 最後執行檔案生成。
