## 一、康軒版 (Kang Hsuan) - 108 課綱 (113/114 下)

### 課程目錄
| 課次 | 課程名稱 | 單元主題 | 關鍵內容預測/研究備註 |
|:---:|:---|:---|:---|
| L1 | 你會怎麼回答？ | 第一單元：換一個角度 | **內容收錄**：三個說話藝術故事。1.邱吉爾以「簽大名忘了寫內容」風趣回擊辱罵。2.黃美廉以「我只看我所有的」回應殘疾。3.艾森豪以「標點符號」比喻演講圓滿結束。 |
| L2 | 智救養馬人 | 第一單元：換一個角度 | **內容收錄**：改寫自《晏子春秋》。晏子假意列舉三條死罪，實則勸諫齊景公莫為一馬而失民心、壞名聲，展現委婉勸諫的機智。 |
| L3 | 真正的「聰明」 | 第一單元：換一個角度 | **內容收錄**：蔡淇華著。從小車廣告「起步最快」與愛因斯坦名言出發，論述聰明是「認清自己、放對位置」，在適合的跑道發揮優勢。 |
| L4 | 小記者，出動！ | 第二單元：職業任意門 | **內容收錄**：全班化身小記者進行職業採訪。 1. 採訪急診室醫師李家豪：探討因病母投入醫界的初衷、面對醫學疑團的無奈，以及在急診室與死神拔河的使命感。 2. 採訪古生物修復師王恩：描述將化石清修、修補至重現樣貌的精細過程，強調細心與耐心是解開時空密碼的關鍵。 |
| L5 | 奇幻光芒的祕密 | 第二單元：職業任意門 | **內容收錄**：作家陳郁如分享創作心路歷程。記述四十歲因與女兒閱讀奇幻小說重拾作家夢，利用寂靜的深夜努力寫作，並立志創作東方文化背景的奇幻小說。描述面對「寫作黑洞」時透過旅行與休閒尋找靈感，強調「不放棄」是通往成功的關鍵。 |
| L6 | 人「聲」就是戲！ | 第二單元：職業任意門 | **內容收錄**：走進配音員的「聲音魔法室」。描述配音員需要眼、耳、鼻、口高度配合，一邊盯螢幕、一邊聽原音、一邊抓聲息。介紹一人分飾多角（公主、男孩、老奶奶）的技巧，以及如何將真實情感（如喜怒哀樂、武打氣聲）融入聲音以產生共鳴。強調台下的觀賞分析與嗓音開發是必備的「練功」。 |
| L7 | 真相？真相！ | 第三單元：海洋這麼說 | **內容收錄**：卓秋汝著。論述「懷疑精神」與「實證態度」的重要性。舉例：1. 鯨魚曾被誤認為魚類，後由呼吸方式與繁殖驗證為哺乳類。 2. 潮汐曾被視為神靈力，後觀測發現是月球引力。 3. 地球由平轉圓的認知改革（麥哲倫環球航行）。強調不應盲從，應勇於追根究柢。 |
| L8 | 你想做人魚嗎？ | 第三單元：海洋這麼說 | **內容收錄**：余光中新詩。以一系列排比與設問（海深、海闊、海量、海涵）引發對大海的好奇。對比陸上化石與海中活生生的大翅鯨，展現海洋的神奇與古老記憶。邀請讀者「向陸地請假」，推開浪花的琉璃門（海生館），化身人魚一窺海底隱祕。 |
| L9 | 海洋的殺手 | 第三單元：海洋這麼說 | **內容收錄**：李弘善著。以無人島亨德孫島累積18公噸垃圾與「1992黃色小鴨事件」揭示洋流如何傳遞塑膠。揭露塑膠微粒進入食物鏈（塑膠鉤蝦、海洋塑膠生物圈）的危害。強調減塑、限塑以及從源頭減量的環保永續行動。 |
| L10 | 玉米人的奇蹟 | 第四單元：來自遠古的神話 | **內容收錄**：馬雅神話。胡利肯（天神）與古祖馬茲（海神）以語言創造世界。經歷「泥人」（意志薄弱、易碎）與「木人」（無敬畏感恩之心）的失敗嘗試後，由動物獻上玉米麵團，最終造出具備優雅語言、健美身形、領悟力與感恩心的完美人類。 |
| L11 | 幸福的火苗 | 第四單元：來自遠古的神話 | **內容收錄**：希臘神話。普羅米修斯不忍人類在嚴寒中受凍、遭狼群威脅，在雅典娜協助下盜取天火。火帶來溫暖、熟食與安全感。普羅米修斯最終因違反宙斯禁令被鎖在岩壁上受鷹啄之苦，但他帶給人類的幸福火苗卻永不熄滅。 |
| L12 | 神農嘗百草 | 第四單元：來自遠古的神話 | **內容收錄**：中國神話。炎帝神農氏為了解除飢餓教民農耕，為了解除疾病不忍族人中毒，親自利用「琉璃肚」嘗試百草，分辨藥性與毒性。後獲天神贈「赭鞭」協助檢驗。最終因誤食斷腸草（開黃花藤蔓）中毒身亡，遺留《神農本草經》造福後世。 |
| 閱 1 | 溜出不一樣的人生－楊元慶 | 閱讀階梯一 | 溜溜球達人的奮鬥故事。 |
| 閱 2 | 旗魚王 | 閱讀階梯二 | 海洋文學，關於自然的敬畏與勇氣。 |

## 二、翰林版 (Han Lin) - 108 課綱 (113/114 下)

### 課程目錄
| 課次 | 課程名稱 | 單元大綱 | 關鍵內容研究備註 |
|:---:|:---|:---|:---|
| L1 | 鵝鑾鼻詩 | 第一單元：禮讚大自然 | **內容收錄**：趙天儀詩作。站在台灣最南端，將燈塔視為發光體，海則是永不休止的音符。關懷台灣歷史的開發（南到北、農到工），在無垠大海與無限天空下，立足南方仰望晴空。 |
| L2 | 山與海的交響樂──東海岸鐵道 | 第一單元：禮讚大自然 | **內容收錄**：郝譽翔散文。描述從台北到花蓮的鐵路之旅。經歷靜謐的山城（瑞芳、猴硐）、福隆後的太平洋美景，感受山壁高聳與海浪捲動鵝卵石的聲音。強調東海岸鐵道是「山與海護衛著的鐵路」。 |
| L3 | 我眼中的東方之最 | 第一單元：禮讚大自然 | **內容收錄**：褚士瑩散文。分享獨特亞洲景點：1.緬甸曼德勒山的寂靜夜景與白玉塔。2.尼泊爾獨有的三角形國旗（象徵山峰與日月長存）。3.不丹政府保護文化的「骨氣」（高額觀光費投入文化保存）。 |
| L4 | 滿修女採訪記 | 第二單元：溫暖的雙手 | **內容收錄**：詹怡宜採訪。敘述來自菲律賓的滿詠萱修女在澎湖聖心教養院服務重殘兒童的故事。強調「照顧他們直到上天堂」的無私信念，認為愛不需要追求治癒奇蹟，而是全然接納他們現在的樣子。 |
| L5 | 誰該被派去非洲 | 第二單元：溫暖的雙手 | **內容收錄**：連加恩家書。引用史懷哲的故事（因意識到家庭富裕是種幸運而非功勞，決定開發優勢助人）。提出助人的前提是「先感覺自己是幸運的接受者」，從而將領受的愛向下翻轉分享給世界。 |
| L6 | 幸福的味道 | 第二單元：溫暖的雙手 | **內容收錄**：小野與女兒的對談。透過刷油漆後的鳳梨清香、媽媽洗草蓆的茶葉香，以及哥哥在夏夜講述的故事，引導讀者發現幸福往往藏在微細的感官記憶中。 |
| L7 | 生活有感──詩兩首 | 第三單元：生活萬花筒 | **內容收錄**：杜秋娘《金縷衣》（勸人愛惜少年時、及時行樂/努力）與朱熹《觀書有感》（以方塘活水比喻讀書能帶來心靈的清澈與源頭能量）。 |
| L8 | 懶人包大解密 | 第三單元：生活萬花筒 | **內容收錄**：科普文。探討媒體如何透過「濃縮與簡化」製作懶人包與一張圖新聞。提醒閱聽人要注意資訊在簡化過程中被刪除或隱藏的風險，建立批判性的識讀能力。 |
| L9 | 良言一句三冬暖 | 第三單元：生活萬花筒 | **內容收錄**：介紹棒球教練委婉的回饋、甲乙獵人妻子的對話對比（鼓勵 vs. 冷語），以及大將凱末爾戰勝後仍給敵將保留面子的誠懇，強調言語的力量與同理心。 |
| L10 | 擅長推理的人 | 第四單元：思考的智慧 | **內容收錄**：改寫自柯南‧道爾《福爾摩斯》。華生初見福爾摩斯，驚訝於對方能精準推斷他「來自阿富汗」。福爾摩斯解析其觀察邏輯：臉色黝黑但手腕白皙（日曬）、受傷姿勢、時局判斷，展現卓越的演繹推理法。 |
| L11 | 草船借箭 | 第四單元：思考的智慧 | **內容收錄**：改寫自《三國演義》。周瑜故意刁難諸葛亮限期造箭。諸葛亮利用天文（大霧）、心理（曹操多疑）與物理（草船受箭），在短短三日內「借」得十萬枝箭。 |
| L12 | 三個問題 | 第四單元：思考的智慧 | **內容收錄**：改寫自托爾斯泰寓言。國王尋找三個重要問題的答案（時機、人、事）。隱士透過現實考驗（救助受傷敵人）讓國王領悟：最重要的時刻是「現在」，重要的人是「身邊的人」，最重要的事是「做好事」。 |

## 三、南一版 (Nan Yi) - 108 課綱 (113/114 下)

### 課程目錄
| 課次 | 課程名稱 | 單元大綱 | 關鍵內容研究備註 |

| L1 | 穿越時空的味道 | 第一單元：生活味覺 | **內容收錄**：李鼎散文。描述閱讀伴著特殊的味道（茶香、咖啡香），並習慣用當時環境小物當書籤（茶包袋、入場券等），讓氣味帶領重回閱讀當下的感動。 |
| L2 | 在黑暗中乘著音樂飛翔 | 第一單元：生活味覺 | **內容收錄**：盲人鋼琴家黃裕翔的故事。失明的他用耳朵探索世界，收集生活中的各種聲音（火車、雨聲、笑聲）作為創作素材，甚至在大賣場輕敲廚具判斷品質。 |
| L3 | 色香味的陽光 | 第一單元：生活味覺 | **內容收錄**：林芳萍散文。描述阿嬤家的陽光有各種果實的色彩與香味（蓮霧紅、葡萄紫、木瓜橘黃）。作者曾偷吃鄰居芭樂被抓包而道歉，體會到童年生活的趣味與人情。 |
| L4 | 縣官審石頭 | 第二單元：機智妙應 | **內容收錄**：改編自民間故事。縣官趙大老爺透過「審石頭」並體罰石頭讓群眾大笑，誘使嫌犯將錢丟入熱水盆，藉由水面浮現的「油花」判定偷錢者。 |
| L5 | 高明說話術 | 第二單元：機智妙應 | **內容收錄**：論說文。強調「良言一句三冬暖」，引用尼克森總統幽默面對飛機故障、設計公司主管鼓勵員工產出佳作等例子。 |
| L6 | 讀書報告佐賀的超級阿嬤 | 第二單元：機智妙應 | **內容收錄**：島田洋七作品讀後感。描述戰後貧困生活中，阿嬤用智慧（磁鐵黏廢鐵、河流攔蔬果）與樂觀態度影響昭廣，教會他「窮得很開朗」。 |
| L7 | 魔術師爸爸 | 第三單元：溫情滿人間 | **內容收錄**：米雅詩作。以季節為軸，描述爸爸化身為小花、樹木、落葉與煙，雖然不在身邊，但守護的心意如同溫熱的眼淚親吻過孩子的臉。 |
| L8 | 八歲一個人去旅行 | 第三單元：溫情滿人間 | **內容收錄**：吳念真作品。八歲時獨自坐火車去宜蘭。途中遇到親切老婆婆互相扶持（對方給芭樂，他幫忙塗萬金油），展現了陌生人間的溫暖信任。 |
| L9 | 紅鼻子醫生 | 第三單元：溫情滿人間 | **內容收錄**：報導文學。採訪馬照琪創辦的協會，介紹小丑醫生如何透過專業表演在醫院為病童帶來歡笑，療癒心靈。 |
| L10 | 沉默的動物園 | 第四單元：世界奇觀 | **內容收錄**：科普散文。介紹祕魯納斯卡線（Nazca Lines），沙漠表面巨大動物、幾何與花卉圖形（狗、猴、蜂鳥等），探討其為天文曆或灌溉系統的神祕遺跡。 |
| L11 | 地下護衛軍 | 第四單元：世界奇觀 | **內容收錄**：歷史科普。介紹秦始皇兵馬俑。描述其壯麗規模（八千件陶俑）與栩栩如生的將軍、士兵造型，展現秦代巅峰工藝。 |
| L12 | 金字塔之謎 | 第四單元：世界奇觀 | **內容收錄**：科普散文。探討古埃及金字塔營造技術（切割搬運巨石、利用斜坡堆疊）以及法老王追求永生的木乃伊文化。 |

## 四、研究結論與協作建議

1.  **結構穩定性**：目前 108 課綱五年級教材已進入穩定成熟期，113 下與 114 下之內容變動率極低（主要為補充教材或排版調整），上述目錄可用於 114 下之題庫生成。
2.  **題庫產出策略**：
    *   **康軒**：側重「角度切換」與「海洋環保」，建議題庫加強相關科普與價值判斷題。
    *   **翰林**：包含較多「社交」與「成功典範」故事，建議題庫強化人物特質分析。
    *   **南一**：在最後單元引入大量「歷史古文明」知識（龐貝、兵馬俑），需準備相關背景知識。
3.  **後續追蹤**：若發現部分課次內容與本研究不符，請第一時間更新本文件並記錄於 `record/CHANGELOG.md`。
