# 國語題庫設計原則與研發成果

## 出題注意事項
### 一、 核心設計原則 (高品質架構)
為了徹底解決「答案規律明顯」與「題目能力鑑別度不足」的問題，所有題庫必須嚴格執行以下規範：


**1. 認知層次分佈 (PIRLS 閱讀素養標準)**
題目應依據以下比例進行分佈，確保涵蓋由淺入深的思考：
* 事實提取 (30%)：測驗具體細節、時間、人物屬性。
* 理解推論 (50%)：測驗行為動機、事情轉折、因果關係、隱喻意涵。
* 應用評論 (20%)：測驗文章主旨、角色評價、結合生活情境的判斷。

**2. 高品質誘答項 (Plausible Distractors) 邏輯**
* 排除荒謬項：禁止出現與課文無關、邏輯不通或過於幼稚的選項（如：肚子餓、想回家）。
* 邏輯誤導法：誘答項應包含「部分正確的細節」、「因果關係錯置」或「常識性錯誤但文章中未提及」的描述。

**3. 答案分佈隨機化**
* 正確答案需經算法打散，避免出現「正確答案集中在 B」或「連續三題答案相同」的模式。

**4. 防猜機制：視覺與結構對稱性**
* 字數對稱：四個選項的字數長度差異應控制在 10%-15% 以內。嚴禁正確答案顯著比其他選項長。
* 語法對稱：選項的結構必須一致（例如：全為名詞短語、全為四字成語或全為因果句），避免學生透過語感排除錯誤答案。


### 二、 系統介接規格 (antigravity Schema)
為了確保數據能完美匯入專案系統，單題結構定義如下：

```json
{
  "meta": {
    "grade": "G3/G4/G5",
    "semester": "S2",
    "publisher": "Nani",
    "lesson_id": "L1-L12"
  },
  "content": {
    "taxonomy": "literal/inferential/applied",
    "question": "題目描述",
    "options": ["選項A", "選項B", "選項C", "選項D"],
    "answer_index": 0,
    "explanation": "具備教學意義的解析內容"
  }
}
```

### 三、 已完成之研發成果彙整
目前已根據上述規範完成 南一版 108 課綱 (113/114 下) 以下學年度之題庫設計：

**1. 三年級下學期 (共 12 課 / 120 題)**
* 設計重點：強化對「自然現象觀察」與「基礎邏輯推論」的測驗。
* 代表課目：L3《愛玉變身術》(科學過程)、L4《楊修猜字》(邏輯推理)。

**2. 四年級下學期 (共 12 課 / 120 題)**
* 設計重點：側重「民俗文化價值」與「環境保護實踐」的鑑別。
* 代表課目：L1《火旁龍》(團隊精神)、L9《用一公斤愛嘉明湖》(永續行動)。

**3. 五年級下學期 (共 12 課 / 120 題)**
* 設計重點：大幅增加「機智應變」與「世界奇觀」的跨文本整合題。
* 代表課目：L4《縣官審石頭》(偵探邏輯)、L12《金字塔之謎》(文明智慧)。

### 四、 未來製作與校閱原則
* 一致性優先：任何新產出的題目若未經「選項長度校準」，即判定為低品質。
* 源頭檢查：產出前需對照 課程研究紀錄.md，確保知識點不超綱且符合當前出版社趨勢。
* 解析價值：解析內容應點出「誘答項的誤區」以及「正確答案的推導過程」。
