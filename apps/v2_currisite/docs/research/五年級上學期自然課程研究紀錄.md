## 一、康軒版 (Kang Hsuan) - 108 課綱 (五上)

### 課程目錄 (基於標準 108 課綱與教材趨勢對齊)
| 單元 | 課次 | 課程名稱 | 關鍵內容研究備註 |
|:---:|:---:|:---|:---|
| 第一單元 | L1 | 觀測太陽 | 太陽升落規律、方位、高度角的測量與影子變化。 |
| | L2 | 太陽對生活的影響 | 日規、日晷原理；太陽能的應用（能源建設）。 |
| 第二單元 | L1 | 植物器官的功能 | 根、莖、葉的形態與生理功能（吸水、運輸、光合作用）。 |
| | L2 | 植物的生長與環境 | 水生、陸生植物的適應策略；種子的構造與傳播。 |
| 第三單元 | L1 | 水溶液的性質 | 溶解與沉澱、水溶液的顏色、氣味與濃度概念。 |
| | L2 | 水溶液的酸鹼性 | 石蕊試紙、自製酸鹼指示劑（紫色高麗菜）與中和。 |
| | L3 | 水溶液的導電性 | 電解質概念、簡易電路測試水溶液是否導電。 |
| 第四單元 | L1 | 力與運動 | 定量力（彈簧秤）的測量；運動快慢（速度）的比較。 |
| | L2 | 摩擦力 | 影響摩擦力的因素（接觸面、重量）與生活中的應用。 |

## 二、翰林版 (Han Lin) - 108 課綱 (五上)

### 課程目錄
| 單元 | 課次 | 課程名稱 | 關鍵內容研究備註 |
|:---:|:---:|:---|:---|
| 第一單元 | L1 | 太陽與生活 | 太陽輻射能的角色、影子與時間（計時器）。 |
| | L2 | 太陽的位置變化 |高度角概念、四季太陽位置的路徑差異。 |
| | L3 | 光的折射 | 光的性質、虹與霓、透鏡的成像原理與應用。 |
| 第二單元 | L1 | 不同環境的植物 | 森林、海邊、溼地植物的特化結構。 |
| | L2 | 植物存活的本事 | 特殊根、莖的變態；抗旱或排水的葉片機制。 |
| | L3 | 植物繁衍大顯身手 | 花部構造、傳粉方式與果實種子的傳播策略。 |
| | L4 | 植物的特徵與分類 | 二分法分類概念。 |
| 第三單元 | L1 | 水溶液中的物質 | 溶解度、飽和水溶液與結晶現象。 |
| | L2 | 水溶液的酸鹼性 | 標準指示劑（石蕊）與生活中常見物質的酸鹼檢測。 |
| | L3 | 水溶液的導電性 | 通電實驗與安全用電。 |
| 第四單元 | L1 | 地球引力 | 重力感官、重量與質量的基礎差異。 |
| | L2 | 力的測量 | 虎克定律應用（彈簧受力）；力的大小、方向、作用點。 |
| | L3 | 摩擦力 | 生活中的增減摩擦力設計。 |

## 三、南一版 (Nan Yi) - 108 課綱 (五上)

### 課程目錄
| 單元 | 課次 | 課程名稱 | 關鍵內容研究備註 |
|:---:|:---:|:---|:---|
| 第一單元 | L1 | 太陽在天空中的位置變化 | 基本方位判定、利用高度角觀測器進行時序追蹤。 |
| | L2 | 認識光的現象 | 光的直線傳播、反射（面鏡反射）與折射應用。 |
| | L3 | 能源對生活的影響 | 再生與非再生能源、節約能源與永續建設。 |
| 第二單元 | L1 | 植物根莖葉的功能 | 水分在植物體內的運輸實驗（染色法）。 |
| | L2 | 植物的繁殖 | 有性生殖（花）與無性生殖（根、莖、葉繁衍）的區別。 |
| | L3 | 植物與人類的生活 | 食、衣、住、行、樂中的植物應用與生態保育。 |
| 第三單元 | L1 | 溶解現象 | 溶解過程的微觀想像、溫度對溶解速律的影響。 |
| | L2 | 水溶液的酸鹼性 | 紫色高麗菜汁的變色範圍與水溶液屬性。 |
| | L3 | 水溶液的導電性 | 開路/閉路實驗與水質安全意識。 |
| 第四單元 | L1 | 力的測量 | 彈簧彈性限度、力矩初步感官（翹翹板平衡）。 |
| | L2 | 摩擦力 | 滾動摩擦與滑動摩擦的差異；潤滑劑的作用。 |
| | L3 | 運動狀態的快慢 | 距離與時間的關係，相對速度的建設性觀察。 |
