# 產品需求說明書（摘要）

完整版見 **docs/需求說明書.md**。本摘要供快速對照與驗證用。

---

## 產品定位

- 國小多學科複習練習站（國語、數學、自然、社會、英語／英文；低年級含生活）。
- 支援年級 1～6、出版社南一／康軒／翰林、上下學期；題庫來自 `public/questions/platform/`（唯讀）。

## 畫面與視圖

| 視圖 | 說明 |
|------|------|
| 頂部列 | 年級、學期、出版社、科目、統計、錯題、關於 |
| 主選單 | 無題庫→單一空狀態「題庫建置中」；有題庫→綜合練習、分課練習（字體較小，不顯示題數）、全部題庫 |
| 測驗 | 進度條、即時對錯計數、題目卡、答題後明顯正確/錯誤回饋與解析、下一題／查看結果 |
| 結果 | 得分、總體統計、本次錯題、累積錯題預覽、再練習／返回 |
| 全部題庫 | 依課程 Tab、題目卡片列表 |
| 錯題檢視 | 本次錯題／累積錯題列表與詳情 |
| 統計 | 綜合練習統計、分類統計、練習歷史 |

## 關鍵流程

- **題庫載入**: manifest → files → 依序 fetch JSON；路徑含 base（如 /Science/）。
- **分課**: 僅當前學期；按鈕顯示「第 N 課：標題」，字體較小、不顯示題數。
- **答題**: 確認後寫入 localStorage（按 grade/subject/semester/publisher）；即時更新正確/錯誤數與回饋動畫。

## 資料格式

- 題庫路徑與 JSON 格式：見 **agent/CONTRACT.md**。
- localStorage：答題歷史、使用者偏好、練習歷史、測驗進度（鍵名見完整需求說明書）。

實作與驗證時請以 **需求說明書.md** 為準。
