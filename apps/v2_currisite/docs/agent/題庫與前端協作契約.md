# 題庫與前端協作契約（單一來源）

**版本**: 1.0 | **更新**: 2026-02-18  
**讀者**: Cursor（前端）、Antigravity（題庫）  
**用途**: 路徑、檔名、JSON 格式、分工、檢查清單，以此份為準，避免重複定義。

---

## 1. 路徑規則（雙方必守）

- **根目錄**: `public/questions/platform/`
- **路徑格式**: `G{年級}/{科目}/S{學期}/{出版社}/`
  - 年級: G1～G6
  - 科目: `國語`、`數學`、`自然`、`社會`、`英文`（G3–G6）、`英語`（G1–G2）、`生活`（G1–G2）
  - 學期: S1（上）、S2（下）
  - 出版社: `康軒`、`南一`、`翰林`
- **前端讀取**: 先 fetch `{baseUrl}questions/platform/G{年級}/{科目}/S{學期}/{出版社}/manifest.json`，再依 `files` 依序 fetch 同目錄下的 JSON。部署在子路徑時 `baseUrl` 為 Vite `base`（如 `/Science/`）。

---

## 2. 檔名與 manifest

- **每課一檔**: `{課次ID}_{課程標題}.json`（例: `Sci1_植物的身體.json`、`L1_心的悄悄話.json`）
- **manifest.json**: 每「年級/科目/學期/出版社」目錄一個，內容至少:
```json
{ "files": [ "L1_xxx.json", "L2_xxx.json" ] }
```
- `files` 僅檔名、順序即課程順序。

---

## 3. 單課題庫 JSON 格式

- **必備**: `meta`、`questions`
- **meta 必填**: `grade`（grade_1～grade_6）、`semester`（semester_1|semester_2）、`subject`（與目錄一致）、`publisher`（kang_hsuan|nan_yi|han_lin）、`lesson`（課次 ID）、`title`（課程標題，分課按鈕顯示用）
- **題目**: `id`、`type`（multiple_choice|true_false|fill_in_the_blank）、`question`、`answer`、`options`（選擇題必填）；`explanation` 建議填。
- **答案**: 選擇題可字串（與選項一致）或 0 起索引；是非題 "True"/"False"。

---

## 4. 分工

| 角色 | 負責 | 不做 |
|------|------|------|
| **Antigravity** | 產出/維護 platform 下 JSON 與 manifest；符合本契約 | 不改前端程式 |
| **Cursor** | 前端讀取與渲染；唯讀 platform | 不直接改題庫 JSON；錯誤記入 record/DATA_ERRORS.md |

---

## 5. 檢查清單（交檔前）

**Antigravity**: [ ] 路徑 G{年級}/{科目}/S{學期}/{出版社}/ [ ] 檔名 {課次ID}_{標題}.json [ ] 每目錄有 manifest 且 files 完整 [ ] meta 含 title（課程標題）、publisher 代碼 [ ] 選擇題 answer 與 options 一致或為索引  
**Cursor**: [ ] fetch 使用 baseUrl + questions/platform/... [ ] 404 時顯示友善空狀態（無題庫） [ ] 分課僅顯示當前學期、按鈕用 meta.title [ ] 改版時在 record/CHANGELOG.md 標註版本號與日期時間（YYYY-MM-DD HH:mm），與 Antigravity 對齊釋出。
