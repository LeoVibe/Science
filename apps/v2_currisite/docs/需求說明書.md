# 課後複習網站 需求說明書

本文件為**完整需求說明書**，涵蓋畫面、功能、檔案格式、UI 操作、頁面數量與內容、背後流程設計等所有規格細節，供其他 AI 工具或開發者驗證與實作相同產品。

**文件版本**：1.0  
**最後更新**：2026-02-18  
**對應專案**：ScienceQuest（小學多學科複習練習網站）

---

## 一、專案概述與目標

### 1.1 產品定位

- 小學**多學科複習練習**網站（國語、數學、自然、社會、英語／英文，低年級含生活）。
- 支援**多年級**（1～6）、**多出版社**（南一、康軒、翰林）、**上下學期**切換。
- 題庫來自外部產出（`public/questions/platform/`），前端**唯讀**不修改題庫檔案。
- 本地儲存：答題紀錄、錯題、練習歷史、使用者偏好、測驗進度（localStorage）。

### 1.2 技術棧

- **前端**：Vue 3（Composition API）、Vite。
- **資料**：靜態 JSON 題庫（fetch）、localStorage。
- **部署**：靜態站點，無後端 API。

### 1.3 使用者情境

1. 選擇年級、學期、出版社、科目 → 進入主選單。
2. 主選單可：**綜合練習**（10 題／20 題）、**分課練習**（依當前學期課程）、**全部題庫**（複習模式）。
3. 作答過程即時對錯、紀錄寫入 localStorage；可中斷後再「繼續練習」。
4. 可查看**統計**、**累積錯題**、**關於本站**。

## 二、畫面與頁面清單

全站為**單頁應用（SPA）**，無路由；以「視圖」切換呈現不同畫面。共 **8 個主要視圖** + **1 個全域彈窗**。

| 序號 | 視圖代碼 | 畫面名稱 | 說明 |
|------|----------|----------|------|
| 1 | (全域) | 頂部列 + 關於本站彈窗 | 頂部列固定顯示；關於彈窗可隨時開啟／關閉 |
| 2 | menu | 主選單 | 綜合練習、分課練習、全部題庫入口 |
| 3 | quiz | 測驗頁 | 單題作答、進度條、對錯與解釋、下一題／查看結果 |
| 4 | result | 結果頁 | 得分、總體統計、本次錯題、累積錯題預覽、再練習／返回主選單 |
| 5 | review | 全部題庫（複習） | 依課程分類 Tab、題目卡片列表（題幹＋選項＋答案＋解釋） |
| 6 | wrong-questions | 本次錯題檢視 | 本次練習答錯題目列表與詳情 |
| 7 | all-wrong-questions | 累積錯題檢視 | 當前「年級／科目／學期／出版社」下累積錯題列表與詳情 |
| 8 | statistics | 學習統計 | 綜合練習統計、分類統計、練習歷史記錄 |

### 2.1 各畫面內容與元素（細項）

#### 2.1.1 頂部列（app-header）

- **年級**：下拉選單，選項 1～6 年級；無題庫之年級可標註「(無題庫)」並 disabled 或可選但切換後顯示尚無題庫。
- **學期**：下拉選單，選項「上學期」「下學期」（對應 1、2）。
- **出版社**：按鈕組，康軒／南一／翰林；版面足夠時顯示完整名稱，窄版顯示簡稱（康、南、翰）；當前選中高亮；無題庫之組合可 disabled。
- **科目**：按鈕組，依年級顯示不同科目（見 3.1）；版面足夠時顯示完整名稱，窄版顯示簡稱；當前選中高亮；無題庫之組合可 disabled。
- **統計**：按鈕，點擊進入 statistics 視圖。
- **錯題**：按鈕，點擊進入 all-wrong-questions 視圖。
- **關於**：按鈕，點擊開啟「關於本站」彈窗。
- **響應式**：小螢幕時頂部為**科目按鈕**（圖示+簡稱，可快速切換）+「☰ 選單」按鈕；點選單展開年級／學期／出版社／科目／統計／錯題／關於。
- **樣式**：頂部列背景依當前科目主題色（漸層）；主內容區 `.app-main` 設 `min-height: calc(100vh - 80px)` 以減少切換時抖動。

#### 2.1.2 關於本站彈窗（about-modal）

- **開發緣由**：簡述為 vibe coding 練習、Antigravity + Cursor 協作；聯絡信箱 yotta0280@gmail.com。
- **更版資訊**：以版本條列（例：0.1 版 2026/1/3 … 0.6 版 2026/2/18），每條為版本號、日期、簡述；文末一句「後續將依課程研究產出…」。
- **操作**：點擊遮罩或關閉鈕關閉彈窗。

#### 2.1.3 主選單（MainMenu）

- **標題**：科目圖標 + 科目名 + 「複習」+ 科目圖標（例：📖 國語複習 📖）。
- **副標題**：`{年級}年級 {科目} {上學期|下學期} ({出版社}版)`；若無題庫顯示「⚠️ 尚無題庫」。
- **綜合練習**：兩個按鈕——「基本挑戰 (10題)」「高級挑戰 (20題)」。無題庫時顯示灰色佔位文案。
- **分課練習**：僅顯示**當前學期**的課程名稱，按鈕文案「第 N 課：{課程標題}」，字體較小、不顯示題數。若無題庫則顯示「分課練習 (無對應題庫)」。
- **全部題庫**：一顆按鈕「📖 全部題庫」，無題庫時顯示灰色佔位。
- **背景**：依科目主題色（gradient、textColor）。

#### 2.1.4 測驗頁（QuizView）

- **返回**：返回主選單（若測驗進行中可先確認是否離開並保存進度）。
- **進度條**：視覺進度條 + 文字「第 X 題 / 共 Y 題」。
- **即時統計**：✓ 正確數、✗ 錯誤數、總答題數。
- **題目卡片**：課程標籤（category）、題型標籤（選擇題）；題幹；選項按鈕（A/B/C/D 或 是/否）；確認答案後顯示對錯、正確答案、解釋；可自動進入下一題或手動「查看結果」。
- **快捷鍵**：1–4 或 A–D 可選選項（可選實作）。
- **作答邏輯**：選項 → 確認答案 → 寫入答題紀錄（saveAnswerRecord）→ 顯示結果 → 自動或手動下一題；最後一題後「查看結果」進入 result 視圖。

#### 2.1.5 結果頁（ResultView）

- **標題**：「🎉 答題完成！」
- **得分**：大數字 score / total、百分比。
- **鼓勵文案**：依正確率區間顯示不同訊息（全對／≥80%／≥60%／<60%）。
- **總體統計**：總答題數、總正確數、總錯誤數、正確率（依當前 grade/subject/semester/publisher）。
- **本次答錯**：若有，顯示「本次答錯題目 (N題)」+ 按鈕「📖 查看錯題詳情」→ 進入 wrong-questions 視圖。
- **累積錯題本**：列出前 5 筆錯題（題號、題幹摘要、錯誤次數、正確率），超過 5 題顯示「還有 N 題錯題…」。
- **本次練習統計**：練習類型、答題時間、正確率。
- **最近練習記錄**：最近數筆練習（類型、時間、正確率、得分、耗時）。
- **按鈕**：「🔄 再練習一次」「🏠 返回主選單」。

#### 2.1.6 全部題庫／複習（ReviewView）

- **返回**：「← 返回」回主選單。
- **標題**：「📚 知識複習」。
- **分類 Tab**：依題庫的 category（課程標題）分 Tab，點擊切換顯示該分類題目。
- **題目卡片**：每題顯示類型、題號、題幹、選項（正確項標示）、答案、解釋、小知識（若有）。

#### 2.1.7 本次錯題檢視（WrongQuestionsView）

- **返回**、標題「❌ 錯題檢視」、錯題數量；列表每題：題號、分類、題幹、選項（正確項標示）、解釋。

#### 2.1.8 累積錯題檢視（AllWrongQuestionsView）

- **返回**、標題「❌ 累積錯題檢視」、錯題數量；列表每題：題號、分類、錯誤次數與正確率、題幹、選項、解釋。資料來源為當前 grade/subject/semester/publisher 的 localStorage 錯題列表。

#### 2.1.9 學習統計（StatisticsView）

- **返回**、標題「📊 學習統計報告」、副標題「{年級}年級 {科目} {上學期|下學期} ({出版社}版)」。
- **綜合練習統計**：練習次數、平均得分、平均正確率、平均時間；無則顯示「此項目尚無練習記錄」。
- **分類複習統計**：各分類（課程）答題數、正確／錯誤、正確率進度條；無則顯示「此項目尚無分類練習記錄」。
- **練習歷史記錄**：依時間列最近練習（類型、時間、得分、正確率、耗時）；無則顯示「此項目尚無練習記錄」。

## 三、功能規格與操作流程

### 3.1 全域設定與資料維度

- **四維度**：年級（grade 1–6）、學期（semester 1|2）、出版社（publisher）、科目（subject）。
- **科目依年級**：
  - 1–2 年級：國語、數學、英語、生活。
  - 3–6 年級：國語、數學、英語、自然、社會。
- **UI 顯示**：版面足夠時出版社與科目顯示完整名稱（康軒、南一、翰林；國語、數學等）；窄版改為簡稱（康、南、翰；國、數、英、自、社、生）。
- **題庫路徑**：G3–G6 的「英語」在**路徑**上使用目錄名「**英文**」；G1–G2 使用「英語」。UI 仍可統一顯示「英語」。

### 3.2 題庫載入與「尚無題庫」

- 題庫根目錄：`/questions/platform/`（對應 `public/questions/platform/`）。
- 路徑格式：`G{年級}/{科目}/S{學期}/{出版社}/`，例如 `G3/國語/S1/南一/`。
- 先 fetch `manifest.json`，取得 `files` 陣列；再依序 fetch 各 JSON。若 manifest 或任一檔 404，該組合視為無題庫。
- 無題庫時：主選單顯示「尚無題庫」、分課／綜合／全部題庫為灰色或佔位；不報錯，回傳空陣列。

### 3.3 主選單流程

1. 進入主選單時，依當前 (grade, subject, semester, publisher) 呼叫 `loadQuestions`。
2. **綜合練習**：從當前學期題目中篩選「有效選擇題」（至少 2 選項、答案為有效索引）；可優先納入錯題再補足 10 或 20 題；打亂順序後進入 quiz 視圖。
3. **分課練習**：僅列出**當前學期**的課程（由題目之 category/lessonTitle/lesson 彙整，按 lessonOrder 排序）；點擊某課後，僅從**當前學期**題目中篩選該課題目，再進入 quiz。
4. **全部題庫**：進入 review 視圖，以當前載入之題目按 category 分 Tab 顯示。

### 3.4 測驗流程（Quiz）

1. **開始**：可傳入題目陣列、測驗類型（如「基本挑戰」）、startTime。若有同組合的未完成進度，可詢問「是否繼續」；選繼續則還原題目與已答列表與得分。
2. **作答**：選選項 → 確認 → 寫入 `saveAnswerRecord(questionId, isCorrect, grade, subject, semester, publisher)`；更新 session 正確/錯誤數；顯示對錯與解釋；自動延遲後下一題或最後一題顯示「查看結果」。
3. **進度保存**：每題切換或離開前呼叫 `saveQuizProgress(grade, subject, semester, publisher, { questions, currentIndex, answeredQuestions, score, type, startTime })`。進度逾 24 小時可視為過期並清除。
4. **結束**：最後一題後點「查看結果」→ 計算耗時、正確率 → 寫入 `savePracticeRecord({ grade, subject, semester, publisher, type, score, count, accuracy, duration, ... })` → 切換至 result 視圖，並傳遞 sessionWrongQuestions、sessionStats 等。

### 3.5 結果頁與錯題

- **總體統計／累積錯題**：依當前 (grade, subject, semester, publisher) 呼叫 `getStatistics`、`getWrongQuestions`。
- **本次錯題**：由 result 傳入之 sessionWrongQuestions，點「查看錯題詳情」切換至 wrong-questions 視圖並傳遞該列表。
- **再練習一次**：清除該組合測驗進度後，以當前配置重新 startQuiz（同主選單綜合練習邏輯）。

### 3.6 配置切換（年級／學期／出版社／科目）

- 切換時呼叫 `onConfigChange`：若當前在測驗中，先 confirm 是否離開並保存進度；若在統計或累積錯題頁，可一併回到主選單。
- 年級切換時若當前科目在新年級不可用，自動改為該年級第一個可用科目；出版社＋科目不可用時，先試換出版社，再試換科目。
- 每次變更後 `saveUserPreference(grade, subject, semester, publisher)`，並更新 document.title。

### 3.7 可用性與緩存

- **年級可用**：某年級在任意的 (科目×學期×出版社) 下至少有一組有題庫，則該年級視為有題庫。
- **出版社+科目可用**：某 (grade, subject, publisher) 在 S1 或 S2 任一期有題庫，則該組合視為可用。
- 可用性可緩存（如 Map），題庫載入成功後可清除該組合緩存以更新狀態。無題庫之年級／出版社+科目可在 UI 上 disabled 或標註。

## 四、檔案與資料格式

### 4.1 題庫目錄結構（platform）

```
public/questions/platform/
  G{年級}/{科目}/S{學期}/{出版社}/
    manifest.json
    {課次ID}_{課程標題}.json
    ...
```

- **年級**：G1～G6。
- **科目**（目錄名）：國語、數學、自然、社會、**英文**（G3–G6）、**英語**（G1–G2）、生活。
- **學期**：S1（上學期）、S2（下學期）。
- **出版社**：康軒、南一、翰林。

### 4.2 manifest.json

- 每個「年級/科目/學期/出版社」目錄下一個檔案。
- 內容範例：
```json
{
  "files": [
    "L1_你好，新朋友.json",
    "L2_我們的約定.json"
  ]
}
```
- `files`：僅檔名，順序即課程順序。

### 4.3 單課題庫 JSON

- 每檔一課，檔名：`{課次ID}_{課程標題}.json`。
- 結構：
```json
{
  "meta": {
    "grade": "grade_3",
    "semester": "semester_1",
    "subject": "國語",
    "publisher": "nan_yi",
    "lesson": "L1",
    "order": 1,
    "title": "你好，新朋友"
  },
  "questions": [
    {
      "id": "1",
      "type": "multiple_choice",
      "question": "題幹...",
      "options": ["A", "B", "C", "D"],
      "answer": "B",
      "explanation": "解析..."
    }
  ]
}
```

- **meta 必填**：grade（grade_1～grade_6）、semester（semester_1|semester_2）、subject（與目錄一致）、publisher（kang_hsuan | nan_yi | han_lin）、lesson、title。order 建議填。
- **題型**：multiple_choice（需 options；answer 可字串或 0 起索引）、true_false（answer 為 "True"/"False"，前端可轉 0/1）、fill_in_the_blank（answer 字串）。
- 前端會將 meta.title 作為題目的 category／分課顯示名稱；題目不需另填 category。

### 4.4 載入後題目物件（前端擴充）

- 每題合併 meta：`category = meta.title`（或 lesson）、`lesson`、`lessonTitle`、`lessonOrder`。
- 答案正規化：選擇題 answer 統一為選項索引（0 起）；是非題為 0/1；選項不足的是非題補 `['是','否']`。

### 4.5 localStorage 鍵與結構

- **答題歷史**：鍵 `history_G{年級}_{科目碼}_S{學期}_{出版社碼}`，值為物件，key 為題目 id，value 為 `{ questionId, grade, subject, semester, publisher, total, correct, wrong, lastAnswer, lastAnswerTime }`。
- **使用者偏好**：鍵 `sci_v2_user_preference`，值 `{ grade, subject, semester, publisher, timestamp }`。
- **練習歷史**：鍵 `sci_v2_all_practice_history`，值為陣列，每筆 `{ id, timestamp, grade, subject, semester, publisher, type, score, count, accuracy, duration }`，建議保留最近 200 筆。
- **測驗進度**：鍵 `progress_G{年級}_{科目碼}_S{學期}_{出版社碼}`，值 `{ questions, currentIndex, answeredQuestions, score, type, startTime, timestamp }`；逾 24 小時可清除。

科目碼／出版社碼範例：國語→CHI，數學→MAT，自然→SCI，社會→SOC，英語→ENG；康軒→KNSH，南一→NANI，翰林→HLM。

## 五、UI／UX 規格摘要

- **主題**：依科目有 primary、secondary、gradient、textColor；頂部與主選單背景可依科目變色。
- **按鈕**：統計／錯題／關於 有圖標與文字；出版社／科目為圖標按鈕組，active 態明顯。
- **主內容區**：`.app-main` 固定 min-height，減少切換視圖時版面抖動。
- **響應式**：小螢幕時頂部選單收合為漢堡，展開後可選年級、學期、出版社、科目、統計、錯題、關於。
- **無題庫**：顯示「尚無題庫」或灰色佔位，不報錯。
- **測驗中切換配置**：先 confirm 並保存進度再離開；返回主選單時可提示「是否繼續未完成練習」。

## 六、背後流程設計（關鍵邏輯）

### 6.1 題庫載入流程（loadQuestions）

1. 依 (grade, subject, semester, publisher) 計算路徑：`getSubjectForPath` 使 G3–G6 英語→英文目錄。
2. `fetch(basePath + '/manifest.json')`；失敗則回傳 []。
3. 對 manifest.files 每檔 `fetch(basePath + '/' + fileName)`，解析 JSON。
4. 驗證每檔具 meta + questions；且 meta 與當前 grade/semester/subject/publisher 一致（publisher 用 kang_hsuan 等代碼比對）。
5. 將每題加上 category、lesson、lessonTitle、lessonOrder；答案正規化（選擇題→索引，是非題→0/1）。
6. 合併所有題目，按 lessonOrder 排序，回傳 `{ questions, getAllCategories, getQuestionsByCategory }`。

### 6.2 分課練習與學期一致

- 分課列表**僅來自當前學期**載入的題目，不混合 S1、S2；切換學期後分課按鈕應變為該學期課程名稱。
- 點擊某課後，僅從當前學期題目中篩選該課（category/lessonTitle/lesson）再進入測驗。

### 6.3 答題紀錄與統計

- 每次確認答案後：`saveAnswerRecord(questionId, isCorrect, grade, subject, semester, publisher)` 更新該題 total/correct/wrong。
- 統計頁／結果頁的總體統計與錯題列表，皆依 (grade, subject, semester, publisher) 從同一套 history 計算。

### 6.4 測驗進度恢復

- 進入主選單點「綜合練習」時，先 `loadQuizProgress(grade, subject, semester, publisher)`；若有進度且 answeredQuestions.length > 0，confirm「是否繼續」；若繼續則帶入 savedProgress 到 QuizView，還原 currentIndex、answeredQuestions、score。

## 七、邊界與錯誤處理

- manifest 或題庫 JSON 404：靜默回傳空陣列，UI 顯示尚無題庫。
- 題庫 JSON 格式錯誤或 meta 不符：該檔捨棄（回傳 null），不中斷其餘檔案載入。
- 選擇題 answer 與 options 不一致：前端可嘗試以字串匹配或數字索引解析；若仍無效可略過該題或標記為無效題（綜合練習時篩掉）。
- 無有效選擇題時：主選單綜合／分課可禁用或 alert「目前沒有可用的題目」。
