## ❌ 需要修正的問題

### 1. 答案與選項不匹配（7 個檔案）

以下題目的 `answer` 欄位與 `options` 中的選項**不完全一致**，導致平台無法正確匹配答案。

#### 問題說明
- 平台會自動將字串答案轉換為選項索引
- 如果答案字串與選項內容不完全一致（包含多餘字元、空格差異等），會導致匹配失敗
- 建議：答案必須與選項內容**完全一致**，或直接使用數字索引（0, 1, 2, 3...）

#### 需要修正的檔案清單

| 檔案路徑 | 題目 ID | 問題描述 |
|---------|--------|---------|
| `G3/國語/S1/南一/L9_回家.json` | 1 | answer: `"見見到親愛的家人與溫暖的家"`，但選項是 `"見到親愛的家人與溫暖的家"`（多了一個"見"） |
| `G3/國語/S2/南一/L8_和魚一起游泳.json` | 4 | answer 與選項不完全匹配 |
| `G4/國語/S1/南一/L9_兩個和尚.json` | 4 | answer 與選項不完全匹配 |
| `G4/國語/S1/康軒/L9_請到我的家鄉來.json` | 5 | answer 與選項不完全匹配 |
| `G4/國語/S1/翰林/L8_平凡的大俠.json` | 4 | answer 與選項不完全匹配 |
| `G4/社會/S1/翰林/S6_家鄉故事導覽員.json` | 1 | answer: `"採訪當地的長輩 or 居民"`，選項中可能沒有完全匹配 |
| `G5/國語/S1/康軒/L5_商標的故事.json` | 4 | answer 與選項不完全匹配 |

#### 修正建議

**方法 1：修正答案字串（推薦）**
```json
{
  "id": "1",
  "type": "multiple_choice",
  "question": "...",
  "options": [
    "可以不用上學",
    "見到親愛的家人與溫暖的家",
    "可以看電視",
    "拿到新衣服"
  ],
  "answer": "見到親愛的家人與溫暖的家",
  "explanation": "..."
}
```

**方法 2：使用數字索引**
```json
{
  "answer": 1
}
```
