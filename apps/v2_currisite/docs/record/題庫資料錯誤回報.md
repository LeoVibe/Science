# 題庫資料錯誤回報

本檔案用於記錄從**網站端**發現的題庫資料問題，供 **Antigravity（題庫產出方）** 在源頭修正並重新產出。請勿直接修改 `public/questions/platform/` 內的 JSON。

---

## 回報格式

```markdown
### [日期] 簡短描述
- **路徑/檔案**：例如 `G5/英文/S1/康軒/U1_xxx.json`
- **問題**：例如「題目 #3 的 answer 與 options 不符」
- **建議**：例如「將 answer 改為與選項完全一致的字串」
```
