# UI/UX 設計規格書

**文件版本**: 1.0  
**最後更新**: 2026-02-18  
**用途**: 提供給 Lovable AI 或其他前端開發工具使用，進行網站與服務的介面設計與實作  
**對應專案**: ScienceQuest（小學多學科複習練習網站）


## 操作流程

### 3.1 初始載入流程

1. **頁面載入**
   - 顯示載入動畫（可選）
   - 從 localStorage 讀取使用者偏好 (`loadUserPreference`)
   - 設定預設年級、學期、出版社、科目
   - 更新 `document.title`

2. **題庫載入**
   - 依序 fetch 各題庫 JSON
   - 驗證格式與 meta
   - 合併題目並排序

3. **顯示主選單**
   - 若無題庫: 顯示空狀態
   - 若有題庫: 顯示綜合練習、分課練習、全部題庫選項

### 3.2 配置切換流程

1. **使用者點擊年級/學期/出版社/科目**
   - 觸發介面改變

2. **檢查當前狀態**
   - 若在測驗中: 顯示確認對話框「是否離開並保存進度？」
   - 若在統計/錯題頁: 可選擇回到主選單或直接切換

3. **更新配置**


4. **更新 UI**
   - 更新頂部列顯示
   - 更新主選單背景色
   - 更新 `document.title`

### 3.3 綜合練習流程

1. **點擊「基本挑戰 (10題)」或「進階挑戰 (25題)」**


2. **準備題目**
   - 從當前學期題目中篩選有效選擇題
   - 可優先納入錯題
   - 隨機打亂順序
   - 取前 10 或 20 題

3. **開始測驗**
   - 切換至 `quiz` 視圖
   - 初始化 `currentIndex = 0`
   - 記錄 `startTime = Date.now()`
   - 顯示第一題

4. **答題流程**（見 3.4）

5. **完成測驗**
   - 計算總分與正確率
   - 計算耗時
   - 保存練習記錄 (`savePracticeRecord`)
   - 清除測驗進度 (`clearQuizProgress`)
   - 切換至 `result` 視圖

### 3.4 答題流程

1. **顯示題目**
   - 顯示題目卡片
   - 顯示選項按鈕
   - 顯示進度條與即時統計

2. **選擇答案**
   - 使用者點擊選項（或使用快捷鍵 1-4 / A-D）
   - 選項高亮顯示（`.selected`）
   - 顯示「確認答案」按鈕

3. **確認答案**
   - 使用者點擊「確認答案」
   - 計算是否正確
   - 更新即時統計 (`sessionStats`)
   - 保存答題紀錄 (`saveAnswerRecord`)
   - 保存測驗進度 (`saveQuizProgress`)

4. **顯示結果**

   - 選項顯示正確/錯誤狀態
   - 顯示答案解釋
   - 顯示「下一題」按鈕

5. **進入下一題**
   - 自動: 2 秒後自動進入下一題（可選）
   - 手動: 點擊「下一題」按鈕
   - 更新 `currentIndex++`
   - 若為最後一題: 顯示「查看結果」按鈕

### 3.5 分課練習流程

1. **點擊分課按鈕**
   - 從當前學期題目中篩選該課題目
   - 進入測驗流程（同 3.3 步驟 3-5）

2. **分課列表**
   - 僅顯示當前學期的課程
   - 按 `lessonOrder` 排序
   - 按鈕顯示「第 N 課：{課程標題}」

### 3.6 全部題庫流程

1. **點擊「全部題庫」**
   - 切換至 `review` 視圖
   - 載入當前配置的題目

2. **顯示分類 Tab**
   - 依題目的 `category` 分組
   - 顯示 Tab 按鈕

3. **切換分類**
   - 點擊 Tab 切換顯示該分類題目
   - 顯示題目卡片列表（題幹、選項、答案、解釋）

### 3.7 錯題檢視流程

1. **點擊「錯題」按鈕**
   - 切換至 `all-wrong-questions` 視圖
   - 載入當前配置的題目
   - 呼叫 `getWrongQuestions(grade, subject, semester, publisher)`

2. **顯示錯題列表**
   - 列出所有累積錯題
   - 顯示錯誤次數與正確率
   - 顯示題目詳情（題幹、選項、解釋）

3. **本次錯題**
   - 從結果頁點擊「查看錯題詳情」
   - 切換至 `wrong-questions` 視圖
   - 顯示本次練習答錯的題目

### 3.8 統計檢視流程

1. **點擊「統計」按鈕**
   - 切換至 `statistics` 視圖
   - 載入當前配置的題目

2. **顯示統計資料**
   - 綜合練習統計: 呼叫 `getStatistics(grade, subject, semester, publisher)`
   - 分類統計: 依題目分類計算答題數與正確率
   - 練習歷史: 呼叫 `getPracticeHistory(grade, subject, semester, publisher)`

## 無障礙設計

### 6.1 鍵盤導航

- **Tab 鍵**: 依序聚焦可互動元素
- **Enter/Space**: 啟動按鈕、選項
- **ESC**: 關閉模態框、返回上一頁
- **方向鍵**: 導航選項（可選）

### 6.2 快捷鍵

- **1-4 / A-D**: 選擇選項（測驗頁）
- **Enter**: 確認答案、下一題
- **ESC**: 返回、關閉

## 附錄

### A. 設計工具建議

- **Figma**: 用於設計稿與原型
- **Adobe XD**: 用於互動原型
- **Sketch**: 用於視覺設計

### B. 開發工具建議

- **Vue 3**: 前端框架
- **Vite**: 建置工具
- **CSS Variables**: 主題色彩管理
- **Tailwind CSS**: 可選的 CSS 框架

### C. 測試建議

- **視覺回歸測試**: 使用 Percy、Chromatic
- **響應式測試**: 使用 BrowserStack、Responsively
- **無障礙測試**: 使用 axe、WAVE
