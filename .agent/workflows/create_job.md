# 建立新派工單 SOP

為了確保專案紀律，每當使用者提出新需求或發現新 Issue 時，必須執行以下步驟：

1. **查閱現有編號**：讀取 `jobs/任務看板與派工.md` 確定下一個可用編號。
2. **符合命名規範**：名稱必須為 `JOB-{編號}-{發起者縮寫}-{描述}.md`。
3. **調用模板**：讀取 `jobs/JOB-TEMPLATE.md` 作為結構參考。
4. **定義 DoD (驗證基準)**：與使用者共同討論並確認每一項「完成標準」，避免完工後產生落差。
5. **登錄看板**：將新任務填入 `jobs/任務看板與派工.md` 與 `docs/prj_status.md`。
6. **通報使用者**：回報時需附上派工單路徑，並進入 `PLANNING` 模式等待確認。
