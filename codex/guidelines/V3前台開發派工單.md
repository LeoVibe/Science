## 1. 系統架構背景與規格更新

嗨，Cursor！我是負責資料架構的 Antigravity。
我們決定擴增題庫的讀取邏輯。請在載入題庫時，檢查 `question/platform/<年級>/<科目>/<學期>/<出版社>/manifest.json` 的內容。

我剛對所有 `manifest.json` 匯入了新的屬性 `moduleMetaData`：

```json
{
  "version": "1.0.0",
  "files": [ "L1_題目.json" ],
  "moduleMetaData": {
    "status": "active", // 枚舉: "active" (啟用) | "disabled" (停用/維護中)
    "quality": {
      "depthScore": 9.0,      // 0~10 的數字
      "accuracyScore": 9.5,   // 0~10 的數字
      "isVerified": true      // 布林值
    }
  }
}
```

## 2. 你的任務清單 (Tasks for Cursor)

### 第一部分：型別定義修改 (TypeScript)
請找到負責讀取 Manifest 的型別定義檔（例如 `types/question.ts` 或 `api.ts`），擴增 `Manifest` 的 Interface，確保它支援 `moduleMetaData` 的讀取。

### 第二部分：實作前台路由攔截 (Route Guard)
在學生點擊進入某個測驗單元（例如 `/quiz/G5/math/...`）時：
1. Fetch 該單元的 `manifest.json`。
2. 檢查 `moduleMetaData.status`。若為 `disabled`，**不可進入測驗引擎**。
3. 顯示一個友善的 Fallback UI：「⚠️ 本學科的題庫目前正在維修/優化中，我們正在準備更優質的題目，請稍後再回來看！」

### 第三部分：實作狀態與品質分數 UI (Subjects / Courses List)
在科目列表或章節總覽頁面 (`SubjectView.tsx` 或類似組件)：
1. 若該科目 `status === 'disabled'`，請將按鈕標示為灰色或鎖定狀態。
2. 若該科目 `status === 'active'` 且存在 `quality` 物件，請在介面右上角或旁邊加入一個小銘牌 (Badge) 顯示它的品質：
   - 範例文字：`🎯 深度 9.0 | 正確度 9.5`
   - 若 `isVerified` 為 `true`，加上一個徽章小圖示 (如 ✅)。
